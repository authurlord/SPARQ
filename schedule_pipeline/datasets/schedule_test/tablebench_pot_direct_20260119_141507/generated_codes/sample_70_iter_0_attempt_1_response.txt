Step 1: The user wants to know the number of Indians admitted in the year 2005.  
Step 2: Load the dataframe.  
Step 3: Filter the row where 'year' is '2005'.  
Step 4: Extract the value in the 'indians admitted' column for that row.  
Step 5: Print the result.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the row where year is 2005 and get the 'indians admitted' value
indians_2005 = df[df['year'] == '2005']['indians admitted'].values[0]
print(f"Final Answer: {indians_2005}")
```
