Step 1: The user wants to forecast the pass percentage and obtained GPA for 2011 based on the trend from 2005 to 2010.
Step 2: Load the dataframe.
Step 3: Extract the 'pass percentage' and 'obtained gpa - 5' columns, converting them to numeric values (removing '%' from pass percentage).
Step 4: Perform a simple linear regression or use a trend line (using numpy.polyfit) to predict the values for 2011.
Step 5: Output the forecasted pass percentage and GPA.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Convert 'pass percentage' to float by removing '%'
df['pass percentage'] = df['pass percentage'].str.replace('%', '').astype(float)

# Extract year and metrics
years = df['year'].astype(int)
pass_percentages = df['pass percentage']
gpa_values = df['obtained gpa - 5']

# Fit linear models for both metrics
poly_pass = np.polyfit(years, pass_percentages, 1)
poly_gpa = np.polyfit(years, gpa_values, 1)

# Predict for 2011
predicted_pass = np.polyval(poly_pass, 2011)
predicted_gpa = np.polyval(poly_gpa, 2011)

print(f"Final Answer: {predicted_pass:.2f}, {predicted_gpa:.2f}")
```
