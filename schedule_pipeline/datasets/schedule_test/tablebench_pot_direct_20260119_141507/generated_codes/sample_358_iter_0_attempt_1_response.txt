Step 1: The user wants to count the number of years where the number of Indians admitted exceeds 25,000.  
Step 2: Load the dataframe.  
Step 3: Select the 'indians admitted' column and filter rows where the value is greater than 25000.  
Step 4: Count the number of such rows and print the result.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Count years where 'indians admitted' > 25000
count_years = df[df['indians admitted'] > 25000].shape[0]
print(f"Final Answer: {count_years}")
```
