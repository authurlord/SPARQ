Step 1: Identify players who have won men's singles and mixed doubles titles in the same year.
Step 2: For each year, check if the same player appears in both "mens singles" and "mixed doubles".
Step 3: Count how many times a player appears in mixed doubles for the years they also won men's singles.
Step 4: Filter players who have won mixed doubles at least twice in such years (i.e., in multiple years where they also won men's singles).
Step 5: Return the name of such players.

Note: The data shows that "mixed doubles" is listed as a team, but we are to find individuals. However, the question asks for a player who won both men's singles and mixed doubles in the same year, and has done so at least twice (in different years). So we will treat each entry as a year and extract the individual names from the mixed doubles and men's singles columns.

We need to:
- Extract the men's singles winner per year.
- Extract the mixed doubles partners per year.
- Check if any player appears in both men's singles and mixed doubles in the same year.
- Then count how many times that player appears in mixed doubles across years when they also won men's singles.

However, mixed doubles is listed as a pair (e.g., "svetoslav stoyanov raina tzvetkova"), so we need to extract individual names from that string.

We will:
- Split the mixed doubles string by space to get individual names.
- Check if any of those names matches the men's singles winner in that year.
- If yes, record the player and the year.
- Then count how many times the player appears in mixed doubles in such years (i.e., in years when they also won men's singles).

Let’s implement this step-by-step.

```python
import pandas as pd

# Load the data
df = pd.read_csv('table.csv')

# Convert the data to a list of dictionaries for easier manipulation
data = df.to_dict('records')

# Dictionary to store player appearances in mixed doubles when they also won men's singles
player_count = {}

# Iterate over each row (year)
for row in data:
    year = row['year']
    mens_singles = row['mens singles']
    mixed_doubles = row['mixed doubles']
    
    # Split mixed doubles into individual names
    mixed_names = mixed_doubles.split()
    
    # Check if any of the mixed doubles players matches the men's singles winner
    for name in mixed_names:
        if name == mens_singles:
            # If the player is the same, increment count
            if name in player_count:
                player_count[name] += 1
            else:
                player_count[name] = 1

# Find players who have won mixed doubles at least twice in years when they also won men's singles
result = [name for name, count in player_count.items() if count >= 2]

print(f"Final Answer: {', '.join(result)}")
```

Note: This assumes that the mixed doubles partner list contains the men's singles winner as one of the names. This may not always be true due to name variations or formatting issues (e.g., "jeliazko valkov" appears in both men's singles and mixed doubles). But based on the data, it seems consistent in several years (e.g., 1985–1988, 1991, etc.).

The code checks for exact name matches. If the name matches exactly, it counts the occurrence.
