Step 1: The user wants the average annual increase in issue price from 2007 to 2011.  
Step 2: Load the dataframe and convert 'issue price' to float for numerical operations.  
Step 3: Extract the 'year' and 'issue price' columns, sort by year, and compute the year-on-year price differences.  
Step 4: Calculate the average of these differences (annual increases).  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'issue price' to float
df['issue price'] = df['issue price'].astype(float)
# Sort by year
df = df.sort_values('year')
# Calculate the year-on-year difference in issue price
price_diffs = df['issue price'].diff().dropna()
# Calculate average annual increase
avg_increase = price_diffs.mean()
print(f"Final Answer: {avg_increase:.2f}")
```
