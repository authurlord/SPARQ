Step 1: The user wants to find the maximum increase in issue price from one year to the next.
Step 2: Load the dataframe.
Step 3: Convert 'issue price' to float for numerical operations.
Step 4: Sort by 'year' to ensure chronological order.
Step 5: Calculate the difference between consecutive years' issue prices.
Step 6: Find the maximum increase and print it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'issue price' to float
df['issue price'] = pd.to_numeric(df['issue price'])
# Sort by year
df = df.sort_values('year')
# Calculate the difference between consecutive years
price_increase = df['issue price'].diff()
# Find the maximum increase
max_increase = price_increase.max()
print(f"Final Answer: {max_increase:.2f}")
```
