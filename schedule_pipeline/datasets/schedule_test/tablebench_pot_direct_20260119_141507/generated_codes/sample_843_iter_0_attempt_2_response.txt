Step 1: The user wants to find the bishop with the longest tenure in office and compare it to the average tenure.  
Step 2: Extract the "Office started" and "Office ended" columns to calculate the tenure for each bishop.  
Step 3: For bishops with missing death dates (like "Incumbent"), we assume their tenure ends at the current time, but since no end date is given, we exclude such cases or treat them as incomplete. However, only the first 13 bishops have clear start and end years.  
Step 4: Convert "Office started" and "Office ended" to integers (years), compute tenure as (end - start).  
Step 5: Find the maximum tenure and its corresponding bishop.  
Step 6: Compute the average tenure of all bishops with valid tenures.  
Step 7: Calculate the difference between the longest tenure and the average tenure.  

Note: The last row ("Agnes Sigurðardóttir") has no office end date, so we exclude it from tenure calculation.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Drop rows where 'Office ended' is missing or invalid (e.g., "Incumbent")
df_clean = df.dropna(subset=['Office ended'])

# Convert Office started and Office ended to integers
df_clean['Office started'] = df_clean['Office started'].astype(int)
df_clean['Office ended'] = df_clean['Office ended'].astype(int)

# Calculate tenure in years
df_clean['tenure'] = df_clean['Office ended'] - df_clean['Office started']

# Find the bishop with the longest tenure
longest_tenure_bishop = df_clean.loc[df_clean['tenure'].idxmax(), 'Name']
max_tenure = df_clean['tenure'].max()

# Calculate average tenure
avg_tenure = df_clean['tenure'].mean()

# Difference between longest and average tenure
difference = max_tenure - avg_tenure

print(f"Final Answer: {longest_tenure_bishop}, {difference:.1f}")
```
