Step 1: The user wants the mean and standard deviation of the `against` column, which represents the total points conceded by each team.  
Step 2: Load the dataframe.  
Step 3: Extract the `against` column.  
Step 4: Calculate the mean and standard deviation using pandas.  
Step 5: Print both values.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Calculate mean and standard deviation of the 'against' column
mean_against = df['against'].mean()
std_against = df['against'].std()
print(f"Final Answer: {mean_against:.1f}, {std_against:.1f}")
```
