Step 1: The user wants to find the nation that ranked 4th in the medal count.
Step 2: Load the dataframe.
Step 3: Filter the row where 'rank' is '4'.
Step 4: Extract the 'nation' column value and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where rank is 4
nation_rank_4 = df[df['rank'] == '4']['nation'].values[0]
print(f"Final Answer: {nation_rank_4}")
```
