Step 1: The user wants to identify the country with the highest German imports in 1939 and compare it to its imports in 1934.
Step 2: Load the dataframe.
Step 3: Filter data for the year 1939 and find the country with the maximum import value.
Step 4: Retrieve the import value for that country in 1934.
Step 5: Present the country name, 1939 value, and 1934 value in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Drop the last row which contains headers
df = df.iloc[:-1]
# Set the first column as index (year)
df.set_index('-', inplace=True)
# Convert all columns to numeric
df = df.astype(float)

# Find the country with highest imports in 1939
max_1939 = df.loc['1939'].idxmax()
value_1939 = df.loc['1939', max_1939]
value_1934 = df.loc['1934', max_1939]

print(f"Final Answer: {max_1939}, {value_1939:.1f}, {value_1934:.1f}")
```
