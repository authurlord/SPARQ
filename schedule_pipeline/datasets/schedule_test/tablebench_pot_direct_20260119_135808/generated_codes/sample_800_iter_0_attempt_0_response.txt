Step 1: The user wants the median points scored by artists who sang in languages other than French.
Step 2: Load the dataframe.
Step 3: Filter rows where the 'language' is not 'french'.
Step 4: Extract the 'points' column from the filtered data.
Step 5: Calculate the median of the 'points' column and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter out rows where language is 'french'
non_french_data = df[df['language'] != 'french']
# Calculate median of points for non-French languages
median_points = non_french_data['points'].median()
print(f"Final Answer: {median_points}")
```
