We are asked to find the difference in total goals between the top-scoring forward (fw) and the top-scoring midfielder (mf) in the league.

Step-by-step approach:
1. Identify players with position 'fw' (forward) and 'mf' (midfielder).
2. Extract the 'total goals' column for each group.
3. Find the maximum total goals for forwards and midfielders.
4. Compute the difference: max(forwards) - max(midfielders).

Note: The error in the previous attempt was likely due to incorrect parsing of the 'total goals' column, especially when values like '3 (1)' are present. However, we see that in the data, the 'total goals' column is already in a format like '3', '0', or '1', and the parentheses are part of the app count (e.g., "43 (1)") — so we only need the numeric value before the space or parenthesis.

But looking at the table, the 'total goals' column is already stored as a string with numbers like '3', '0', '9', etc. For example:
- '3' for Andy Holdsworth
- '0' for Joe Skarz

So we can safely extract the numeric value from the string. However, in the provided data, the 'total goals' column is already in a clean format like '3', '0', '9', etc., without parentheses. This means we can directly convert it to integer.

Therefore:
- Filter rows where position == 'fw' or position == 'mf'
- Convert 'total goals' to integer
- Find the max for each group
- Compute the difference

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for forwards and midfielders
forwards = df[df['position'] == 'fw']
midfielders = df[df['position'] == 'mf']

# Extract total goals and convert to integers
forward_goals = forwards['total goals'].astype(int)
midfielder_goals = midfielders['total goals'].astype(int)

# Find maximum goals for each group
max_forward_goals = forward_goals.max()
max_midfielder_goals = midfielder_goals.max()

# Calculate the difference
difference = max_forward_goals - max_midfielder_goals

print(f"Final Answer: {difference}")
```
