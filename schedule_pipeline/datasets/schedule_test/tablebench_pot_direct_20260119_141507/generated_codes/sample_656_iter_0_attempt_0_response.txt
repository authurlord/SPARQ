Step 1: The user wants to find the correlation between 'bp comp 1 (°C)' and '% wt comp 1'.  
Step 2: Load the dataframe.  
Step 3: Extract the two columns of interest.  
Step 4: Compute the Pearson correlation coefficient between them.  
Step 5: Print the result.

Note: The data contains some non-numeric entries (like '- 0.5' or '–'), but in this context, they are likely meant to be interpreted as numeric values (e.g., -0.5). We will convert them to float during processing.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert 'bp comp 1 (˚C)' and '% wt comp 1' to numeric, handling any formatting issues
df['bp comp 1 (˚c)'] = pd.to_numeric(df['bp comp 1 (˚c)'], errors='coerce')
df['% wt comp 1'] = pd.to_numeric(df['% wt comp 1'], errors='coerce')

# Drop rows with NaN due to invalid conversion
df_clean = df.dropna(subset=['bp comp 1 (˚c)', '% wt comp 1'])

# Compute correlation coefficient
correlation = df_clean['bp comp 1 (˚c)'].corr(df_clean['% wt comp 1'])

print(f"Final Answer: {correlation:.3f}")
```
