Step 1: The user wants the total number of films from the years 2012 to 2014.
Step 2: Load the dataframe.
Step 3: Filter rows where the year (first column) is between 2012 and 2014 inclusive.
Step 4: Select the 'Films' column and sum the values.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for years 2012 to 2014
filtered_df = df[(df['-'] >= '2012') & (df['-'] <= '2014')]
# Convert 'Films' column to numeric, handling potential non-numeric values like '700+'
filtered_df['Films'] = pd.to_numeric(filtered_df['Films'].str.replace('+', ''), errors='coerce')
total_films = filtered_df['Films'].sum()
print(f"Final Answer: {int(total_films)}")
```
