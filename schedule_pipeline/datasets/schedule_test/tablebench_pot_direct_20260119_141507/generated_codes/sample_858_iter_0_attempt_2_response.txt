Step 1: The user wants to identify the country with the highest GDP per capita and compute the difference between that value and the GDP per capita of the EC6 (1958) region.  
Step 2: Load the dataframe.  
Step 3: Extract the 'gdp per capita (us)' column.  
Step 4: Find the maximum GDP per capita and the corresponding country.  
Step 5: Calculate the difference between the maximum GDP per capita and the GDP per capita of EC6 (1958).  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the country with the highest GDP per capita
max_gdp_per_capita = df['gdp per capita (us)'].max()
max_gdp_country = df[df['gdp per capita (us)'] == max_gdp_per_capita]['member countries'].values[0]

# GDP per capita of EC6 (1958)
ec6_gdp_per_capita = df[df['member countries'] == 'ec6 (1958)']['gdp per capita (us)'].values[0]

# Calculate the difference
difference = max_gdp_per_capita - ec6_gdp_per_capita

print(f"Final Answer: {max_gdp_country}, {difference:.0f}")
```
