Step 1: The user wants to find the number of league goals scored by George McLean during his career from 1930 - 1934.  
Step 2: Look at the row where the name is "george mclean" and check the "league goals" column.  
Step 3: Extract the value and print it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for George McLean and get the league goals
george_mclean_goals = df[df['name'] == 'george mclean']['league goals'].values[0]
print(f"Final Answer: {george_mclean_goals}")
```
