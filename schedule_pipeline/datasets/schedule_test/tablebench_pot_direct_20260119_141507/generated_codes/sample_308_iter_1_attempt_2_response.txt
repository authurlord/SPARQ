The error occurred because the "Year" column contains string values (e.g., '1984'), and we attempted to compare them with integers using `>=`. We need to ensure the year is converted to an integer before filtering.

Step-by-step approach:
1. Load the dataframe.
2. Filter rows where the Artist is "Glen Campbell".
3. Convert the "Year" column to integer type to enable numerical comparison.
4. Check if the year is in the 1980s (i.e., between 1980 and 1989 inclusive).
5. Count the number of such songs.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert Year to integer, then filter for Glen Campbell songs in the 1980s
df['Year'] = pd.to_numeric(df['Year'], errors='coerce')
glen_campbell_1980s = df[(df['Artist'] == 'Glen Campbell') & (df['Year'] >= 1980) & (df['Year'] <= 1989)]
count = len(glen_campbell_1980s)
print(f"Final Answer: {count}")
```
