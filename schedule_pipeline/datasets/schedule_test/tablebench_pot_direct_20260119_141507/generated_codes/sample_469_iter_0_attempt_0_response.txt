Step 1: Identify potential anomalies in the data. Anomalies can include:
- Missing or inconsistent values (e.g., "unknown", "none", "0.1", etc.)
- Extremely high or low values compared to others
- Inconsistencies in total deaths vs. sum of military and civilian deaths
- Discrepancies in wounded or casualties

Step 2: Check for:
- Total deaths not matching sum of military and civilian deaths
- Outliers in numerical values (e.g., very high or very low)
- Values with inconsistent formatting (e.g., "unknown" vs. numbers)

Step 3: Analyze rows where:
- Military deaths + civilian deaths ≠ total deaths (not including foreigners)
- Wounded or casualties are inconsistent with other values
- Some values are missing or marked as "unknown"

Step 4: Highlight rows with anomalies.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert all entries to numeric, treating non-numeric as NaN
df_numeric = df.apply(pd.to_numeric, errors='coerce')

# Check if sum of military and civilian deaths equals total deaths (excluding foreigners)
anomalies = []

for idx, row in df.iterrows():
    military = row['military deaths']
    civilian = row['civilian deaths']
    total_deaths = row['total deaths (not including foreigners)']
    
    # Skip if any value is "unknown" or not numeric
    if pd.isna(military) or pd.isna(civilian) or pd.isna(total_deaths):
        anomalies.append((idx, "Missing data in deaths"))
        continue
    
    # Convert to int for comparison
    m = int(military)
    c = int(civilian)
    t = int(total_deaths)
    
    # Check if sum of military and civilian deaths matches total deaths
    if m + c != t:
        anomalies.append((idx, f"Sum mismatch: {m} + {c} = {m+c} ≠ {t}"))
    
    # Check for extreme outliers in total casualties
    if row['total casualties'] > 100000:
        anomalies.append((idx, f"High total casualties: {row['total casualties']}"))

# Print anomalies found
print("Anomalies found:")
for idx, msg in anomalies:
    print(f"Row {idx}: {msg}")
```
