Step 1: The user wants the difference between the highest and lowest PSI values across provinces.
Step 2: Load the dataframe.
Step 3: Extract the 'PSI' column and convert values to float, handling '-' as NaN.
Step 4: Find the maximum and minimum PSI values (excluding invalid entries).
Step 5: Calculate the difference and print it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'PSI' column to numeric, treating '-' as NaN
df['PSI'] = pd.to_numeric(df['PSI'], errors='coerce')
# Drop rows where PSI is NaN
df_clean = df.dropna(subset=['PSI'])
# Calculate the difference between max and min PSI
difference = df_clean['PSI'].max() - df_clean['PSI'].min()
print(f"Final Answer: {difference:.1f}")
```
