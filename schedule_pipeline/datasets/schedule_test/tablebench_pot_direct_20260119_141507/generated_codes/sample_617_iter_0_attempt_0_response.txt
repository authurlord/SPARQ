Step 1: The user wants the total number of episodes across Seasons 1, 2, and 3.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'Season' is 1, 2, or 3.  
Step 4: Sum the 'Episodes' column for these rows.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter episodes for Seasons 1, 2, and 3
filtered_episodes = df[(df['Season'].isin([1, 2, 3]))]['Episodes']
total_episodes = filtered_episodes.sum()
print(f"Final Answer: {total_episodes}")
```
