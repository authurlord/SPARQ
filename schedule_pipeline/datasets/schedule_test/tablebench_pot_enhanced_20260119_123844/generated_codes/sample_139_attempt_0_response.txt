Step 1: The user wants a horizontal bar chart showing the lifespan of each locomotive, with the x-axis representing years and the y-axis representing locomotive names.
Step 2: Load the dataframe.
Step 3: Calculate the lifespan for each locomotive by subtracting 'Introduced' from 'Withdrawn'.
Step 4: Create a horizontal bar chart using matplotlib with locomotive names on the y-axis and lifespan on the x-axis.
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')
# Calculate lifespan
df['lifespan'] = df['Withdrawn'].astype(int) - df['Introduced'].astype(int)
# Create horizontal bar chart
plt.figure(figsize=(10, 6))
plt.barh(df['Name'], df['lifespan'], color='skyblue')
plt.xlabel('Lifespan (years)')
plt.ylabel('Locomotive Name')
plt.title('Lifespan of Each Locomotive')
plt.gca().invert_yaxis()  # To display the longest lifespan at the top
plt.show()
```
