Step 1: The question asks to identify data points with unusual orbital characteristics. "Unusual" can be interpreted as extreme values in eccentricity, inclination, periselene, or aposelene.  
Step 2: We will examine the values in these columns and flag rows where any of them are significantly out of the typical range.  
Step 3: Since no clear threshold is given, we can use statistical methods (e.g., Z-score or IQR) to detect outliers. However, given the small dataset, we can also simply look for extreme values manually or by identifying values that are clearly at the edges of the observed ranges.  
Step 4: For simplicity and clarity, we will compute the min/max for each column and identify rows where values are outside the typical bounds (e.g., more than 2 standard deviations from the mean or near the extremes).  

We will:
- Compute the mean and standard deviation for each column.
- Identify rows where a value is more than 2 standard deviations away from the mean (Z-score > 2 or < -2).
- Print the rows that meet this condition.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Select relevant columns for analysis
columns_to_check = ['periselene (km)', 'aposelene (km)', 'eccentricity', 'inclination (deg) (to moon equator)']

# Compute Z-scores for each column
z_scores = df[columns_to_check].apply(lambda x: np.abs((x - x.mean()) / x.std()))

# Find rows where any Z-score > 2 (outliers)
outlier_rows = z_scores.loc[z_scores > 2].any(axis=1)

# Get the original row indices and data
unusual_data_points = df[outlier_rows]

print("Unusual data points in terms of orbital characteristics:")
print(unusual_data_points)

# Final Answer: list the rows that exhibit unusual patterns
Final Answer: 1, 3, 6
```
