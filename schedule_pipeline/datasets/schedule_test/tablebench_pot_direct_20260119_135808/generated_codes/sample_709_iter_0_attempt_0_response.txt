Step 1: The user wants to identify the party with the highest total number of seats across all panels.
Step 2: Load the dataframe.
Step 3: Select the 'total' column and find the maximum value.
Step 4: Identify the corresponding party name for the maximum total.
Step 5: Print the party with the highest total.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the party with the highest total
max_total_party = df.loc[df['total'].idxmax(), 'party']
print(f"Final Answer: {max_total_party}")
```
