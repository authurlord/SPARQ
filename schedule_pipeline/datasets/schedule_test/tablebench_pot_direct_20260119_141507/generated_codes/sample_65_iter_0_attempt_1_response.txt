Step 1: The user wants to know the percentage of Black voters who voted in 1960.  
Step 2: Identify the row for "Black" and the column for "1960".  
Step 3: Extract the value from that cell (it is already given as a percentage).  
Step 4: Since the data is in percentage form, no conversion is needed.  

The value for "Black" in the year 1960 is 68.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the value for 'Black' in the column '1960'
black_voters_1960 = df.loc[df['Unnamed: 0'] == 'Black', '1960'].values[0]
print(f"Final Answer: {black_voters_1960}")
```
