Step 1: The user wants to count how many songs written by Glen Campbell were released in the 1980s.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'Artist' is 'Glen Campbell' and the 'Year' is between 1980 and 1989 (inclusive).  
Step 4: Count the number of such rows.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter songs by Glen Campbell released in the 1980s
glen_1980s = df[(df['Artist'] == 'Glen Campbell') & (df['Year'].between(1980, 1989))]
count = len(glen_1980s)
print(f"Final Answer: {count}")
```
