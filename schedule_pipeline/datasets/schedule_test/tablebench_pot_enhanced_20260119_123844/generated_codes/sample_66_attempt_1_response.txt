Step 1: The user wants to find the number of 3-pointers made by Alpha Ambrose Kargbo.
Step 2: Load the dataframe.
Step 3: Filter the row where 'player name' is 'alpha ambrose kargbo'.
Step 4: Extract the value from the '3 - points' column.
Step 5: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for Alpha Ambrose Kargbo
kargbo_row = df[df['player name'] == 'alpha ambrose kargbo']
# Extract the 3-pointers made
three_pointers = kargbo_row['3 - points'].values[0]
print(f"Final Answer: {three_pointers}")
```
