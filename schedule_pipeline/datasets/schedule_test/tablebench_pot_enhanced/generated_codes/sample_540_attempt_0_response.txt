Step 1: Filter the data for the 'honda' team in the '125cc' class from 1994 to 1998.
Step 2: Extract the 'points' values for these years.
Step 3: Calculate the annual increase by computing the difference between consecutive years' points.
Step 4: Compute the average of these annual increases.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for honda in 125cc class from 1994 to 1998
honda_125cc = df[(df['team'] == 'honda') & (df['class'] == '125cc') & (df['year'].astype(int) >= 1994) & (df['year'].astype(int) <= 1998)]
# Sort by year to ensure correct order
honda_125cc = honda_125cc.sort_values('year')
# Extract points and calculate annual increase
points = honda_125cc['points'].astype(int).values
annual_increases = [points[i] - points[i-1] for i in range(1, len(points))]
# Calculate average annual increase
avg_increase = sum(annual_increases) / len(annual_increases)
print(f"Final Answer: {avg_increase:.1f}")
```
