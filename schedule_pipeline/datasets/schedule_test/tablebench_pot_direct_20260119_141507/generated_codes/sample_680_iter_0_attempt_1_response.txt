Step 1: The user wants the correlation coefficient between 'median household income' and 'population' for New Mexico counties.  
Step 2: First, filter the data to include only rows where the 'county' is in New Mexico (note: "new mexico" appears as a row in the table, and other counties are specific).  
Step 3: Extract the 'median household income' and 'population' columns for the relevant rows.  
Step 4: Compute the Pearson correlation coefficient between these two variables.  
Step 5: Print the correlation coefficient.

Note: The row labeled "new mexico" has population and income values that represent state-level data, not county-level. Since the question asks for "New Mexico counties", we should exclude the state-level row and focus only on the county-level entries for New Mexico.

From the table, the counties listed are: los alamos, santa fe, bernalillo, sandoval, eddy, lincoln, taos, mora, grant, colfax, catron, de baca, san juan, valencia, curry, rio arriba, lea, otero, union, san miguel, chaves, doña ana, quay, socorro, hidalgo, torrance, roosevelt, sierra, luna, cibola, harding, guadalupe, mckinley. Among these, only those explicitly named as part of New Mexico (all are) are valid. However, "new mexico" as a row is a state-level entry, so we exclude it.

We will exclude the row with "new mexico" and compute the correlation among the remaining county-level entries.

```python
import pandas as pd

# Load the data
df = pd.read_csv('table.csv')

# Filter rows where county is not 'new mexico' (exclude state-level row)
df_filtered = df[df['county'] != 'new mexico']

# Extract 'median household income' and 'population' columns
income = df_filtered['median household income'].astype(float)
population = df_filtered['population'].astype(float)

# Calculate correlation coefficient
correlation = income.corr(population)

print(f"Final Answer: {correlation:.3f}")
```
