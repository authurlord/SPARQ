The error occurred because the 'total' column contains string values (e.g., '51', '21') that need to be converted to numeric before computing the median. We must convert the 'total' column to numeric type and then compute the median for both the top 5 nations and all nations.

Step-by-step approach:
1. Load the dataframe.
2. Convert the 'total' column to numeric (to avoid conversion errors).
3. Extract the total medals for the top 5 rankings (rows where rank is 1 to 5).
4. Compute the median of the top 5 nations' total medals.
5. Compute the median of all nations' total medals.
6. Print both medians.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'total' column to numeric to ensure proper calculation
df['total'] = pd.to_numeric(df['total'], errors='coerce')

# Get the total medals for top 5 rankings (rank 1 to 5)
top_5_total = df[df['rank'].astype(int).le(5)]['total']

# Compute median for top 5 and all nations
median_top_5 = top_5_total.median()
median_all = df['total'].median()
```
