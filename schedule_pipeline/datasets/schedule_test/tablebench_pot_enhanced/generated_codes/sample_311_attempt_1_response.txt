Step 1: The user wants to find the player who won both men's singles and men's doubles titles in the same year.
Step 2: Load the dataframe.
Step 3: Iterate through each row and check if the men's singles winner is also part of the men's doubles winners.
Step 4: If a match is found, record the player and the year.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Initialize variables to store the result
winner = None
year = None

# Iterate through each row
for index, row in df.iterrows():
    men_singles = row["men 's singles"]
    men_doubles = row["men 's doubles"]
    
    # Check if the men's singles winner is in the men's doubles winners
    if men_singles in men_doubles:
        winner = men_singles
        year = row['year']
        break

print(f"Final Answer: {winner}, {year}")
```
