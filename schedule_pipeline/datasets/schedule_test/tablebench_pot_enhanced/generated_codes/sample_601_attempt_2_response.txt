Step 1: The user wants to calculate the number of R class locomotives in service at the end of 1931.
Step 2: The R class in service at the start of 1931 is given as 11.
Step 3: One locomotive was withdrawn during the year.
Step 4: Subtract the quantity withdrawn from the starting number to get the ending number.
Step 5: Output the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Extract data for 1931
start_r_class = df[df['Year'] == '1931']['R class in service at start of year'].values[0]
withdrawn = df[df['Year'] == '1931']['Quantity withdrawn'].values[0]

# Calculate end of year R class
end_r_class = int(start_r_class) - int(withdrawn)
print(f"Final Answer: {end_r_class}")
```
