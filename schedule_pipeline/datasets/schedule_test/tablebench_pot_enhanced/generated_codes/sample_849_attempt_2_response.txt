Step 1: The user wants to find the difference in enrollment between the school with the highest enrollment and the school with the lowest enrollment.
Step 2: Load the dataframe.
Step 3: Convert the 'enrollment' column to integers for numerical operations.
Step 4: Find the maximum and minimum enrollment values.
Step 5: Calculate the difference and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'enrollment' column to integer type
df['enrollment'] = pd.to_numeric(df['enrollment'])
# Calculate the difference between max and min enrollment
enrollment_diff = df['enrollment'].max() - df['enrollment'].min()
print(f"Final Answer: {enrollment_diff}")
```
