Step 1: The user wants to count how many cities have a residential monthly usage of 1000 kwh above 12.
Step 2: Load the dataframe.
Step 3: Select the 'residential monthly usage : 1000 kwh' column.
Step 4: Filter rows where the value is greater than 12.
Step 5: Count the number of such cities and print.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert the residential monthly usage column to float for comparison
residential_usage = df['residential monthly usage : 1000 kwh'].astype(float)
# Count cities with usage above 12
count_above_12 = (residential_usage > 12).sum()
print(f"Final Answer: {count_above_12}")
```
