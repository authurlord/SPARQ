Step 1: The user wants the total number of enrolled men and women in regions where the 'e / vap ratio total' is greater than 105%.

Step 2: Load the dataframe.

Step 3: Filter rows where 'e / vap ratio total' > 105% (note: this column contains strings with %, so we need to handle it properly).

Step 4: Convert 'e / vap ratio total' to numeric by removing the '%' sign and converting to float.

Step 5: Filter rows where the value is greater than 105.

Step 6: Sum the 'enrolled men' and 'enrolled women' columns for the filtered rows.

Step 7: Print the total.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert 'e / vap ratio total' to numeric by removing the % and converting to float
df['e / vap ratio total'] = df['e / vap ratio total'].str.replace('%', '').astype(float)

# Filter regions where 'e / vap ratio total' > 105
filtered_df = df[df['e / vap ratio total'] > 105]

# Sum enrolled men and women
total_enrolled_men = filtered_df['enrolled men'].sum()
total_enrolled_women = filtered_df['enrolled women'].sum()

# Final answer is the sum of both
total_enrolled = total_enrolled_men + total_enrolled_women

print(f"Final Answer: {total_enrolled}")
```
