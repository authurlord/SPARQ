Step 1: The user wants to count how many conferences had occurrences in the year 1996.
Step 2: Load the dataframe.
Step 3: Focus on the columns corresponding to years, specifically '1996'.
Step 4: Count the number of non-missing (not '-') entries in the '1996' column.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Count non-missing values in the '1996' column
count_1996 = df['1996'].ne('-').sum()
print(f"Final Answer: {count_1996}")
```
