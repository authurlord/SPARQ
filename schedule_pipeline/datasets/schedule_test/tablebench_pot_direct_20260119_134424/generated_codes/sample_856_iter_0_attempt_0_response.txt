Step 1: The user wants to find the difference between the 'dp / da' values for the 2004 election and the 1999 election.
Step 2: Load the dataframe.
Step 3: Filter rows for '2004 election' and '1999 election'.
Step 4: Extract the 'dp / da' values for both.
Step 5: Calculate the difference and print.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows for the required events
dp_da_2004 = df[df['event'] == '2004 election']['dp / da'].values[0]
dp_da_1999 = df[df['event'] == '1999 election']['dp / da'].values[0]
# Calculate the difference
difference = int(dp_da_2004) - int(dp_da_1999)
print(f"Final Answer: {difference}")
```
