Step 2: Load the dataframe.  
Step 3: Extract the 'Passengers' column and convert it to numeric (to handle comma-separated values).  
Step 4: Ensure the 'City' column is properly mapped to passenger counts.  
Step 5: Use matplotlib to create a bar chart with cities on the x-axis and passenger numbers on the y-axis.  

Note: The 'Passengers' column contains values like '132,046', so we must remove commas and convert to integer.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')

# Convert 'Passengers' to numeric by removing commas
df['Passengers'] = df['Passengers'].str.replace(',', '').astype(int)

# Create a bar chart
plt.figure(figsize=(10, 6))
plt.bar(df['City'], df['Passengers'], color='skyblue')
plt.xlabel('City')
plt.ylabel('Number of Passengers')
plt.title('Number of Passengers for Each City')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```
