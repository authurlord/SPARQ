Step 1: The user wants to identify the series with the highest average viewership.
Step 2: Load the dataframe.
Step 3: Convert the 'average viewers (millions)' column to numeric for comparison.
Step 4: Find the row with the maximum value in this column.
Step 5: Extract and return the corresponding series name.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'average viewers (millions)' to float for proper comparison
df['average viewers (millions)'] = pd.to_numeric(df['average viewers (millions)'])
# Find the series with the highest average viewership
max_viewers_series = df.loc[df['average viewers (millions)'].idxmax(), 'series']
print(f"Final Answer: {max_viewers_series}")
```
