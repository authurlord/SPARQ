Step 1: The user wants to find the highest score achieved by Lionel Palairet.  
Step 2: Locate the row where the player is "Lionel Palairet" in the table.  
Step 3: Extract the value in the "highest score" column for that row.  
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find Lionel Palairet's highest score
highest_score = df[df['player'] == 'lionel palairet']['highest score'].values[0]
print(f"Final Answer: {highest_score}")
```
