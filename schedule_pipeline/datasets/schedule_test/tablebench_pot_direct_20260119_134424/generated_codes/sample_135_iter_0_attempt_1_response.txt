Step 1: The user wants a percentage bar chart showing the percentage of total sales for each song across different regions.
Step 2: Load the dataframe.
Step 3: Exclude the 'total' column as it's not a region, and focus on the regional columns.
Step 4: Calculate the percentage of each song's sales in each region relative to the total sales.
Step 5: Use matplotlib to create a grouped bar chart where each bar represents a song and the segments show the percentage contribution from each region.
Step 6: Add labels, title, and legend for clarity.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')

# Define regions (excluding 'song' and 'total')
regions = ['mobiles', 'northern ireland', 'northern england', 'scotland', 'southern england', 'wales']

# Calculate total sales per region
total_sales_per_region = df[regions].sum()

# Calculate percentage of total sales for each song in each region
df_percentage = df[regions].div(total_sales_per_region) * 100

# Set up the bar chart
fig, ax = plt.subplots(figsize=(12, 6))

# Define bar width and positions
bar_width = 0.8
index = range(len(df))

# Plot each region as a stacked bar
bottom = [0] * len(df)
colors = ['#FF6F61', '#6B5B95', '#88B04B', '#F7CAC9', '#92A8D1', '#A05195']

for i, region in enumerate(regions):
    ax.bar(index, df_percentage[region], bar_width, label=region, bottom=bottom, color=colors[i])
    bottom = [b + v for b, v in zip(bottom, df_percentage[region])]

# Set labels and title
ax.set_xlabel('Song')
ax.set_ylabel('Percentage of Total Sales (%)')
ax.set_title('Percentage of Total Sales by Song and Region')
ax.set_xticks(index)
ax.set_xticklabels(df['song'], rotation=45)
ax.legend(loc='upper right', bbox_to_anchor=(1.15, 1))

# Show the plot
plt.tight_layout()
plt.show()
```
