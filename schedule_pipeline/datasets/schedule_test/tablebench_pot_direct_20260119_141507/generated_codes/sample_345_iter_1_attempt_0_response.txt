The error occurred because the "pop density (per km square)" column contains string values (e.g., '3905.68') instead of numeric values. We need to convert this column to numeric before comparing it to 3000.

Step-by-step approach:
1. Load the dataframe.
2. Convert the "pop density (per km square)" column to numeric (to handle string values properly).
3. Filter rows where pop density > 3000.
4. Count the number of such rows.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert pop density to numeric, coercing errors to NaN if any
df['pop density (per km square)'] = pd.to_numeric(df['pop density (per km square)'], errors='coerce')
# Count how many have population density over 3000
count_high_density = df[df['pop density (per km square)'] > 3000].shape[0]
print(f"Final Answer: {count_high_density}")
```
