Step 1: The user wants to count the number of teams with a win percentage of 0.7 or higher.  
Step 2: Load the dataframe.  
Step 3: Filter rows where 'win pct' is greater than or equal to 0.7.  
Step 4: Count the number of such teams (excluding the "totals :" row, which is not a team).  

Note: The last row is labeled "totals :" and should be excluded from the count.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Exclude the "totals :" row
df_filtered = df[df['team'] != 'totals :']
# Filter teams with win percentage >= 0.7
high_win_pct_teams = df_filtered[df_filtered['win pct'] >= 0.7]
count = len(high_win_pct_teams)
print(f"Final Answer: {count}")
```
