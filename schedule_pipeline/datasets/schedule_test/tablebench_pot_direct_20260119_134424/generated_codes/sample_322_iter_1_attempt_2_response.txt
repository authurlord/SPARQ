Step 1: The user wants to find the year when the athlete achieved their personal best time in the 20 km walk event at the African Championships.  
Step 2: Filter the data to include only rows where the 'Competition' is 'African Championships' and the 'Event' is '20 km walk'.  
Step 3: Clean the 'Notes' column to extract numeric times, handling cases like '1:22:55 (CR)' by removing non-numeric characters and converting to seconds for comparison.  
Step 4: Find the minimum time (personal best) and return the corresponding 'Year'.  
Step 5: Use proper string parsing to avoid errors from time formats like '1:22:55 (CR)'.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for African Championships and 20 km walk
african_champs_20km = df[(df['Competition'] == 'African Championships') & (df['Event'] == '20 km walk')]

# Function to convert time string to seconds
def time_to_seconds(time_str):
    if pd.isna(time_str) or time_str == 'DQ' or time_str == 'DNF' or time_str == '–':
        return float('inf')  # Invalid or no time
    # Remove any non-numeric characters except colons and parentheses
    cleaned = ''.join(c for c in time_str if c.isdigit() or c == ':')
    parts = cleaned.split(':')
    if len(parts) == 3:
        return int(parts[0]) * 3600 + int(parts[1]) * 60 + int(parts[2])
    elif len(parts) == 2:
        return int(parts[0]) * 60 + int(parts[1])
    else:
        return float('inf')

# Apply conversion and find the minimum time
african_champs_20km['time_seconds'] = african_champs_20km['Notes'].apply(time_to_seconds)
best_time_row = african_champs_20km.loc[african_champs_20km['time_seconds'].idxmin()]

# Extract the year of the personal best
final_year = best_time_row['Year']
print(f"Final Answer: {final_year}")
```
