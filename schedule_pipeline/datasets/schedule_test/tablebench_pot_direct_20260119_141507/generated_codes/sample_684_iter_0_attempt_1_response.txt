Step 1: The user wants the correlation coefficient between the number of typhus cases and smallpox cases over the years.  
Step 2: Load the dataframe.  
Step 3: Extract the 'typhus' and 'smallpox' columns.  
Step 4: Compute the Pearson correlation coefficient between these two columns.  
Step 5: Print the correlation coefficient.

Note: The data contains a row with "191822" and "2940 (avg)" which may not be numeric. We need to handle this properly — since "2940 (avg)" is likely a typo or misformatting, and we are only interested in correlation between typhus and smallpox, we will treat all values as numeric, and if any value is non-numeric (like "2940 (avg)"), we will convert it to float by removing the text part. However, given the context, it's more reasonable to assume that "191822" is a typo for "1918–1922" and the smallpox value is an average. But since the question asks for correlation over years, and the values are mixed, we proceed by extracting only the numeric parts.

We will clean the data: remove non-numeric characters from typhus and smallpox columns, then compute the correlation.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Clean the 'typhus' and 'smallpox' columns by removing non-numeric characters
def clean_numeric(x):
    if isinstance(x, str):
        # Remove non-numeric characters and convert to float
        return float(''.join(char for char in x if char.isdigit() or char == '.'))
    return x

df['typhus'] = df['typhus'].apply(clean_numeric)
df['smallpox'] = df['smallpox'].apply(clean_numeric)

# Compute the correlation coefficient
correlation = df['typhus'].corr(df['smallpox'])

print(f"Final Answer: {correlation:.3f}")
```
