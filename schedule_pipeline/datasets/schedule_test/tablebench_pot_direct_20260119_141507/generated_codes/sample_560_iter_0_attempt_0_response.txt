Step 1: The user wants the average number of appearances (apps) per year for Castleford Tigers from 2005 to 2009.  
Step 2: Filter the data to include only years from 2005 to 2009 (excluding the "total" row).  
Step 3: Extract the 'apps' column for those years.  
Step 4: Calculate the mean of the 'apps' values and print it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows for years 2005 to 2009 (exclude the total row)
filtered_df = df[df['year'].between(2005, 2009)]
# Calculate the average number of appearances
avg_apps = filtered_df['apps'].mean()
print(f"Final Answer: {avg_apps:.1f}")
```
