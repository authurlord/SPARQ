The error occurred because the "Political Rights" column contains string values (like '6', '7') that need to be converted to numeric before performing calculations. Additionally, we are only analyzing data from 1975 to 1990, so we must filter the rows accordingly.

Step-by-step approach:
1. Load the dataframe.
2. Convert the "Political Rights" column to numeric (to handle string values).
3. Filter rows where the Year is between 1975 and 1990 (inclusive).
4. Compute the standard deviation of the filtered "Political Rights" scores.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Political Rights' to numeric, coercing errors to NaN
df['Political Rights'] = pd.to_numeric(df['Political Rights'], errors='coerce')

# Filter rows from 1975 to 1990 inclusive
filtered_df = df[(df['Year'] >= 1975) & (df['Year'] <= 1990)]

# Calculate standard deviation of Political Rights in the filtered range
std_political_rights = filtered_df['Political Rights'].std()

print(f"Final Answer: {std_political_rights:.1f}")
```
