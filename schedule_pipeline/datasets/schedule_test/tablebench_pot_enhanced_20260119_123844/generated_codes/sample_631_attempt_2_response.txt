Step 1: The user wants the difference in enrollment between the institution with the highest enrollment and the lowest enrollment.
Step 2: Load the dataframe.
Step 3: Select the 'enrollment' column, convert it to integers.
Step 4: Find the maximum and minimum values of enrollment.
Step 5: Calculate the difference and print.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'enrollment' column to integers
df['enrollment'] = pd.to_numeric(df['enrollment'])
# Find max and min enrollment
max_enrollment = df['enrollment'].max()
min_enrollment = df['enrollment'].min()
# Calculate difference
difference = max_enrollment - min_enrollment
print(f"Final Answer: {difference}")
```
