Step 1: The user wants to count how many mountains are located in Austria.
Step 2: Load the dataframe.
Step 3: Filter rows where the 'location' column contains 'austria' (case-insensitive).
Step 4: Count the number of such rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Count the number of mountains located in Austria
austria_mountains_count = df[df['location'].str.contains('austria', case=False, na=False)].shape[0]
print(f"Final Answer: {austria_mountains_count}")
```
