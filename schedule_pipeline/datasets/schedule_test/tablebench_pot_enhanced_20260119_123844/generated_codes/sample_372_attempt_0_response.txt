Step 1: The user wants to count how many cost categories have a percentage increase greater than 5% from 2017 to 2018.
Step 2: Load the dataframe.
Step 3: Convert the 'Percent Increase (Decrease)' column to numeric, handling negative values and 'nm' (not meaningful) entries.
Step 4: Filter rows where the percentage increase is greater than 5.
Step 5: Count the number of such rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Percent Increase (Decrease)' to numeric, coercing errors to NaN
df['Percent Increase (Decrease) (In cents, except percentage changes)'] = pd.to_numeric(df['Percent Increase (Decrease) (In cents, except percentage changes)'], errors='coerce')
# Filter rows where percentage increase > 5
high_increase = df[df['Percent Increase (Decrease) (In cents, except percentage changes)'] > 5]
count = len(high_increase)
print(f"Final Answer: {count}")
```
