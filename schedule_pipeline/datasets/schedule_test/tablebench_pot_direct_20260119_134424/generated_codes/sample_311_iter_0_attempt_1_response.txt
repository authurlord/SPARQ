Step 1: The user wants to identify the player who won both men's singles and men's doubles titles in the same year.
Step 2: Load the dataframe.
Step 3: Iterate through each row and check if the men's singles winner is also part of the men's doubles winners.
Step 4: Extract the year and the player's name when a match is found.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Initialize variables to store result
result_year = None
result_player = None

# Iterate through each row
for index, row in df.iterrows():
    men_singles = row["men 's singles"]
    men_doubles = row["men 's doubles"]
    
    # Check if men's singles winner is in men's doubles winners
    if men_singles in men_doubles:
        result_year = row['year']
        result_player = men_singles
        break

print(f"Final Answer: {result_player}, {result_year}")
```
