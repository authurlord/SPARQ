Step 1: The user wants to find the year where the number of tropical storms increased the most compared to the previous year. This requires calculating the year-over-year difference in the number of tropical storms and identifying the maximum increase.

Step 2: Load the dataframe and extract the "number of tropical storms" column.

Step 3: Compute the differences between consecutive years (i.e., current year - previous year) and find the year with the maximum increase.

Step 4: Since the data starts from 1860, we compare from 1861 onwards (no previous year for 1860).

Step 5: Return the year with the largest increase.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'year' to integer and 'number of tropical storms' to integer
df['year'] = pd.to_numeric(df['year'], errors='coerce')
df['number of tropical storms'] = pd.to_numeric(df['number of tropical storms'], errors='coerce')

# Sort by year
df = df.sort_values('year').reset_index(drop=True)

# Calculate year-over-year increase in tropical storms
df['increase'] = df['number of tropical storms'].diff()

# Find the year with the maximum increase (skip the first row since it has no previous year)
max_increase_row = df[df['increase'] == df['increase'].max()]
year_with_max_increase = max_increase_row.iloc[0]['year']

print(f"Final Answer: {year_with_max_increase}")
```
