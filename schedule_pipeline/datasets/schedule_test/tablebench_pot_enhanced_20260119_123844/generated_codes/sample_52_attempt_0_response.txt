Step 1: The user wants to find the nation that has won exactly 5 gold medals and 2 silver medals.
Step 2: Load the dataframe.
Step 3: Filter the rows where 'Gold' is 5 and 'Silver' is 2.
Step 4: Extract the 'Nation' column value from the filtered row and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where Gold is 5 and Silver is 2
result = df[(df['Gold'] == '5') & (df['Silver'] == '2')]
# Extract the nation name
nation = result['Nation'].values[0]
print(f"Final Answer: {nation}")
```
