The error occurred because the 'dp / da' values are stored as strings (e.g., '-', '1') and cannot be directly subtracted. We need to convert only the numeric values to integers and skip or handle missing values (like '-') before performing the subtraction.

Step 1: Identify the rows for the 2004 election and 1999 election.
Step 2: Extract the 'dp / da' values for these rows, converting them to integers (ignoring '-' as invalid).
Step 3: Compute the difference between the two values.
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Find the 'dp / da' values for 2004 election and 1999 election
row_2004 = df[df['event'] == '2004 election']
row_1999 = df[df['event'] == '1999 election']

# Extract 'dp / da' values and convert to int, ignoring '-'
dp_da_2004 = int(row_2004['dp / da'].values[0]) if row_2004['dp / da'].values[0] != '-' else 0
dp_da_1999 = int(row_1999['dp / da'].values[0]) if row_1999['dp / da'].values[0] != '-' else 0

# Calculate the difference
difference = dp_da_2004 - dp_da_1999
print(f"Final Answer: {difference}")
```
