Step 1: The user wants the percentage change in 'l (mh / km)' when frequency increases from 1 to 100k Hz.  
Step 2: Load the dataframe.  
Step 3: Extract the 'l (mh / km)' values for frequency 1 and 100k.  
Step 4: Compute the percentage change using the formula: ((new - old) / old) * 100.  
Step 5: Print the result.

Note: The "ratio of g to c remains constant" is a red herring here because the question only asks for the percentage change in 'l' based on the given data, which already includes the effect of frequency. We proceed with direct computation.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Extract l values at frequency 1 and 100k
l_at_1 = df[df['frequency (hz)'] == '1']['l (mh / km)'].values[0]
l_at_100k = df[df['frequency (hz)'] == '100k']['l (mh / km)'].values[0]

# Convert to float
l_at_1 = float(l_at_1)
l_at_100k = float(l_at_100k)

# Calculate percentage change
percentage_change = ((l_at_100k - l_at_1) / l_at_1) * 100

print(f"Final Answer: {percentage_change:.2f}")
```
