Step 1: Identify the relevant column for the 400m event and personal best time. The "Event" column indicates the event, and the "Notes" column contains the time. We are looking for rows where "Event" is "400 m" and then find the best (minimum) time among those.

Step 2: Filter the data to include only rows where the "Event" is "400 m".

Step 3: Among those rows, find the one with the smallest time (personal best).

Step 4: Extract the "Year" corresponding to that row.

Step 5: Print the year.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where Event is '400 m'
filtered_df = df[df['Event'] == '400 m']
# Convert 'Notes' to float to extract times and find the minimum
times = filtered_df['Notes'].astype(float)
# Get the row with the minimum time
best_time_row = filtered_df.iloc[times.idxmin()]
# Extract the year from the row
year = best_time_row['Year']
print(f"Final Answer: {year}")
```
