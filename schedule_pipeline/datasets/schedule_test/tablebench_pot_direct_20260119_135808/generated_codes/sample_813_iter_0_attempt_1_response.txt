Step 1: The user wants to find the party with the highest percentage increase in seats from the First Duma to the Fourth Duma.
Step 2: Load the dataframe.
Step 3: For each party, extract the number of seats in the First Duma and Fourth Duma.
Step 4: Calculate the percentage increase using the formula: ((Fourth Duma - First Duma) / First Duma) * 100.
Step 5: Identify the party with the maximum percentage increase.
Step 6: Print the party name.

Note: Some values are missing (e.g., '–'), so we need to handle them by converting to NaN and skipping such entries.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert 'First Duma' and 'Fourth Duma' columns to numeric, handling '–' as NaN
df['First Duma'] = pd.to_numeric(df['First Duma'].str.split(' ').str[0], errors='coerce')
df['Fourth Duma'] = pd.to_numeric(df['Fourth Duma'].str.split(' ').str[0], errors='coerce')

# Drop the 'TOTAL' row since it's a summary
df = df[df['Party'] != 'TOTAL']

# Calculate percentage increase
df['Percentage Increase'] = ((df['Fourth Duma'] - df['First Duma']) / df['First Duma']) * 100

# Find the party with the highest percentage increase
max_increase_party = df.loc[df['Percentage Increase'].idxmax()]['Party']

print(f"Final Answer: {max_increase_party}")
```
