Step 1: The user is asking for a forecast of points for Suzuki in the 50cc and 125cc classes from 1961 to 1967. Since this is a time series with limited data, we can analyze trends by calculating the average points per year for each class.
Step 2: Filter data for Suzuki in the 50cc and 125cc classes.
Step 3: Compute the average points for each class.
Step 4: Use the average as a simple forecast for future performance.
Step 5: Output the forecasted points for both classes.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter data for Suzuki in 50cc and 125cc classes
suzuki_50cc = df[(df['team'] == 'suzuki') & (df['class'] == '50cc')]
suzuki_125cc = df[(df['team'] == 'suzuki') & (df['class'] == '125cc')]

# Calculate average points for each class
avg_points_50cc = suzuki_50cc['points'].mean()
avg_points_125cc = suzuki_125cc['points'].mean()

print(f"Final Answer: {avg_points_50cc:.1f}, {avg_points_125cc:.1f}")
```
