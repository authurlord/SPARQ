Step 1: The user wants the average annual increase in points for the 'honda' team in the '125cc' class from 1994 to 1998.  
Step 2: Filter the data to include only rows where team is 'honda' and class is '125cc'.  
Step 3: Extract the points for years 1994 to 1998.  
Step 4: Compute the annual increase (difference in points per year) and then calculate the average of these increases.  

Note: Since the data only includes 1994–1998, we can compute the differences between consecutive years and take the mean.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows for Honda in 125cc class
filtered_df = df[(df['team'] == 'honda') & (df['class'] == '125cc')]

# Extract points and years
points = filtered_df['points'].astype(int)
years = pd.to_numeric(filtered_df['year'])

# Compute annual increase between consecutive years
differences = []
for i in range(1, len(years)):
    diff = points.iloc[i] - points.iloc[i-1]
    differences.append(diff)

# Calculate average annual increase
avg_increase = sum(differences) / len(differences) if differences else 0
print(f"Final Answer: {avg_increase:.1f}")
```
