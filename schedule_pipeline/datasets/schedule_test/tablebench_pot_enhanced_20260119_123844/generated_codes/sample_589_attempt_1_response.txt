Step 1: The user wants the total number of children from marriages that took place in 1846.
Step 2: Load the dataframe.
Step 3: Filter rows where 'year of marriage' is '1846'.
Step 4: Sum the 'of children' column for these rows.
Step 5: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where year of marriage is 1846
marriages_1846 = df[df['year of marriage'] == '1846']
# Sum the number of children
total_children = marriages_1846['of children'].sum()
print(f"Final Answer: {total_children}")
```
