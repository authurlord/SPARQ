Step 1: The user wants the total number of years that all ambassadors served.  
Step 2: Load the dataframe.  
Step 3: Convert 'Start' and 'End' columns to integers.  
Step 4: Calculate the difference between 'End' and 'Start' for each ambassador.  
Step 5: Sum all the differences to get the total years served.  
Step 6: Print the total.

Note: The "Chargé d'Affaires" roles are not counted since the question asks only for ambassadors.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter only rows where Title is 'Ambassador'
ambassadors = df[df['Title'] == 'Ambassador']
# Convert Start and End to integers
ambassadors['Start'] = ambassadors['Start'].astype(int)
ambassadors['End'] = ambassadors['End'].astype(int)
# Calculate years served for each ambassador
ambassadors['Years'] = ambassadors['End'] - ambassadors['Start']
# Sum total years served
total_years = ambassadors['Years'].sum()
print(f"Final Answer: {total_years}")
```
