Step 1: The user wants to calculate the average number of points received by the singers.  
Step 2: Load the dataframe.  
Step 3: Select the 'points' column, which contains the points values.  
Step 4: Compute the mean of the 'points' column and print the result.  

```python

df = pd.read_csv('table.csv')
```
