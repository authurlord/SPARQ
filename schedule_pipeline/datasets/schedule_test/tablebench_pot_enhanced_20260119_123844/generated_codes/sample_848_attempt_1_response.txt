Step 1: The user wants the difference in elevation between the highest and lowest mountains in the dataset.
Step 2: Load the dataframe.
Step 3: Convert the 'elevation (m)' column to numeric type since it's stored as strings.
Step 4: Find the maximum and minimum values of the elevation column.
Step 5: Calculate the difference and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'elevation (m)' column to numeric
df['elevation (m)'] = pd.to_numeric(df['elevation (m)'])
# Calculate the difference between max and min elevation
elevation_diff = df['elevation (m)'].max() - df['elevation (m)'].min()
print(f"Final Answer: {elevation_diff}")
```
