Step 1: Filter the data to include only mountain peaks in Morocco with elevation ≥ 3000 meters and col > 1500 meters.
Step 2: Extract the 'prominence (m)' values for the filtered rows.
Step 3: Calculate the average of these prominence values.
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for Morocco, elevation >= 3000, and col > 1500
filtered_df = df[(df['country'] == 'morocco') & 
                 (df['elevation (m)'].astype(int) >= 3000) & 
                 (df['col (m)'].astype(int) > 1500)]
# Calculate average prominence
avg_prominence = filtered_df['prominence (m)'].astype(int).mean()
print(f"Final Answer: {avg_prominence:.1f}")
```
