Step 1: The user wants a horizontal bar chart showing the tonnage of sunken ships.  
Step 2: Load the dataframe.  
Step 3: Filter the rows where 'Fate' is 'Sunk' (since only sunken ships are of interest).  
Step 4: Extract the 'Tonnage (GRT)' column and convert it to numeric.  
Step 5: Create a horizontal bar chart using matplotlib, with ship names on the x-axis and tonnage on the y-axis.  

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')
# Filter only sunken ships
sunken_ships = df[df['Fate'] == 'Sunk']
# Convert tonnage to numeric
sunken_ships['Tonnage (GRT)'] = pd.to_numeric(sunken_ships['Tonnage (GRT)'], errors='coerce')
# Drop any rows with invalid tonnage
sunken_ships = sunken_ships.dropna(subset=['Tonnage (GRT)'])

# Create horizontal bar chart
plt.figure(figsize=(10, 6))
plt.barh(sunken_ships['Name'], sunken_ships['Tonnage (GRT)'], color='steelblue')
plt.xlabel('Tonnage (GRT)')
plt.title('Tonnage of Sunken Ships')
plt.gca().invert_yaxis()  # Invert so highest tonnage is at top
plt.tight_layout()
plt.show()
```
