Step 1: The user wants the average size in cents of intervals whose just ratio involves the number 11.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'just ratio' column contains '11' (e.g., '11:8', '14:11', '11:9', etc.).  
Step 4: Convert the 'size (cents)' column to numeric and calculate the mean.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where 'just ratio' contains '11'
filtered_df = df[df['just ratio'].str.contains('11', na=False)]
# Convert 'size (cents)' to float and calculate mean
average_size_cents = filtered_df['size (cents)'].astype(float).mean()
print(f"Final Answer: {average_size_cents:.2f}")
```
