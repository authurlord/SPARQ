Step-by-step approach:
1. Load the DataFrame.
2. Identify the first 5 episodes by sorting by "no in series" (which is numeric).
3. Extract the "viewers (millions)" for those episodes.
4. Compute the average of these viewers.

Note: The "no in series" column contains strings like '25', '26', etc., but they are actually numeric. We can safely convert them to integers and sort.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Sort by 'no in series' to get the first 5 episodes
df_sorted = df.sort_values(by='no in series').head(5)
# Calculate the average viewers for these 5 episodes
average_viewers = df_sorted['viewers (millions)'].mean()
```
