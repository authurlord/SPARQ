Step 1: Filter the warships built before 1870 (i.e., built year < 1870).
Step 2: Extract the 'horse-power' column for these warships.
Step 3: Convert 'horse-power' to numeric type and calculate the standard deviation.
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter warships built before 1870
df_before_1870 = df[df['built year'] < 1870]
# Convert 'horse-power' to numeric and calculate standard deviation
std_hp = pd.to_numeric(df_before_1870['horse - power']).std()
print(f"Final Answer: {std_hp:.2f}")
```
