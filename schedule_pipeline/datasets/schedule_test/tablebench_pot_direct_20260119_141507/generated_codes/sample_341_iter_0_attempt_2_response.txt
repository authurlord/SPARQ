Step 1: The user is asking for the year when the athlete won a gold medal in the 400m event at the CARIFTA Games (U-20) with a personal best (PB) time.  
Step 2: Look through the "Event" column to find entries where the event is "400 m" and the competition is "CARIFTA Games (U-20)".  
Step 3: Check the "Notes" column for "PB" (personal best) to confirm it was a personal best.  
Step 4: Extract the corresponding "Year" from those rows.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where Event is '400 m' and Competition is 'CARIFTA Games (U-20)'
filtered_df = df[(df['Event'] == '400 m') & (df['Competition'] == 'CARIFTA Games (U-20)')]
# Further filter where Notes contains 'PB' (personal best)
pb_filtered = filtered_df[filtered_df['Notes'].str.contains('PB', case=False)]
# Extract the Year
year = pb_filtered.iloc[0]['Year'] if not pb_filtered.empty else None
print(f"Final Answer: {year}")
```
