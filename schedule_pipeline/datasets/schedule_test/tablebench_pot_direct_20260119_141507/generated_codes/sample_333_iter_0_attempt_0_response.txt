Step 1: The user wants to find the year when the athlete achieved their highest ranking in the Javelin throw event at the Olympic Games.  
Step 2: Filter the data to include only rows where the Event is "Javelin throw" and the Competition is "Olympic Games".  
Step 3: Among those rows, identify the one with the highest (i.e., lowest number) Position value.  
Step 4: Extract the Year from that row.  

Note: In sports rankings, a lower position number means a better rank. So, "1st" is better than "21st", etc.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for Olympic Games and Javelin throw events
olympic_javelin = df[(df['Competition'] == 'Olympic Games') & (df['Event'] == 'Javelin throw')]
# Find the row with the best (lowest) position
best_ranking = olympic_javelin.loc[olympic_javelin['Position'].idxmin()]
print(f"Final Answer: {best_ranking['Year']}")
```
