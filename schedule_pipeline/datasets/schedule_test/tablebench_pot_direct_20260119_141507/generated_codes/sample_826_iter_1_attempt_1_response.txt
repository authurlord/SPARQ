The error occurred because the "total" column contains string values (e.g., '10', '11') instead of numeric values. We need to convert the "total" column to numeric before computing the standard deviation.

Step-by-step approach:
1. Load the dataframe.
2. Convert the "total" column to numeric (to handle string values like '10').
3. Compute the standard deviation of the "total" column.
4. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'total' column to numeric, coercing errors to NaN if any (though all should be valid)
df['total'] = pd.to_numeric(df['total'], errors='coerce')
# Calculate standard deviation of the total points
std_total = df['total'].std()
print(f"Final Answer: {std_total:.1f}")
```
