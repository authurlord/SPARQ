Step 1: The user wants to identify the year with the highest crude birth rate per 1000.
Step 2: Load the dataframe.
Step 3: Convert the 'Crude birth rate (per 1000)' column to numeric, handling any formatting issues (like spaces in numbers).
Step 4: Find the row with the maximum value in this column.
Step 5: Extract and return the corresponding year.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Crude birth rate (per 1000)' to numeric, handling any non-numeric values like '1 104'
df['Crude birth rate (per 1000)'] = pd.to_numeric(df['Crude birth rate (per 1000)'], errors='coerce')
# Find the year with the maximum crude birth rate
max_year = df.loc[df['Crude birth rate (per 1000)'].idxmax(), 'Unnamed: 0']
print(f"Final Answer: {max_year}")
```
