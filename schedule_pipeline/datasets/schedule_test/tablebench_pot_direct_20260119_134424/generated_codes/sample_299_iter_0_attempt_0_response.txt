Step 1: The user wants to find the year when the athlete achieved their best position in the 800m event at the World Championships.  
Step 2: Filter the data to only include rows where the 'Competition' is 'World Championships' and the 'Event' is '800 m'.  
Step 3: Among these filtered rows, identify the row with the best (lowest) position (e.g., 1st is better than 2nd).  
Step 4: Extract the 'Year' corresponding to that best position.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for World Championships and 800m event
world_champs_800m = df[(df['Competition'] == 'World Championships') & (df['Event'] == '800 m')]
# Find the best position (lowest numerical value)
best_position_row = world_champs_800m.loc[world_champs_800m['Position'].str.replace('th', '').astype(int).idxmin()]
best_year = best_position_row['Year']
print(f"Final Answer: {best_year}")
```
