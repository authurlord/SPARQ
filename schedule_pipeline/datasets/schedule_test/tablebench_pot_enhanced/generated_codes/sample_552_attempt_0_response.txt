Step 1: The user wants the average number of Indians admitted per year from 2000 to 2010 (inclusive).
Step 2: Load the dataframe.
Step 3: Filter rows where 'year' is between '2000' and '2010'.
Step 4: Convert the 'indians admitted' column to numeric and calculate the mean.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for years 2000 to 2010
df_filtered = df[df['year'].between('2000', '2010')]
# Convert 'indians admitted' to numeric and calculate average
avg_indians = df_filtered['indians admitted'].astype(int).mean()
print(f"Final Answer: {avg_indians:.1f}")
```
