Step 1: The user wants the average US chart position of all songs.
Step 2: Load the dataframe.
Step 3: Select the 'US Chart position' column.
Step 4: Convert the values to numeric, handling any non-numeric entries (like '17 (R&B)') by removing the text part and keeping only the number.
Step 5: Calculate the mean of the cleaned numeric values.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Clean the 'US Chart position' column by extracting numeric values
df['US Chart position'] = df['US Chart position'].astype(str).str.extract('(\d+)').astype(float)
# Calculate the average
avg_chart_position = df['US Chart position'].mean()
print(f"Final Answer: {avg_chart_position:.1f}")
```
