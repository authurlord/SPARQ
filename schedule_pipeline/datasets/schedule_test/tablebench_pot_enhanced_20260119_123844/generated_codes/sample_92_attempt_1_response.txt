Step 1: The user wants to find the season when the skier achieved a giant slalom score of 7.
Step 2: Load the dataframe.
Step 3: Filter the rows where the 'giant slalom' column equals '7'.
Step 4: Extract the corresponding 'season' value and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where 'giant slalom' is '7'
result = df[df['giant slalom'] == '7']['season']
print(f"Final Answer: {result.iloc[0]}")
```
