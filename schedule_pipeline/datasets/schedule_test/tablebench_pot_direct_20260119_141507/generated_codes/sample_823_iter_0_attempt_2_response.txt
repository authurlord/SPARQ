Step 1: The user wants the median population density of EU member states.
Step 2: Load the dataframe.
Step 3: Select the 'pop density people / km 2' column, excluding the 'European Union' row (as it represents the total, not individual member state data).
Step 4: Calculate the median of the selected values and print it.

Note: The first row is "European Union" with population density 112.0, which is aggregate, not a member state. We exclude it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter out the 'European Union' row to get only member states
df_member_states = df[df['member state'] != 'european union']
# Extract the 'pop density people / km 2' column
pop_density = df_member_states['pop density people / km 2'].astype(float)
# Calculate the median
median_density = pop_density.median()
print(f"Final Answer: {median_density:.1f}")
```
