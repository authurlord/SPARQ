The error occurred because the 'points' column contains string values (like '27', '3', '11') that need to be converted to numeric before computing the average. We must ensure proper type conversion to avoid parsing errors.

Step-by-step approach:
1. Load the dataframe.
2. Convert the 'points' column from string to numeric (handling any potential parsing issues).
3. Calculate the mean of the numeric 'points' column.
4. Print the result with appropriate formatting.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'points' column to numeric, coercing errors to NaN and then dropping invalid entries
df['points'] = pd.to_numeric(df['points'], errors='coerce')
# Calculate the mean of valid points
mean_points = df['points'].mean()
print(f"Final Answer: {mean_points:.1f}")
```
