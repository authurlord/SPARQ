Step 1: The user wants the average score of Francisco Bravo Medical Magnet High School from 2007 to 2011.  
Step 2: Load the dataframe.  
Step 3: Filter the row corresponding to "Francisco Bravo Medical Magnet High School".  
Step 4: Extract the values for the years 2007 to 2011 (as strings or numbers).  
Step 5: Convert the values to numeric and compute the mean.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for Francisco Bravo Medical Magnet High School
school_data = df[df['School'] == 'Francisco Bravo Medical Magnet High School']
# Extract the scores for the years 2007 to 2011
scores = school_data[['2007', '2008', '2009', '2010', '2011']].apply(pd.to_numeric, errors='coerce')
# Drop NaN values if any and calculate mean
mean_score = scores.mean().mean()
print(f"Final Answer: {mean_score:.1f}")
```
