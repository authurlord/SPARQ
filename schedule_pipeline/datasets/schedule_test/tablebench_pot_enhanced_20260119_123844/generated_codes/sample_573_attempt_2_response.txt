Step 1: Filter the buildings constructed between 1960 and 1980 (inclusive).
Step 2: Extract the 'floors' column for these buildings.
Step 3: Calculate the average number of floors.
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where year is between 1960 and 1980 (inclusive)
filtered_df = df[(df['year'].astype(int) >= 1960) & (df['year'].astype(int) <= 1980)]
# Calculate the average number of floors
average_floors = filtered_df['floors'].astype(int).mean()
print(f"Final Answer: {average_floors:.1f}")
```
