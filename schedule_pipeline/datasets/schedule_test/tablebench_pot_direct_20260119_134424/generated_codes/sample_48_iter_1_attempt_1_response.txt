Step 1: The user wants to calculate the average number of points received by singers in the competition.
Step 2: Load the dataframe.
Step 3: Select the 'points' column and convert it to numeric, handling any potential non-numeric values.
Step 4: Calculate the mean of the 'points' column and print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'points' column to numeric, coercing errors to NaN
df['points'] = pd.to_numeric(df['points'], errors='coerce')
# Calculate the mean of the 'points' column, ignoring NaN values
average_points = df['points'].mean()
print(f"Final Answer: {average_points:.1f}")
```
