Step 1: The user wants the correlation coefficient between the number of typhus cases and smallpox cases over the years.  
Step 2: Load the dataframe.  
Step 3: Extract the 'typhus' and 'smallpox' columns.  
Step 4: Compute the Pearson correlation coefficient between these two columns.  
Step 5: Print the correlation coefficient.

Note: The data contains an outlier in 191822 where smallpox is given as "106" and typhus as "1300", which may be a typo (likely meant to be a year range). However, since the question is about correlation over years, we proceed with the available numerical values, treating it as valid data.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the 'typhus' and 'smallpox' columns
typhus_cases = df['typhus']
smallpox_cases = df['smallpox']

# Calculate the correlation coefficient
correlation_coefficient = typhus_cases.corr(smallpox_cases)
print(f"Final Answer: {correlation_coefficient:.2f}")
```
