Step 1: The user wants to count the number of parties that have more than 10% of the total votes.
Step 2: Load the dataframe.
Step 3: Convert the '%', column to float for comparison.
Step 4: Filter rows where '%' > 10.
Step 5: Count the number of such parties and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert '%' column to float for numerical comparison
df['%'] = pd.to_numeric(df['%'])
# Count parties with more than 10% votes
count_parties = (df['%'] > 10).sum()
print(f"Final Answer: {count_parties}")
```
