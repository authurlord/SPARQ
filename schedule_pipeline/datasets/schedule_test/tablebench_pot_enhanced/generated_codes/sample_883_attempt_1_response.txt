Step 1: The user wants to identify the country with the highest percentage of AIDS-related orphans as a percentage of total orphans in 2001 and compare it to Uganda's percentage in the same year.

Step 2: Filter the data for the year 2001 (rows where the country ends with "(2001)").

Step 3: Extract the 'aids orphans as % of orphans' column for these rows.

Step 4: Find the maximum value and the corresponding country.

Step 5: Retrieve Uganda's value for comparison.

Step 6: Print both values in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for year 2001
df_2001 = df[df['country'].str.endswith('(2001)')]

# Find the country with the highest percentage of AIDS-related orphans
max_country = df_2001.loc[df_2001['aids orphans as % of orphans'].idxmax()]
highest_percentage = max_country['aids orphans as % of orphans']
uganda_2001 = df_2001[df_2001['country'] == 'uganda (2001)']['aids orphans as % of orphans'].values[0]

print(f"Final Answer: {highest_percentage}, {uganda_2001}")
```
