Step 1: The user wants a forecast for the pass percentage and obtained GPA metric for the year 2011 based on the trend from 2005 to 2010.  
Step 2: Load the dataframe.  
Step 3: Extract the 'pass percentage' and 'obtained gpa - 5' columns, converting them to numeric values (removing % sign and handling as float).  
Step 4: Fit a linear trend (simple linear regression) to predict values for 2011.  
Step 5: Use the fitted model to predict the pass percentage and GPA for 2011.  
Step 6: Output the predicted values.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Convert 'pass percentage' to numeric by removing '%' and converting to float
df['pass percentage'] = df['pass percentage'].str.replace('%', '').astype(float)

# Ensure 'obtained gpa - 5' is numeric
df['obtained gpa - 5'] = pd.to_numeric(df['obtained gpa - 5'])

# Prepare x (year) and y (metrics)
x = df['year'].astype(int)
y_pass = df['pass percentage']
y_gpa = df['obtained gpa - 5']

# Fit linear models
coeff_pass = np.polyfit(x, y_pass, 1)
coeff_gpa = np.polyfit(x, y_gpa, 1)

# Predict for 2011
year_2011 = 2011
predicted_pass = np.polyval(coeff_pass, year_2011)
predicted_gpa = np.polyval(coeff_gpa, year_2011)

print(f"Final Answer: {predicted_pass:.2f}, {predicted_gpa:.2f}")
```
