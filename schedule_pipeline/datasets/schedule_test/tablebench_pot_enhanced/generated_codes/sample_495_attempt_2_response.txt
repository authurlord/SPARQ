Step 1: The user wants to find the airport with the highest capacity utilization rate. The "capacity in use" column contains the utilization rate as a percentage (e.g., "126,06%"), so we need to parse and convert it to a numeric value.
Step 2: Load the dataframe.
Step 3: Clean the "capacity in use" column by removing commas and converting it to a float.
Step 4: Find the row with the maximum "capacity in use" value.
Step 5: Extract the corresponding location (airport name) and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Clean the 'capacity in use' column by removing commas and converting to float
df['capacity in use'] = df['capacity in use'].str.replace(',', '').astype(float)
# Find the airport with the highest capacity utilization rate
max_utilization_airport = df.loc[df['capacity in use'].idxmax(), 'location']
print(f"Final Answer: {max_utilization_airport}")
```
