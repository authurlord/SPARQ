Step 1: The user wants to find the episode with the highest number of viewers.
Step 2: Load the dataframe.
Step 3: Convert the 'viewers' column to numeric (it's currently stored as string).
Step 4: Find the row with the maximum value in the 'viewers' column.
Step 5: Extract the 'title' of that episode and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'viewers' column to numeric
df['viewers'] = pd.to_numeric(df['viewers'], errors='coerce')
# Find the episode with the highest viewership
max_viewers_episode = df.loc[df['viewers'].idxmax()]
print(f"Final Answer: {max_viewers_episode['title']}")
```
