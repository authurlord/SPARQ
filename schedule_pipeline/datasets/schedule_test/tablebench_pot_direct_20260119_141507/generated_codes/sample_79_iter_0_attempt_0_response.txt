Step 1: The user wants to identify the team that is in 3rd position in the league.  
Step 2: The 'position' column indicates the ranking of teams, with '3' corresponding to the 3rd place.  
Step 3: Find the row where 'position' is '3' and extract the corresponding 'team' name.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the team in 3rd position
third_place_team = df[df['position'] == '3']['team'].values[0]
print(f"Final Answer: {third_place_team}")
```
