Step 1: The user wants the average magnitude of earthquakes that meet two conditions:
- Death toll ≥ 1,000
- Depth < 30 km

Step 2: Load the dataframe.

Step 3: Filter rows where:
- Death toll is at least 1,000 (convert string to integer)
- Depth is less than 30 km

Step 4: Compute the mean of the "Magnitude" column for the filtered rows.

Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert 'Death toll' to numeric and filter based on conditions
df['Death toll'] = pd.to_numeric(df['Death toll'], errors='coerce')
filtered_df = df[(df['Death toll'] >= 1000) & (df['Depth (km)'].astype(float) < 30)]

# Calculate average magnitude of filtered rows
if not filtered_df.empty:
    avg_magnitude = filtered_df['Magnitude'].mean()
else:
    avg_magnitude = None

print(f"Final Answer: {avg_magnitude:.1f}")
```
