We need to filter out rows where the language is not "French", then extract the "points" column and compute the median.

Step-by-step approach:
1. Load the dataframe.
2. Filter rows where the 'language' is not "French".
3. Extract the 'points' column from the filtered data.
4. Convert the points to numeric (handling any missing or non-numeric values).
5. Compute the median of the filtered points.
6. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where language is not French
non_french_points = df[df['language'] != 'french']['points']
# Convert to numeric, coercing errors to NaN, then drop NaN
non_french_points_numeric = pd.to_numeric(non_french_points, errors='coerce')
# Drop NaN values and compute median
median_points = non_french_points_numeric.dropna().median()
print(f"Final Answer: {median_points}")
```
