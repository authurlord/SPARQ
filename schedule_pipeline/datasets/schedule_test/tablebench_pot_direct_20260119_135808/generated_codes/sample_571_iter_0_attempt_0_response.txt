Step 1: Filter the data for the 'all around' event in both 'olympic trials' and 'us championships' during 2008.
Step 2: Extract the qualifying scores for these two competitions.
Step 3: Calculate the difference (change) between the qualifying scores.
Step 4: Print the result as the average change.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter data for 'all around' event in 'olympic trials' and 'us championships'
olympic_trials = df[(df['event'] == 'all around') & (df['competition'] == 'olympic trials')]
us_championships = df[(df['event'] == 'all around') & (df['competition'] == 'us championships')]

# Extract qualifying scores
qualifying_score_olympic_trials = olympic_trials['qualifying score'].values[0]
qualifying_score_us_championships = us_championships['qualifying score'].values[0]

# Calculate the change
change = float(qualifying_score_us_championships) - float(qualifying_score_olympic_trials)

print(f"Final Answer: {change:.1f}")
```
