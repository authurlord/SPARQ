Step 1: The user wants the percentage change in 'l (mh / km)' when frequency increases from 1 Hz to 100 kHz.  
Step 2: Load the dataframe.  
Step 3: Extract the 'l (mh / km)' values at frequency 1 and 100k.  
Step 4: Calculate the percentage change using the formula: ((new - old) / old) * 100.  
Step 5: Print the result.

Note: The assumption about the ratio of 'g' to 'c' remaining constant is not needed for this calculation since we are directly comparing the 'l' values at two frequencies.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract l values at frequency 1 and 100k
l_at_1 = df[df['frequency (hz)'] == '1']['l (mh / km)'].values[0]
l_at_100k = df[df['frequency (hz)'] == '100k']['l (mh / km)'].values[0]

# Calculate percentage change
percentage_change = ((float(l_at_100k) - float(l_at_1)) / float(l_at_1)) * 100
print(f"Final Answer: {percentage_change:.2f}")
```
