Step 1: The user wants to find the year when the athlete achieved their personal best time in the 20 km walk event at the African Championships.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'Competition' is 'African Championships' and the 'Event' is '20 km walk'.  
Step 4: Among these, identify the row with the best (lowest) time. Note that times are in format '1:22:55', so we need to convert them to seconds for comparison.  
Step 5: Extract the 'Year' corresponding to the best time.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for African Championships and 20 km walk
african_championships_20km = df[(df['Competition'] == 'African Championships') & (df['Event'] == '20 km walk')]

# Convert time to seconds for comparison
def time_to_seconds(time_str):
    if pd.isna(time_str) or time_str == 'DNF' or time_str == 'DQ' or time_str == '?':
        return float('inf')
    h, m, s = map(int, time_str.split(':'))
    return h * 3600 + m * 60 + s

african_championships_20km['time_seconds'] = african_championships_20km['Notes'].apply(time_to_seconds)

# Find the row with minimum time
best_time_row = african_championships_20km.loc[african_championships_20km['time_seconds'].idxmin()]

# Get the year
best_year = best_time_row['Year']
print(f"Final Answer: {best_year}")
```
