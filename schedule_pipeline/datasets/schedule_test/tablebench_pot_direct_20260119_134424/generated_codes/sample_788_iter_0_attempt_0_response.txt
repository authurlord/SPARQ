Step 1: The user wants the median elevation of mountain peaks located in Greece.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'country' column contains 'greece' (case-insensitive).  
Step 4: Convert the 'elevation (m)' column to numeric.  
Step 5: Calculate the median of the filtered elevation values.  
Step 6: Print the result.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where country contains 'greece' (case-insensitive)
greece_peaks = df[df['country'].str.lower().str.contains('greece', na=False)]
# Convert elevation to numeric
greece_peaks['elevation (m)'] = pd.to_numeric(greece_peaks['elevation (m)'])
# Calculate median elevation
median_elevation = greece_peaks['elevation (m)'].median()
print(f"Final Answer: {median_elevation}")
```
