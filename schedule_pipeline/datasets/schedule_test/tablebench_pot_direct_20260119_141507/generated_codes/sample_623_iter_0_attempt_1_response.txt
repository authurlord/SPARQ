Step 1: Identify the earthquake with the highest magnitude and the one with the lowest magnitude.  
Step 2: Extract their depth values from the "Depth (km)" column.  
Step 3: Compute the difference between the highest and lowest depth values.  

From the table:
- The highest magnitude is 7.6 (first row).
- The lowest magnitude is 7.0 (rows 12 to 15).

We will find the depth corresponding to the earthquake with magnitude 7.6 and the one with magnitude 7.0, then compute the difference.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Find the depth for the earthquake with highest magnitude (7.6)
max_magnitude_row = df[df['Magnitude'] == '7.6']
depth_max = float(max_magnitude_row['Depth (km)'].iloc[0])

# Find the depth for the earthquake with lowest magnitude (7.0)
min_magnitude_row = df[df['Magnitude'] == '7.0']
depth_min = float(min_magnitude_row['Depth (km)'].iloc[0])

# Calculate the difference
depth_difference = depth_max - depth_min
print(f"Final Answer: {depth_difference:.1f}")
```
