Step 1: The user wants to find the year with the maximum decrease in typhus cases compared to the previous year.
Step 2: Load the dataframe.
Step 3: Convert the 'typhus' column to numeric for calculation.
Step 4: Calculate the year-on-year change in typhus cases.
Step 5: Identify the year with the most negative change (i.e., largest decrease).
Step 6: Return that year.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'typhus' column to numeric
df['typhus'] = pd.to_numeric(df['typhus'], errors='coerce')

# Calculate year-on-year change in typhus cases
df['change'] = df['typhus'].diff()

# Find the year with the maximum decrease (most negative change)
min_change_year = df.loc[df['change'].idxmin(), 'year']

print(f"Final Answer: {min_change_year}")
```
