The error occurred because the "enrollment" column contains string values (e.g., '1042'), not numeric values. We need to convert the enrollment column to numeric before performing arithmetic operations.

Step 1: Load the dataframe.
Step 2: Convert the "enrollment" column to numeric, handling any parsing errors.
Step 3: Find the maximum and minimum enrollment values.
Step 4: Calculate the difference between the highest and lowest enrollment.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert enrollment to numeric, coercing errors to NaN and then dropping invalid entries
df['enrollment'] = pd.to_numeric(df['enrollment'], errors='coerce')
# Remove any rows with NaN enrollment (in case of parsing failure)
df = df.dropna(subset=['enrollment'])
# Find max and min enrollment
max_enrollment = df['enrollment'].max()
min_enrollment = df['enrollment'].min()
difference = max_enrollment - min_enrollment
print(f"Final Answer: {difference}")
```
