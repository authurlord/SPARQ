Step 1: The user wants the total number of 12-inch guns across all ships.  
Step 2: The "12 - inch" column contains the count of 12-inch guns for each ship.  
Step 3: We need to sum the values in the "12 - inch" column, excluding the total row (which is the last row and represents totals).  
Step 4: Since the last row is labeled "total", we will slice the DataFrame to exclude it and sum the relevant column.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Exclude the last row (total row) and sum the '12 - inch' column
total_12_inch_guns = df.iloc[:-1]['12 - inch'].sum()
print(f"Final Answer: {total_12_inch_guns}")
```
