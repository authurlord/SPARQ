The error occurred because the "height" column contains string values (e.g., '46', '48') that need to be converted to numeric before calculating the mean. We must ensure proper type conversion.

Step-by-step approach:
1. Load the dataframe.
2. Filter buildings with more than 10 floors.
3. Convert the "height" column to numeric (to avoid string-to-number errors).
4. Calculate the mean height of the filtered buildings.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'height' to numeric, coercing errors to NaN (though all should be valid)
df['height'] = pd.to_numeric(df['height'], errors='coerce')

# Filter buildings with more than 10 floors
filtered_buildings = df[df['floors'] > 10]

# Calculate mean height of filtered buildings
mean_height = filtered_buildings['height'].mean()
print(f"Final Answer: {mean_height:.1f}")
```
