Step 1: The user wants to find the team that participated in the 'gt1' class and had a co-driver named Peter Kox.
Step 2: Load the dataframe.
Step 3: Filter rows where 'class' is 'gt1' and 'co - drivers' contains 'peter kox'.
Step 4: Extract the 'team' column value from the filtered row and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for 'gt1' class and co-drivers containing 'peter kox'
filtered_df = df[(df['class'] == 'gt1') & (df['co - drivers'].str.contains('peter kox', case=False, na=False))]
# Get the team name
team = filtered_df['team'].values[0]
print(f"Final Answer: {team}")
```
