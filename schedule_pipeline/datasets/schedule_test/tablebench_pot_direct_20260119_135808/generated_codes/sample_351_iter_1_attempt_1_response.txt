Step 1: The user wants to count how many parties have more than 10% of the total votes.
Step 2: Load the dataframe, but skip the last row which contains source information and is not part of the data.
Step 3: Convert the '%', column to float for comparison.
Step 4: Count the number of parties where '%' > 10.
Step 5: Print the result.

```python
import pandas as pd

# Load the data and skip the last row which contains source information
df = pd.read_csv('table.csv')
df = df.iloc[:-1]  # Remove the last row (source info)

# Convert the '%' column to float
df['%'] = pd.to_numeric(df['%'])

# Count parties with more than 10% of votes
count_parties = (df['%'] > 10).sum()

print(f"Final Answer: {count_parties}")
```
