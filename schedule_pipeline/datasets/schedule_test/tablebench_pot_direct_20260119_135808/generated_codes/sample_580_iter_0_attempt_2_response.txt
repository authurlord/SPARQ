Step 1: The user wants to find the year with the maximum increase in the `bötzow` value compared to the previous year.
Step 2: Load the dataframe.
Step 3: Convert the `bötzow` column to float for numerical operations.
Step 4: Calculate the year-on-year difference in `bötzow` values.
Step 5: Identify the year with the maximum increase.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'bötzow' column to float
df['bötzow'] = pd.to_numeric(df['bötzow'])
# Calculate the difference between consecutive years
df['increase'] = df['bötzow'].diff()
# Find the year with the maximum increase
max_increase_year = df.loc[df['increase'].idxmax(), 'year']
print(f"Final Answer: {max_increase_year}")
```
