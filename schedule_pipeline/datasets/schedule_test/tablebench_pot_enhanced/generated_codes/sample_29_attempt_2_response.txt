Step 1: The user wants the total number of films from the years 2012 to 2014.
Step 2: Load the dataframe.
Step 3: Filter rows where the '2011' column (which contains the year) is between 2012 and 2014 inclusive.
Step 4: Select the 'Films' column, convert values to integers (handling potential '+' signs), and sum them.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows for years 2012 to 2014
filtered_df = df[df['-'].isin(['2012', '2013', '2014'])]
# Convert 'Films' column to integers, handling '+' in '700+'
total_films = filtered_df['Films'].str.replace('+', '').astype(int).sum()
print(f"Final Answer: {total_films}")
```
