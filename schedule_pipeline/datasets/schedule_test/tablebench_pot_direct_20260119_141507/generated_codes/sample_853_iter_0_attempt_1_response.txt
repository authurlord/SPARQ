Step 1: The user wants to find the year when the song with the highest US chart position and the year when the song with the lowest US chart position was released.  
Step 2: Extract the 'US Chart position' column and identify the maximum and minimum values along with their corresponding years.  
Step 3: Since "US Chart position" may contain values like "17 (R&B)" or "8 (R&B)", we need to extract only the numeric part for comparison.  
Step 4: Convert the "US Chart position" column to numeric after removing any text (e.g., "(R&B)") and then find the max and min positions.  
Step 5: Get the corresponding years for both the highest and lowest positions.  

Note: The highest US chart position means the smallest number (e.g., position 2 is better than position 10). So we interpret "highest" as the best (lowest number), and "lowest" as the worst (largest number).  

However, the question says: "the song with the highest US chart position" — this is ambiguous. In music charts, a lower number means better position. So "highest" might mean the best (lowest number), and "lowest" means worst (highest number). But the phrasing is odd. Let's interpret it as:
- Highest US chart position → best (lowest number)
- Lowest US chart position → worst (highest number)

So we will:
- Find the year of the song with the best (lowest) US chart position
- Find the year of the song with the worst (highest) US chart position

We'll clean the "US Chart position" column by extracting the numeric value.

```python
import pandas as pd
import re

df = pd.read_csv('table.csv')

# Clean the 'US Chart position' column to extract numeric values
def extract_position(pos):
    match = re.search(r'(\d+)', pos)
    return int(match.group(1)) if match else None

df['cleaned_position'] = df['US Chart position'].apply(extract_position)

# Find the year with the best (lowest) position and worst (highest) position
best_year = df.loc[df['cleaned_position'].idxmin(), 'Year']
worst_year = df.loc[df['cleaned_position'].idxmax(), 'Year']

print(f"Final Answer: {best_year}, {worst_year}")
```
