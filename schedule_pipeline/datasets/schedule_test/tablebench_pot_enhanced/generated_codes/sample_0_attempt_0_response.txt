Step 1: The user wants to calculate the average number of tropical cyclones per season.  
Step 2: Load the dataframe from the provided table.  
Step 3: Extract the 'tropical cyclones' column, which contains the number of tropical cyclones per season.  
Step 4: Compute the mean (average) of the values in this column.  
Step 5: Print the result as the final answer.
