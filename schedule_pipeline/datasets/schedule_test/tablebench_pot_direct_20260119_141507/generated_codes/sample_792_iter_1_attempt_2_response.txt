The error occurred because we are trying to filter rows based on a condition involving strings and integers (e.g., comparing year as string with integer), which is not valid. We need to ensure that the filtering is done correctly by converting the 'Year' column to integers or using proper string comparison.

Step-by-step approach:
1. Load the DataFrame.
2. Convert the 'Year' column to integer type to allow numerical comparisons.
3. Filter rows where the year is between 1975 and 1990 (inclusive).
4. Extract the "Political Rights" scores from the filtered rows.
5. Compute the standard deviation of these scores.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Year' to integer for proper comparison
df['Year'] = pd.to_numeric(df['Year'], errors='coerce')

# Filter rows from 1975 to 1990 inclusive
filtered_df = df[(df['Year'] >= 1975) & (df['Year'] <= 1990)]

# Extract 'Political Rights' scores
political_rights = filtered_df['Political Rights'].dropna()

# Calculate standard deviation
std_dev = political_rights.std()

print(f"Final Answer: {std_dev:.2f}")
```
