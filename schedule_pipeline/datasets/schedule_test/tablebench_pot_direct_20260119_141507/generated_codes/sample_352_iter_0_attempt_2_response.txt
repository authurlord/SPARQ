Step 1: The user wants to count the number of universities located in London.  
Step 2: Load the dataframe.  
Step 3: Filter rows where 'location' is 'london'.  
Step 4: Count the number of such rows and print the result.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Count universities located in London
london_universities = df[df['location'] == 'london'].shape[0]
print(f"Final Answer: {london_universities}")
```
