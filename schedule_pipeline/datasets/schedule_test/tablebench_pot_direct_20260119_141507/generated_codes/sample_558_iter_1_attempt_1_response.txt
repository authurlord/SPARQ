We are asked to calculate the average number of locomotives withdrawn per year from 1935 to 1943.

Step-by-step approach:
1. The data includes a column "Quantity withdrawn" which contains the number of locomotives withdrawn each year.
2. We need to filter the rows for years from 1935 to 1943 inclusive.
3. Extract the "Quantity withdrawn" values for those years.
4. Compute the average of these values.
5. Note: Some entries have text like '—' or numbers with commas (e.g., '1126, 1152, 1338'), but we only care about the quantity withdrawn, not the locomotive numbers.

However, in the given data, the "Quantity withdrawn" column is already numeric (e.g., 1, 3, 1, etc.), and only in a few rows (like 1955 onwards) does it show '—'. But for years 1935–1943, the values are clearly numeric.

But caution: In row 1934, "Quantity withdrawn" is 3; in 1935, it's 1; and so on. All years from 1935 to 1943 have valid numeric values.

So we will:
- Filter rows where Year is between 1935 and 1943 (inclusive).
- Take the "Quantity withdrawn" column.
- Compute the mean.

Note: There is no comma or invalid format in the "Quantity withdrawn" column for these years — all are integers.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter rows from 1935 to 1943 inclusive
filtered_df = df[(df['Year'].astype(str).str.startswith('193')) | 
                  (df['Year'].astype(str).str.startswith('194'))]

# Extract the 'Quantity withdrawn' column and compute the mean
# Convert to numeric safely
withdrawn_values = pd.to_numeric(df['Quantity withdrawn'], errors='coerce')
filtered_withdrawn = withdrawn_values[(df['Year'] >= 1935) & (df['Year'] <= 1943)]

# Compute average
average_withdrawn = filtered_withdrawn.mean()

print(f"Final Answer: {average_withdrawn:.1f}")
```
