Step 1: Filter the warships built before 1870 (i.e., built year < 1870).
Step 2: Extract the 'horse-power' column for these warships.
Step 3: Convert 'horse-power' to numeric type for calculation.
Step 4: Calculate the standard deviation of the horse-power values.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter warships built before 1870
df_before_1870 = df[df['built year'] < 1870]
# Convert 'horse-power' to numeric
df_before_1870['horse-power'] = pd.to_numeric(df_before_1870['horse-power'])
# Calculate standard deviation
std_hp = df_before_1870['horse-power'].std()
print(f"Final Answer: {std_hp:.2f}")
```
