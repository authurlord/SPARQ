Since the years are in string format, we must ensure we only include rows where the year is between '1850' and '1855' inclusive.

Step-by-step approach:
1. Load the dataframe.
2. Filter rows where the year is between '1850' and '1855' (inclusive).
3. Extract the "number of tropical storms" column from the filtered rows.
4. Compute the mean of that column.
5. Print the result.

Note: Since the years are strings, we use string comparison to avoid type errors.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where year is between '1850' and '1855' inclusive
filtered_df = df[(df['year'] >= '1850') & (df['year'] <= '1855')]
# Calculate the average number of tropical storms in the filtered rows
avg_storms = filtered_df['number of tropical storms'].mean()
```
