Step 1: The user wants to find the year with the maximum increase in Conservative councillors compared to the previous year.
Step 2: Load the dataframe.
Step 3: Convert 'Year' to integer and 'Conservative councillors' to integer for numerical operations.
Step 4: Calculate the year-on-year difference in Conservative councillors.
Step 5: Find the year with the maximum increase.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert columns to appropriate types
df['Year'] = df['Year'].astype(int)
df['Conservative councillors'] = df['Conservative councillors'].astype(int)

# Calculate the difference in Conservative councillors from the previous year
df['diff'] = df['Conservative councillors'].diff()

# Find the year with the maximum increase
max_increase_year = df.loc[df['diff'].idxmax(), 'Year']

print(f"Final Answer: {max_increase_year}")
```
