Step 1: The user wants the total number of students at universities located in London.
Step 2: Load the dataframe.
Step 3: Filter rows where 'location' is 'london'.
Step 4: Sum the 'total number of students' column for these rows.
Step 5: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where location is 'london'
london_unis = df[df['location'] == 'london']
# Sum the total number of students for these universities
total_students_london = london_unis['total number of students'].sum()
print(f"Final Answer: {total_students_london}")
```
