Step 1: The user wants to find the airport with the highest capacity utilization rate, which is given in the "capacity in use" column as a percentage (e.g., "126 , 06%").  
Step 2: The "capacity in use" column contains values like "126 , 06%", which have a space or comma as a separator. We need to clean this to extract the numeric value.  
Step 3: Convert the cleaned percentage values into floats and find the row with the maximum value.  
Step 4: Return the location of that row.

Note: The values are formatted as "126 , 06%" — we must remove the space and comma and convert to float.

```python
import pandas as pd
import re

df = pd.read_csv('table.csv')

# Clean the 'capacity in use' column: remove spaces and commas, keep only numbers and %
cleaned = []
for val in df['capacity in use']:
    # Remove space and comma, then extract numbers before %
    cleaned_val = re.sub(r'[ ,%]', '', str(val))
    cleaned.append(float(cleaned_val))

# Create a new series with cleaned values and match to location
df['capacity_in_use_clean'] = cleaned
max_utilization_index = df['capacity_in_use_clean'].idxmax()
highest_utilization_location = df.loc[max_utilization_index, 'location']

print(f"Final Answer: {highest_utilization_location}")
```
