Step 1: The user wants the sum of average daily flights across all routes.
Step 2: Load the dataframe.
Step 3: Convert the 'avg daily flts' column to integer type since it is stored as strings.
Step 4: Sum the values in this column and print the total.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'avg daily flts' column to integers
df['avg daily flts'] = df['avg daily flts'].astype(int)
# Calculate total average daily flights
total_flights = df['avg daily flts'].sum()
print(f"Final Answer: {total_flights}")
```
