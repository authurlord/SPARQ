Step 1: The user wants the difference in depth (km) between the earthquake with the highest magnitude and the one with the lowest magnitude.
Step 2: Load the dataframe.
Step 3: Identify the row with the highest magnitude and the row with the lowest magnitude.
Step 4: Extract their respective depths.
Step 5: Compute the difference and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Magnitude' and 'Depth (km)' to float for numerical operations
df['Magnitude'] = pd.to_numeric(df['Magnitude'])
df['Depth (km)'] = pd.to_numeric(df['Depth (km)'])

# Find the max and min magnitude values
max_magnitude_depth = df.loc[df['Magnitude'].idxmax()]['Depth (km)']
min_magnitude_depth = df.loc[df['Magnitude'].idxmin()]['Depth (km)']

# Calculate the difference
depth_difference = max_magnitude_depth - min_magnitude_depth
print(f"Final Answer: {depth_difference}")
```
