Step 1: The user wants to find the nation that won 1 gold and 4 silver medals.
Step 2: Load the dataframe.
Step 3: Filter the rows where 'gold' is 1 and 'silver' is 4.
Step 4: Extract the 'nation' column from the filtered row and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for nation with 1 gold and 4 silver medals
filtered_nation = df[(df['gold'] == '1') & (df['silver'] == '4')]
# Extract the nation name
nation = filtered_nation['nation'].values[0]
print(f"Final Answer: {nation}")
```
