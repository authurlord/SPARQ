Step 1: The user wants the correlation coefficient between 'Average population (x 1000)' and 'Natural change (per 1000)'.
Step 2: Load the dataframe.
Step 3: Extract the two columns of interest.
Step 4: Compute the Pearson correlation coefficient using pandas' `corr()` method.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Calculate the correlation between 'Average population (x 1000)' and 'Natural change (per 1000)'
correlation = df['Average population (x 1000)'].corr(df['Natural change (per 1000)'])
print(f"Final Answer: {correlation:.3f}")
```
