Step 1: The user wants to count the number of songs in the French language.
Step 2: Load the dataframe.
Step 3: Filter rows where the 'language' column is 'french'.
Step 4: Count the number of such rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where language is 'french'
french_songs = df[df['language'] == 'french']
# Count the number of French songs
count_french_songs = len(french_songs)
print(f"Final Answer: {count_french_songs}")
```
