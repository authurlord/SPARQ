Step 1: The user wants the average yearly increase in issue price from 2005 to 2010.
Step 2: Load the dataframe.
Step 3: Extract the 'issue price' column and convert it to float.
Step 4: Calculate the difference between consecutive years' issue prices.
Step 5: Compute the average of these differences.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'issue price' to float for numerical operations
df['issue price'] = pd.to_numeric(df['issue price'])
# Calculate the year-over-year increase in issue price
price_increase = df['issue price'].diff().dropna()
# Calculate the average increase
avg_increase = price_increase.mean()
print(f"Final Answer: {avg_increase:.2f}")
```
