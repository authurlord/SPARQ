Step 1: The user wants to find the year when the athlete achieved their personal best time in the 20 km walk event at the African Championships.  
Step 2: Filter the data to include only rows where the 'Competition' is 'African Championships' and the 'Event' is '20 km walk'.  
Step 3: Among these rows, identify the one with the fastest (minimum) time.  
Step 4: Extract the 'Year' corresponding to that fastest time.  
Step 5: Print the result.

Note: The 'Notes' column contains times in format like '1:22:55 (CR)' or '1:24:53'. We need to parse these times into comparable values (e.g., seconds). For consistency, we assume that (CR) indicates a record, but we focus on the actual time value.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for African Championships and 20 km walk
african_championships_20km = df[(df['Competition'] == 'African Championships') & (df['Event'] == '20 km walk')]

# Convert time strings to seconds for comparison
def time_to_seconds(time_str):
    if pd.isna(time_str) or time_str == 'DNF' or time_str == 'DQ' or time_str == '-':
        return float('inf')
    # Remove any extra text like (CR)
    time_clean = time_str.split()[0]
    h, m, s = map(int, time_clean.split(':'))
    return h * 3600 + m * 60 + s

# Apply conversion
african_championships_20km['time_seconds'] = african_championships_20km['Notes'].apply(time_to_seconds)

# Find the row with minimum time
best_time_row = african_championships_20km.loc[african_championships_20km['time_seconds'].idxmin()]

# Extract the year
best_year = best_time_row['Year']

print(f"Final Answer: {best_year}")
```
