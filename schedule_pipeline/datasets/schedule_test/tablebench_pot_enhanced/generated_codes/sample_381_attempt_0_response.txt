Step 1: The user wants to count the number of hurricanes that occurred in the month of September.
Step 2: Load the dataframe.
Step 3: Filter rows where the 'Month' column contains 'September'.
Step 4: Count the number of such rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where 'Month' contains 'September'
september_hurricanes = df[df['Month'].str.contains('September', na=False)]
# Count the number of hurricanes
count_september = len(september_hurricanes)
print(f"Final Answer: {count_september}")
```
