Step 1: The user wants the standard deviation of the number of screens for the top 5 movie theater chains.  
Step 2: The "rank" column indicates the order, so the top 5 are the first 5 rows (rank 1 to 5).  
Step 3: Extract the "screens" column for these rows.  
Step 4: Calculate the standard deviation of the selected values.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Select the top 5 rows (rank 1 to 5) and get the 'screens' column
top_5_screens = df.head(5)['screens']
# Calculate standard deviation
std_screens = top_5_screens.std()
print(f"Final Answer: {std_screens:.1f}")
```
