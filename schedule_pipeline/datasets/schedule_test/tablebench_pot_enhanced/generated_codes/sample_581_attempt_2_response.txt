Step 1: Extract the 'civil liberties' scores for the years 1972 and 1980 from the dataset.
Step 2: Calculate the percentage change using the formula: ((new - old) / old) * 100.
Step 3: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract civil liberties scores for 1972 and 1980
civil_liberties_1972 = df[df['year'] == '1972']['civil liberties'].values[0]
civil_liberties_1980 = df[df['year'] == '1980']['civil liberties'].values[0]

# Calculate percentage change
percentage_change = ((civil_liberties_1980 - civil_liberties_1972) / civil_liberties_1972) * 100
print(f"Final Answer: {percentage_change:.1f}")
```
