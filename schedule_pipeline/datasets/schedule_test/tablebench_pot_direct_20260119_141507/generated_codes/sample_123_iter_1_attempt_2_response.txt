We are asked to draw a stacked bar chart showing the match statistics for each team. However, the data provided includes multiple match statistics such as "Played", "Points", "Wins", "Draws", "Losses", "Goals for", "Goals against", and "Goal Difference". A stacked bar chart typically represents categorical data with components stacked on top of each other.

But here, we have one row per team, and each row contains various performance metrics — not naturally suited for a stacked bar chart unless we group or combine some of them.

Since the question says "stacked bar chart showing the match statistics", it's ambiguous. However, a more meaningful interpretation would be to visualize the **distribution of points** (or another metric) across teams, perhaps with breakdowns like wins, draws, and losses — which can be shown in a stacked format.

Let’s interpret the task as:
- Create a stacked bar chart where each bar represents a team.
- The bar is divided into three segments: Wins, Draws, and Losses (since these are the components that sum to "Played").
- This makes sense because "Wins + Draws + Losses = Played" and they are mutually exclusive.

Steps:
1. Load the data.
2. Extract relevant columns: 'Club', 'Wins', 'Draws', 'Losses'.
3. Convert "Played" to ensure it matches the sum of Wins+Draws+Losses (though it's already given).
4. Use matplotlib to create a stacked bar chart with clubs on the x-axis and counts on the y-axis.

Note: The "Points" column has a strange format like "57+19", which is not numerical. We will ignore it since it's not useful for a stacked bar chart of wins/draws/losses.

```python
import pandas as pd
import matplotlib.pyplot as plt

# Load the data
df = pd.read_csv('table.csv')

# Clean and prepare data for plotting
# Select only relevant columns
data = df[['Club', 'Wins', 'Draws', 'Losses']]

# Create a stacked bar chart
plt.figure(figsize=(12, 8))
bars = plt.bar(data['Club'], data['Wins'], label='Wins', color='skyblue')
plt.bar(data['Club'], data['Draws'], bottom=data['Wins'], label='Draws', color='lightgreen')
plt.bar(data['Club'], data['Losses'], bottom=data['Wins'] + data['Draws'], label='Losses', color='salmon')

# Customize labels and title
plt.xlabel('Club')
plt.ylabel('Number of Matches')
plt.title('Stacked Bar Chart of Wins, Draws, and Losses by Club')
plt.legend()

# Rotate x-axis labels for readability
plt.xticks(rotation=45)

# Improve layout
plt.tight_layout()

# Display the plot
plt.show()
```
