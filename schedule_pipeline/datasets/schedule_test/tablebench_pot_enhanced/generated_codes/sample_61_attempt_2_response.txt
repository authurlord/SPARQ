Step 1: The user wants to identify the nation with a total of 57 medals.
Step 2: Load the dataframe.
Step 3: Filter the row where 'Total' equals 57.
Step 4: Extract the 'Nation' column value and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where Total is 57
nation_with_57 = df[df['Total'] == 57]['Nation'].iloc[0]
print(f"Final Answer: {nation_with_57}")
```
