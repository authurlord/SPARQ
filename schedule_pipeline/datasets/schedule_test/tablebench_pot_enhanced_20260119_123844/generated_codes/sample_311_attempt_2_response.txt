Step 1: The user wants to find the player who won both men's singles and men's doubles titles in the same year.
Step 2: Load the dataframe.
Step 3: Iterate through each row and check if the men's singles winner is also listed in the men's doubles winners.
Step 4: If a match is found, record the player and the year.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Initialize variables to store result
result_player = None
result_year = None

# Iterate through each row
for index, row in df.iterrows():
    men_singles = row["men 's singles"]
    men_doubles = row["men 's doubles"]
    
    # Check if the men's singles winner is in the men's doubles winners
    if men_singles in men_doubles:
        result_player = men_singles
        result_year = row['year']
        break  # Assuming only one such case exists

print(f"Final Answer: {result_player}, {result_year}")
```
