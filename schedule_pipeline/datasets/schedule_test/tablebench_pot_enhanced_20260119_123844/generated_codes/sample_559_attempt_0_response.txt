Step 1: The user wants the average number of floors for buildings constructed between 1895 and 1980 (inclusive).
Step 2: Load the dataframe.
Step 3: Filter rows where the 'year' is between 1895 and 1980 (inclusive).
Step 4: Select the 'floors' column and calculate the mean.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter buildings constructed from 1895 to 1980
filtered_df = df[(df['year'].astype(int) >= 1895) & (df['year'].astype(int) <= 1980)]
# Calculate average floors
avg_floors = filtered_df['floors'].astype(int).mean()
print(f"Final Answer: {avg_floors:.1f}")
```
