```python
import pandas as pd

df = pd.read_csv('table.csv')
df['Year'] = pd.to_numeric(df['Year'], errors='coerce')

# Compute year-over-year increase in Conservative councillors
conservative_values = df['Conservative councillors']
differences = conservative_values.diff()

# Find the index of the maximum positive difference
max_increase_idx = differences.idxmax()

# The year of maximum increase is the year at the next row (i.e., max_increase_idx + 1)
# But idxmax returns the label, which is the row index. We need the actual year.
# Since differences is aligned with the rows, the maximum difference occurs between row i and row i+1
# So the year when the increase happens is the year at row i+1.

# If idxmax returns the index (position), then the year is at position idxmax + 1
# But idxmax returns the index label (like 1, 2, ...), so we use .iloc

max_increase_row = differences.argmax()  # This gives the index position (int)
year_of_max_increase = df.iloc[max_increase_row + 1]['Year']

print(f"Final Answer: {year_of_max_increase}")
```
