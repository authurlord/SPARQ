Step 1: The user wants to identify the economy with the highest GDP per capita as of 2012 (PPP).
Step 2: Load the dataframe.
Step 3: Select the 'gdp per capita as of 2012 (ppp)' column.
Step 4: Find the maximum value and return the corresponding economy.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the economy with the highest GDP per capita in 2012 (PPP)
max_gdp_per_capita_economy = df.loc[df['gdp per capita as of 2012 (ppp)'].idxmax(), 'economy']
print(f"Final Answer: {max_gdp_per_capita_economy}")
```
