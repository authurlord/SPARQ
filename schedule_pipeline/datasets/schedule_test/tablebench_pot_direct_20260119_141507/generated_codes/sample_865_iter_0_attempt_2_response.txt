Step 1: The user wants to find the difference between the highest and lowest total medals among schools.  
Step 2: Load the dataframe.  
Step 3: Extract the 'total medals' column.  
Step 4: Find the maximum and minimum values in this column.  
Step 5: Compute the difference and print it.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract total medals column
total_medals = df['total medals'].astype(int)
max_medals = total_medals.max()
min_medals = total_medals.min()
difference = max_medals - min_medals
print(f"Final Answer: {difference}")
```
