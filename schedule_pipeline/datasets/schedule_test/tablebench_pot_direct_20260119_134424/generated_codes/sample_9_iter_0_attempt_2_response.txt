Step 1: The user wants the average number of podiums achieved by a team per season.
Step 2: Load the dataframe.
Step 3: Select the 'podiums' column, which contains the number of podiums for each season.
Step 4: Calculate the mean of the 'podiums' column and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Calculate the average number of podiums per season
average_podiums = df['podiums'].mean()
print(f"Final Answer: {average_podiums:.1f}")
```
