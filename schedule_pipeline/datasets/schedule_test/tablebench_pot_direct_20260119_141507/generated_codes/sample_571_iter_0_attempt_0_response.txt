Step 1: The user wants the average change in qualifying score for the 'all around' event from the 'olympic trials' to the 'us championships' in 2008.  
Step 2: Filter the data for rows where the event is 'all around', competition is either 'olympic trials' or 'us championships', and year is 2008.  
Step 3: Extract the qualifying scores for these two events.  
Step 4: Compute the difference (change) in qualifying score between the 'us championships' and 'olympic trials'.  
Step 5: Take the average of these differences.  

Note: Since there is only one 'all around' entry in each competition, we compute the change directly and return it as the average.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter rows for 'all around' event in 2008
filtered = df[(df['event'] == 'all around') & (df['year'] == '2008')]

# Extract qualifying scores for 'olympic trials' and 'us championships'
qualifying_trials = filtered[filtered['competition'] == 'olympic trials']['qualifying score'].values[0]
qualifying_champs = filtered[filtered['competition'] == 'us championships']['qualifying score'].values[0]

# Calculate the change
change = qualifying_champs - qualifying_trials

print(f"Final Answer: {change:.3f}")
```
