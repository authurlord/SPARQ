Step 1: The user wants to identify the year with the highest crude birth rate (per 1000).  
Step 2: Load the dataframe.  
Step 3: Select the 'Crude birth rate (per 1000)' column.  
Step 4: Find the row with the maximum value and extract the corresponding year.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the year with the highest crude birth rate
max_birth_rate_row = df.loc[df['Crude birth rate (per 1000)'].idxmax()]
highest_birth_rate_year = max_birth_rate_row['Unnamed: 0']
print(f"Final Answer: {highest_birth_rate_year}")
```
