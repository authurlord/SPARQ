Step 1: The user wants to identify the year of the song with the highest US chart position and the year of the song with the lowest US chart position.  
Step 2: Extract the 'US Chart position' column and convert it to numeric (to handle cases like "17 (R&B)" or "8 (R&B)") — we only care about the numeric part.  
Step 3: Find the maximum and minimum US chart positions, and their corresponding years.  
Step 4: Return the years for both the highest and lowest chart positions.

Note: "17 (R&B)" should be treated as 17, and we ignore the "(R&B)" part.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Extract the numeric US Chart position by removing text in parentheses
def extract_position(pos):
    try:
        # Remove any text in parentheses and convert to int
        return int(''.join(c for c in pos if c.isdigit()))
    except:
        return 0

df['US Chart position'] = df['US Chart position'].apply(extract_position)

# Find the year with the highest and lowest chart position
max_pos_row = df.loc[df['US Chart position'].idxmax()]
min_pos_row = df.loc[df['US Chart position'].idxmin()]

highest_year = max_pos_row['Year']
lowest_year = min_pos_row['Year']

print(f"Final Answer: {highest_year}, {lowest_year}")
```
