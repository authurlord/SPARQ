Step 1: The user wants to identify the mountain with the highest elevation among those in Greece.
Step 2: Load the dataframe.
Step 3: Filter rows where 'country' contains 'greece' (case-insensitive).
Step 4: Convert 'elevation (m)' column to numeric for comparison.
Step 5: Find the mountain with the maximum elevation.
Step 6: Print the name of the mountain.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter mountains in Greece (case-insensitive)
greece_mountains = df[df['country'].str.contains('greece', case=False, na=False)]
# Convert elevation to numeric
greece_mountains['elevation (m)'] = pd.to_numeric(greece_mountains['elevation (m)'])
# Find the mountain with the highest elevation
highest_elevation_mountain = greece_mountains.loc[greece_mountains['elevation (m)'].idxmax(), 'peak']
print(f"Final Answer: {highest_elevation_mountain}")
```
