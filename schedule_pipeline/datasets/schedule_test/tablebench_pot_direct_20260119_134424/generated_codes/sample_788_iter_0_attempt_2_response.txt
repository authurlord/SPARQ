Step 1: The user wants the median elevation of mountain peaks in Greece.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the country is Greece (note that some entries include "greece ( crete )" or similar, so we need to check for "greece" in the country column).  
Step 4: Convert the 'elevation (m)' column to numeric.  
Step 5: Calculate the median of the filtered elevation values.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for mountains in Greece (including regions like Crete, Euboea, Kefalonia, etc.)
greek_peaks = df[df['country'].str.contains('greece', case=False, na=False)]
# Convert elevation to numeric
greek_peaks['elevation (m)'] = pd.to_numeric(greek_peaks['elevation (m)'])
# Calculate median elevation
median_elevation = greek_peaks['elevation (m)'].median()
print(f"Final Answer: {median_elevation}")
```
