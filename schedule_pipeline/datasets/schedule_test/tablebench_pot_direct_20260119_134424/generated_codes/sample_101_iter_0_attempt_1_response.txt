Step 1: The user wants a pie chart showing the vote share (%) of candidates from various political parties.
Step 2: Load the dataframe.
Step 3: Filter out rows that are not actual candidates (e.g., "Total valid votes", "Total rejected ballots", etc.).
Step 4: Convert the '%' column to float for plotting.
Step 5: Use matplotlib to create a pie chart with party names and their vote shares.
Step 6: Display the chart.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')

# Filter out non-candidate rows (keep only actual parties)
parties = df[df['Party'] != 'Total valid votes']
parties = parties[parties['Party'] != 'Total rejected ballots']
parties = parties[parties['Party'] != 'Turnout']
parties = parties[parties['Party'] != 'Eligible voters']

# Convert percentage to float
parties['%'] = pd.to_numeric(parties['%'])

# Create pie chart
plt.figure(figsize=(8, 8))
plt.pie(parties['%'], labels=parties['Party'], autopct='%1.1f%%', startangle=90)
plt.title('Vote Share by Political Party')
plt.show()

print("Final Answer: Pie chart displayed")
```
