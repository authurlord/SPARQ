The error occurred because the points column contains string values that cannot be directly converted to numeric. We need to ensure that the "points" column is properly parsed as numeric, handling any potential non-numeric or malformed entries.

Step-by-step approach:
1. Load the dataframe.
2. Convert the 'points' column to numeric, using pd.to_numeric with errors='coerce' to handle invalid entries.
3. Filter out rows where the language is not English.
4. Compute the average of the points for the filtered rows.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'points' to numeric, coercing errors to NaN
df['points'] = pd.to_numeric(df['points'], errors='coerce')
# Filter rows where language is not 'english'
filtered_df = df[df['language'] != 'english']
# Calculate the average points for non-English entries
average_points = filtered_df['points'].mean()
print(f"Final Answer: {average_points:.1f}")
```
