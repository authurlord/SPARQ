Step 1: The user wants the number of Indians admitted in 2005.
Step 2: Load the dataframe.
Step 3: Filter the row where 'year' is '2005'.
Step 4: Extract the value from the 'indians admitted' column and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where year is 2005
indians_2005 = df[df['year'] == '2005']['indians admitted'].iloc[0]
print(f"Final Answer: {indians_2005}")
```
