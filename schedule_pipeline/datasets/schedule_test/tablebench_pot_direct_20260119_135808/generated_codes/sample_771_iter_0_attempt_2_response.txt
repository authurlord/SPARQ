Step 1: The user wants a forecast for pass percentage and obtained GPA for the year 2011 based on the trend from 2005 to 2010.  
Step 2: Load the dataframe.  
Step 3: Extract the 'pass percentage' and 'obtained gpa - 5' columns, converting them to numeric values (removing '%' and handling as floats).  
Step 4: Perform a linear regression or simple trend extrapolation using the year as the independent variable.  
Step 5: Predict the values for 2011.  
Step 6: Output the forecasted pass percentage and GPA.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')

# Convert 'pass percentage' to float by removing '%'
df['pass percentage'] = df['pass percentage'].str.replace('%', '').astype(float)

# Use year as x and pass percentage and GPA as y
x = df['year'].astype(int)
y_pass = df['pass percentage']
y_gpa = df['obtained gpa - 5']

# Fit linear models
coeff_pass = np.polyfit(x, y_pass, 1)
coeff_gpa = np.polyfit(x, y_gpa, 1)

# Predict for 2011
year_2011 = 2011
predicted_pass = np.polyval(coeff_pass, year_2011)
predicted_gpa = np.polyval(coeff_gpa, year_2011)

print(f"Final Answer: {predicted_pass:.2f}, {predicted_gpa:.2f}")
```
