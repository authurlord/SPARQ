The error occurred because we are trying to filter rows based on a year condition (e.g., '1975' to '1990') using string comparison, but the data type of the 'Year' column is string, and we need to ensure proper filtering.

Step 1: Identify the correct years to include — from 1975 to 1990 inclusive.
Step 2: Convert the 'Year' column to integer for proper comparison.
Step 3: Filter the DataFrame for years between 1975 and 1990 (inclusive).
Step 4: Extract the "Political Rights" column from the filtered data.
Step 5: Compute the standard deviation of the filtered "Political Rights" scores.
Step 6: Print the result.

```python
import pandas as pd

# Load the dataframe
df = pd.read_csv('table.csv')

# Convert 'Year' to integer for proper filtering
df['Year'] = pd.to_numeric(df['Year'], errors='coerce')

# Filter rows where Year is between 1975 and 1990 inclusive
filtered_df = df[(df['Year'] >= 1975) & (df['Year'] <= 1990)]

# Extract the 'Political Rights' column and compute standard deviation
political_rights = filtered_df['Political Rights'].dropna()
std_dev = political_rights.std()

print(f"Final Answer: {std_dev:.1f}")
```
