The error occurred because the "total goals" values in the table are stored as strings with parentheses, such as "3 (1)" or "10 (5)", which cannot be directly converted to numbers. We need to extract only the numeric part of the "total goals" column and convert it to integers.

Step-by-step approach:
1. Load the dataframe.
2. Extract the "total goals" column and clean it by removing the text in parentheses and converting to integer.
3. Filter players by position: 'fw' for forwards and 'mf' for midfielders.
4. Find the maximum total goals for forwards and midfielders.
5. Compute the difference between the top-scoring forward and top-scoring midfielder.

```python
import pandas as pd
import re

df = pd.read_csv('table.csv')

# Clean the 'total goals' column by extracting numeric values
def extract_goals(goals_str):
    match = re.search(r'^(\d+)', goals_str)
    return int(match.group(1)) if match else 0

df['total goals'] = df['total goals'].apply(extract_goals)

# Filter for forwards (fw) and midfielders (mf)
forwards = df[df['position'] == 'fw']
midfielders = df[df['position'] == 'mf']

# Get the maximum total goals for each group
top_forward_goals = forwards['total goals'].max()
top_midfielder_goals = midfielders['total goals'].max()

# Calculate the difference
difference = top_forward_goals - top_midfielder_goals

print(f"Final Answer: {difference}")
```
