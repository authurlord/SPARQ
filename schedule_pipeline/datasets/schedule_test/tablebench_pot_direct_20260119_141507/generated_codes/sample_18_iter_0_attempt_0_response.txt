Step 1: The user wants the total population of regions where the percentage of Manchu population is greater than 5%.  
Step 2: Load the dataframe.  
Step 3: Filter rows where 'percentage in manchu population' > 5.  
Step 4: Sum the 'total population' for those filtered rows.  

Note: The "percentage in manchu population" column contains values like '100', '99.83', '66.77', etc. We interpret these as percentages, so we compare them directly with 5 (since >5% means greater than 5).  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where percentage in manchu population is greater than 5%
filtered_df = df[df['percentage in manchu population'].astype(float) > 5]
# Sum the total population of these regions
total_population = filtered_df['total population'].sum()
print(f"Final Answer: {total_population}")
```
