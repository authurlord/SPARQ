Step 1: The user wants to identify the years when the song with the highest and lowest US chart positions were released.  
Step 2: Load the dataframe.  
Step 3: Convert the 'US Chart position' column to numeric, handling non-numeric values (like 'R&B' entries) by skipping or replacing them with a large number for comparison.  
Step 4: Find the row with the highest and lowest US chart positions.  
Step 5: Extract the corresponding 'Year' values for both songs.  
Step 6: Print the result in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'US Chart position' to numeric, coercing errors to NaN
df['US Chart position'] = pd.to_numeric(df['US Chart position'], errors='coerce')

# Drop rows where 'US Chart position' is NaN (e.g., 'R&B' entries)
df_clean = df.dropna(subset=['US Chart position'])

# Find the year with the highest and lowest US chart positions
max_year = df_clean.loc[df_clean['US Chart position'].idxmax(), 'Year']
min_year = df_clean.loc[df_clean['US Chart position'].idxmin(), 'Year']

print(f"Final Answer: {max_year}, {min_year}")
```
