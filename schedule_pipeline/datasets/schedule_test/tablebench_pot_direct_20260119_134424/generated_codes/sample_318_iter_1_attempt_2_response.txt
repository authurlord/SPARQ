Step 1: The user wants to find the year when the athlete achieved their best (highest) position in the 400m event at the European Championships.
Step 2: Filter the data for rows where the 'Competition' is 'European Championships' and the 'Event' is '400 m'.
Step 3: Extract the 'Position' and convert it to a numeric value, handling non-numeric entries like '–' or 'DQ' by treating them as invalid or worst positions.
Step 4: Identify the best (lowest numeric) position and return the corresponding 'Year'.
Step 5: Handle parsing errors by filtering out invalid positions and converting only valid numeric positions.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for European Championships and 400m event
filtered_df = df[(df['Competition'] == 'European Championships') & (df['Event'] == '400 m')]

# Convert Position to numeric, invalid entries become NaN
filtered_df['Position'] = pd.to_numeric(filtered_df['Position'], errors='coerce')

# Drop rows with invalid positions
valid_positions = filtered_df.dropna(subset=['Position'])

# Find the row with the best (lowest) position
best_row = valid_positions.loc[valid_positions['Position'].idxmin()]

# Get the year
best_year = best_row['Year']
print(f"Final Answer: {best_year}")
```
