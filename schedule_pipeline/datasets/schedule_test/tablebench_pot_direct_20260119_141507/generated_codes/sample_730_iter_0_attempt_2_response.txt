Step 1: The user wants to find the mountain with the highest elevation among those in Greece.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'country' column contains "greece" (case-insensitive).  
Step 4: Among the filtered rows, find the one with the maximum value in the 'elevation (m)' column.  
Step 5: Return the name of that mountain.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter mountains in Greece
greece_mountains = df[df['country'].str.contains('greece', case=False)]
# Find the mountain with the highest elevation
highest_elevation_mountain = greece_mountains.loc[greece_mountains['elevation (m)'].idxmax(), 'peak']
print(f"Final Answer: {highest_elevation_mountain}")
```
