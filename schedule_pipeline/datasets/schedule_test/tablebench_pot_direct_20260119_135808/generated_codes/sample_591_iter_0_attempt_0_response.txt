Step 1: The user wants the total number of live births from the period 1950-1955 to 1975-1980.  
Step 2: Load the dataframe.  
Step 3: Filter the rows corresponding to the periods from '1950-1955' to '1975-1980'.  
Step 4: Extract the 'Live births per year' column, convert values from strings with spaces to integers, and sum them.  
Step 5: Print the total.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for the required periods
filtered_df = df[(df['Period'] >= '1950-1955') & (df['Period'] <= '1975-1980')]
# Convert 'Live births per year' to integer after removing spaces
filtered_df['Live births per year'] = filtered_df['Live births per year'].str.replace(' ', '').astype(int)
total_live_births = filtered_df['Live births per year'].sum()
print(f"Final Answer: {total_live_births}")
```
