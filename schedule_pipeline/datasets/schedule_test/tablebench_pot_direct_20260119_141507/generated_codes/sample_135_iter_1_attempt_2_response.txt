We are tasked with drawing a percentage bar chart that shows the percentage of total sales for each song in different regions. 

Step-by-step approach:
1. The table contains sales data per song across different regions (e.g., northern ireland, southern england, etc.), and a 'total' column.
2. We need to compute the percentage of each region's sales relative to the total sales for each song.
3. Then, we will create a bar chart where each song is represented, and the bars show the percentage of sales in each region (we can use stacked or grouped bars; however, since we want "percentage of total sales for each song in different regions", a stacked bar chart makes sense).
4. Alternatively, if we interpret it as showing the share of each region per song, we can create a stacked bar chart with each song as a group.

But note: the question says "percentage of total sales for each song in different regions". This implies we want to show, for each song, what portion of its total sales comes from each region.

So:
- For each song, calculate the share of each region's sales as a percentage of the song's total.
- Then plot a stacked bar chart where each song is a group, and each region is a segment.

We'll use matplotlib to create this.

Important: The 'total' column is already given. So for each song, we can compute the percentage contribution of each region.

Let’s proceed:

```python
import pandas as pd
import matplotlib.pyplot as plt

# Load the data
df = pd.read_csv('table.csv')

# Convert the 'mobiles' column to numeric (though it seems irrelevant here)
# We focus on the regions and total for each song

# Drop the 'mobiles' column as it doesn't seem relevant to the analysis
df = df.drop(columns=['mobiles'])

# Convert all region columns to numeric
region_cols = ['northern ireland', 'northern england', 'scotland', 'southern england', 'wales']
df[region_cols] = df[region_cols].apply(pd.to_numeric, errors='coerce')

# Calculate percentage of total sales for each region per song
df['total'] = pd.to_numeric(df['total'], errors='coerce')
df['total'] = df['total'].fillna(0)

# Create a new dataframe for percentages
percentages = df.copy()
for col in region_cols:
    percentages[col] = (percentages[col] / percentages['total']) * 100

# Now we want to plot a stacked bar chart: one bar per song, with segments for each region
# We will use the percentages to create the chart

# Set up the plot
plt.figure(figsize=(12, 8))
bar_width = 0.35
index = df.index

# Create the stacked bar chart
bars = []
for i, col in enumerate(region_cols):
    bars.append(plt.bar(index, percentages[col], label=col, width=bar_width))

# Add labels and title
plt.xlabel('Song')
plt.ylabel('Percentage of Total Sales')
plt.title('Percentage of Total Sales for Each Song by Region')
plt.xticks(index, df['song'], rotation=45)

# Add legend
plt.legend(title='Region')

# Improve layout
plt.tight_layout()

# Show the plot
plt.show()
```
