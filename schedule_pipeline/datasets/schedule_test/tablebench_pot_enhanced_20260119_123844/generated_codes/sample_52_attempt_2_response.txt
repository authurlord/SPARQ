Step 1: The user wants to find the nation that has won exactly 5 gold medals and 2 silver medals.
Step 2: Load the dataframe.
Step 3: Filter rows where 'Gold' is 5 and 'Silver' is 2.
Step 4: Extract the 'Nation' column value from the filtered row and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for nation with 5 gold and 2 silver medals
filtered_nation = df[(df['Gold'] == '5') & (df['Silver'] == '2')]
# Extract the nation name
nation = filtered_nation['Nation'].values[0]
print(f"Final Answer: {nation}")
```
