Step 1: The user wants to find the year with the highest average issue price and compare it to the average issue price of the lowest year(s).  
Step 2: Load the dataframe.  
Step 3: Group by 'year' and calculate the average issue price for each year.  
Step 4: Identify the year with the highest average issue price and the year with the lowest average issue price.  
Step 5: Compute the difference between the highest and lowest average issue prices.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Group by year and compute average issue price
avg_issue_price = df.groupby('year')['issue price'].mean()

# Find the year with the highest and lowest average issue price
max_year = avg_issue_price.idxmax()
min_year = avg_issue_price.idxmin()
max_price = avg_issue_price.max()
min_price = avg_issue_price.min()
difference = max_price - min_price

print(f"Final Answer: {max_year}, {difference:.2f}")
```
