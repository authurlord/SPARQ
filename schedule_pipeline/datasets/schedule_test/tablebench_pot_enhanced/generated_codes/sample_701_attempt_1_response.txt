Step 1: The user wants to identify the year with the highest number of injuries.
Step 2: Load the dataframe.
Step 3: Parse the 'Injuries (US $000)' column, handling non-numeric values like 'no data' and '202 (estimate)'.
Step 4: Convert the column to numeric, replacing 'no data' with NaN and extracting the numeric value from '202 (estimate)'.
Step 5: Find the year with the maximum injury value.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Clean the 'Injuries (US $000)' column
df['Injuries (US $000)'] = df['Injuries (US $000)'].astype(str).str.replace(r'\(estimate\)', '', regex=True)
df['Injuries (US $000)'] = pd.to_numeric(df['Injuries (US $000)'], errors='coerce')

# Find the year with the maximum injuries
max_injuries_year = df.loc[df['Injuries (US $000)'].idxmax(), 'Year']
print(f"Final Answer: {max_injuries_year}")
```
