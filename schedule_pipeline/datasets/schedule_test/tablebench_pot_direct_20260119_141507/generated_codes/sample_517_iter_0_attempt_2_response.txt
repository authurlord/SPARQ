Step 1: Understand that "AIDS-related orphans" is represented in the column "total orphans (aids related)" and we need to find the year with the highest value for this category.  
Step 2: The data includes entries for different countries and years (e.g., botswana (1990), malawi (1995), etc.). We need to extract the year from the country-year label and identify the maximum value of "total orphans (aids related)".  
Step 3: Since the year is embedded in the row label (e.g., "botswana (1990)"), we can parse it and compare values across rows.  
Step 4: Find the row with the maximum "total orphans (aids related)" and extract the corresponding year.

```python
import pandas as pd

# Load the data
df = pd.read_csv('table.csv')

# Convert 'total orphans (aids related)' to numeric (some values are strings like '< 100')
df['total orphans (aids related)'] = pd.to_numeric(df['total orphans (aids related)'], errors='coerce')

# Extract year from the country column (e.g., 'botswana (1990)' -> 1990)
df['year'] = df['country'].str.extract(r'\((\d{4})\)').astype(str).str.strip()

# Find the row with the maximum AIDS-related orphans
max_orphans_row = df.loc[df['total orphans (aids related)'].idxmax()]
max_year = max_orphans_row['year']

print(f"Final Answer: {max_year}")
```
