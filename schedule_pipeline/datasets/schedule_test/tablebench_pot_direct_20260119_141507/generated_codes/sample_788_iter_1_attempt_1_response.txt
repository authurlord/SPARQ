The error occurred because the elevation values are stored as strings, and we need to convert them to numeric before computing the median. We must ensure proper type conversion when processing the 'elevation (m)' column.

Step 1: Load the dataframe.
Step 2: Convert the 'elevation (m)' column from string to numeric (using pd.to_numeric with errors='coerce' to handle any invalid entries).
Step 3: Filter only the peaks in Greece (based on the 'country' column).
Step 4: Compute the median of the elevation values for these peaks.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert elevation to numeric, handling any parsing errors
df['elevation (m)'] = pd.to_numeric(df['elevation (m)'], errors='coerce')

# Filter mountains in Greece (case-insensitive match)
greece_peaks = df[df['country'].str.contains('greece', case=False, na=False)]

# Calculate median elevation of peaks in Greece
median_elevation = greece_peaks['elevation (m)'].median()
print(f"Final Answer: {median_elevation:.0f}")
```
