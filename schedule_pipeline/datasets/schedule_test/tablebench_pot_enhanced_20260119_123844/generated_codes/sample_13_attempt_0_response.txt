Step 1: The user wants to calculate the average population density of all municipalities.
Step 2: Load the dataframe.
Step 3: Select the 'population density ( / km 2 )' column.
Step 4: Calculate the mean of this column and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# The column 'population density ( / km 2 )' contains numerical values
mean_density = df['population density ( / km 2 )'].mean()
```
