Step 1: The user wants the average revenue of the top 5 companies in the 'banking' industry.  
Step 2: First, filter the dataframe to include only rows where the 'industry' is 'banking'.  
Step 3: Among these, select the top 5 companies by revenue (though the table is already sorted by rank, we assume rank order corresponds to ranking).  
Step 4: Extract the 'revenue (millions)' values for these top 5 banking companies.  
Step 5: Compute the mean of these revenues and print it.

Note: The table is already sorted by rank, so the first 5 companies in the 'banking' industry are the top 5.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where industry is 'banking'
banking_companies = df[df['industry'] == 'banking']

# Select the top 5 (first 5 rows) based on rank
top_5_banking = banking_companies.head(5)

# Calculate the average revenue of these companies
average_revenue = top_5_banking['revenue (millions)'].mean()
print(f"Final Answer: {average_revenue:.1f}")
```
