Step 1: The user wants to find the year when the athlete achieved their best position in the 800m event at the World Championships.
Step 2: Filter the data for rows where 'Competition' is 'World Championships' and 'Event' is '800 m'.
Step 3: Among these filtered rows, identify the row with the best (lowest) 'Position' value (since lower position numbers indicate better performance).
Step 4: Extract the corresponding 'Year' and print it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for World Championships and 800m event
world_champs_800m = df[(df['Competition'] == 'World Championships') & (df['Event'] == '800 m')]
# Find the row with the best position (lowest position number)
best_position_row = world_champs_800m.loc[world_champs_800m['Position'].str.extract('(\d+)', expand=False).astype(int).idxmin()]
# Extract the year
best_year = best_position_row['Year']
print(f"Final Answer: {best_year}")
```
