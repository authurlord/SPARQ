Step 1: The user wants the total average viewership of the top 5 TV shows.
Step 2: Load the dataframe.
Step 3: Extract the 'average' column, which represents the average viewership.
Step 4: Select the first 5 rows (top 5 shows) and sum their average viewership.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the 'average' column and sum the values for the top 5 shows
total_average_viewership = df['average'].head(5).sum()
print(f"Final Answer: {total_average_viewership}")
```
