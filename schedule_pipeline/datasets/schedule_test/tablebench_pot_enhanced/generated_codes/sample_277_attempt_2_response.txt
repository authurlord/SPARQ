Step 1: The user wants the average points scored by songs that:
- Have a non-English language title.
- Have points greater than the median points value of all songs.

Step 2: Load the dataframe.

Step 3: Calculate the median of the 'points' column.

Step 4: Filter rows where 'language' is not 'english' and 'points' > median.

Step 5: Compute the mean of the 'points' for the filtered rows.

Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Calculate median points
median_points = df['points'].median()

# Filter non-English songs with points > median
non_english_high_points = df[(df['language'] != 'english') & (df['points'] > median_points)]

# Calculate average points for these songs
average_points = non_english_high_points['points'].mean()

print(f"Final Answer: {average_points:.1f}")
```
