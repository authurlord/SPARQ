Step 1: The user wants the payout for a "four of a kind, 2-4" hand when betting 3 credits.
Step 2: Load the dataframe.
Step 3: Filter the row where 'hand' is "four of a kind , 2 - 4".
Step 4: Extract the value in the '3 credits' column.
Step 5: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for "four of a kind , 2 - 4"
row = df[df['hand'] == 'four of a kind , 2 - 4']
# Get the payout for 3 credits
payout = row['3 credits'].values[0]
print(f"Final Answer: {payout}")
```
