The error occurred because the data includes a row labeled "total" which contains aggregated values, and these values are not part of the years 2000 to 2010. We need to exclude the "total" row when calculating the average for years 2000 to 2010.

Step-by-step approach:
1. Load the DataFrame.
2. Filter out the row where 'year' is 'total'.
3. Extract the 'indians admitted' column for years 2000 to 2010.
4. Compute the mean of that column.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows for years 2000 to 2010 and exclude the 'total' row
filtered_df = df[df['year'].str.contains(r'^20\d{2}$') & (df['year'] != 'total')]
# Calculate the average number of Indians admitted per year
average_indians = filtered_df['indians admitted'].mean()
print(f"Final Answer: {average_indians:.0f}")
```
