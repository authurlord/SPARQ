Step 1: The user wants the average annual change in the number of Conservative councillors from 1947 to 1972.  
Step 2: Load the dataframe.  
Step 3: Extract the 'Conservative councillors' values for the years 1947 to 1972.  
Step 4: Calculate the difference between consecutive years to get annual changes.  
Step 5: Compute the average of these changes.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data from 1947 to 1972
df_filtered = df[df['Year'].astype(int) >= 1947]
df_filtered = df_filtered[df_filtered['Year'].astype(int) <= 1972]

# Convert 'Conservative councillors' to integer
conservative_councillors = df_filtered['Conservative councillors'].astype(int)

# Calculate annual changes
annual_changes = conservative_councillors.diff().dropna()

# Calculate average annual change
avg_change = annual_changes.mean()

print(f"Final Answer: {avg_change:.1f}")
```
