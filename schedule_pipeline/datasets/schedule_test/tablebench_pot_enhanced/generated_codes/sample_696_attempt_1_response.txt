Step 1: Identify the column related to "foreign" language speakers.
Step 2: Find the municipality with the highest and lowest values in the "foreign" column.
Step 3: Calculate the difference between the highest and lowest values.
Step 4: Output the municipality with the highest number and the difference.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the 'foreign' column and find max and min values
foreign_column = df['foreign']
max_municipality = df.loc[foreign_column.idxmax(), 'mapiri municipality']  # This is the municipality name with max value
min_municipality = df.loc[foreign_column.idxmin(), 'mapiri municipality']  # This is the municipality name with min value
max_value = foreign_column.max()
min_value = foreign_column.min()
difference = max_value - min_value

print(f"Final Answer: {max_municipality}, {difference}")
```
