Step 1: The user wants to find the series with the highest average viewership (in millions).  
Step 2: Load the dataframe.  
Step 3: Select the 'average viewers (millions)' column and identify the row with the maximum value.  
Step 4: Retrieve the corresponding 'series' value for that row.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the series with the highest average viewers (in millions)
max_viewers_series = df.loc[df['average viewers (millions)'].idxmax(), 'series']
print(f"Final Answer: {max_viewers_series}")
```
