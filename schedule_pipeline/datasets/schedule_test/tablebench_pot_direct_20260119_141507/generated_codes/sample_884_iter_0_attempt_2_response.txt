Step 2: The percentage increase is calculated as:
   (New value - Old value) / Old value * 100

Step 3: We will compute the percentage increase for domestic and foreign steel tonnage for each year, then compare them year by year.

Step 4: Identify the year where domestic percentage increase > foreign percentage increase.

Step 5: Since the data is from 2000 to 2006, we will compute the differences between consecutive years (i.e., from 2000 to 2001, etc.) and calculate the percentage increases.

Note: The table shows values for each year, so we can compute the year-over-year percentage change.

import pandas as pd

# Sort by year

import pandas as pd

df = pd.read_csv('table.csv')

# Convert to numeric
df['domestic s ton'] = pd.to_numeric(df['domestic s ton'], errors='coerce')
df['foreign total s ton'] = pd.to_numeric(df['foreign total s ton'], errors='coerce')

# Sort by year
df = df.sort_values('year').reset_index(drop=True)

# Compute year-over-year percentage increases (skip first row)
df['domestic_increase'] = ((df['domestic s ton'] - df['domestic s ton'].shift(1)) / df['domestic s ton'].shift(1)) * 100
df['foreign_increase'] = ((df['foreign total s ton'] - df['foreign total s ton'].shift(1)) / df['foreign total s ton'].shift(1)) * 100

# Filter years where domestic increase > foreign increase
valid_years = df[(df['domestic_increase'] > df['foreign_increase']) & (df['domestic_increase'].notna()) & (df['foreign_increase'].notna())]['year']

if valid_years.empty:
    Final Answer: "No such year"

    Final Answer: valid_years.iloc[0]
