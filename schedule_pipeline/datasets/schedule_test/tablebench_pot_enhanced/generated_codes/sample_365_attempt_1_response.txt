Step 1: The user wants to count how many jurisdictions had more than 70% of votes in favor of prohibition.
Step 2: Load the dataframe.
Step 3: Convert the 'percent for' column to float.
Step 4: Filter jurisdictions where 'percent for' > 70.
Step 5: Count the number of such jurisdictions and print.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'percent for' to float for comparison
df['percent for'] = pd.to_numeric(df['percent for'])
# Filter jurisdictions with more than 70% in favor
count = df[df['percent for'] > 70].shape[0]
print(f"Final Answer: {count}")
```
