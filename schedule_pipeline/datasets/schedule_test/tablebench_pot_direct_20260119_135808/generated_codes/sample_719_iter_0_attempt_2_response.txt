Step 1: The user wants the top 3 mountains in New Zealand ranked by elevation from highest to lowest.
Step 2: Load the dataframe.
Step 3: Filter the data for mountains in New Zealand (the 'country' column is 'new zealand').
Step 4: Sort the data by 'elevation (m)' in descending order.
Step 5: Select the top 3 rows and extract the mountain names ('peak').
Step 6: Print the result in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for New Zealand mountains
nz_mountains = df[df['country'] == 'new zealand']
# Sort by elevation in descending order
top_3 = nz_mountains.sort_values(by='elevation (m)', ascending=False).head(3)
# Extract the peak names
top_3_peaks = top_3['peak'].tolist()
print(f"Final Answer: {', '.join(top_3_peaks)}")
```
