Step 1: The user wants the median elevation of mountain peaks in Greece.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the country is 'greece' (case-insensitive) or includes 'greece' in the country field.  
Step 4: Convert the 'elevation (m)' column to numeric for calculation.  
Step 5: Calculate the median of the elevation values.  
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for mountains in Greece (handling variations like 'greece ( crete )')
greece_peaks = df[df['country'].str.contains('greece', case=False, na=False)]
# Convert elevation to numeric
greece_peaks['elevation (m)'] = pd.to_numeric(greece_peaks['elevation (m)'])
# Calculate median elevation
median_elevation = greece_peaks['elevation (m)'].median()
print(f"Final Answer: {median_elevation}")
```
