Step 1: Identify the relevant rows where the event is "100 m" and the competition is "African Junior Championships".  
Step 2: Check the "Year" column for those rows to find when a gold medal (i.e., 1st position) was won.  
Step 3: From the data, we see that in 1997, the athlete achieved 1st place in the 100 m event at the African Junior Championships.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where Event is '100 m' and Competition is 'African Junior Championships'
filtered_df = df[(df['Event'] == '100 m') & (df['Competition'] == 'African Junior Championships')]
# Check for 1st position (gold medal)
gold_medal_year = filtered_df[filtered_df['Position'] == '1st']['Year'].values
# Since only one such row exists, return the year
print(f"Final Answer: {gold_medal_year[0]}")
```
