Step 1: Identify intervals with a just ratio involving the number 11. These are ratios like '11:8', '14:11', '11:9', and '13:11' (since they contain 11 in either numerator or denominator).

Step 2: Extract the 'size (cents)' values for these intervals.

Step 3: Calculate the average of these 'size (cents)' values.

Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter rows where just ratio contains '11'
filtered_df = df[df['just ratio'].str.contains('11', na=False)]

# Extract 'size (cents)' values and compute average
average_size_cents = filtered_df['size (cents)'].astype(float).mean()

print(f"Final Answer: {average_size_cents:.2f}")
```
