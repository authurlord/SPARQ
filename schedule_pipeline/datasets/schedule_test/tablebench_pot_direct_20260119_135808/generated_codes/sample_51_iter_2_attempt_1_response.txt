Step 1: The user wants to find the team(s) that finished with a goal difference of 16.
Step 2: Load the dataframe.
Step 3: Filter the rows where 'Goal Difference' equals 16.
Step 4: Extract the 'Club' column from the filtered rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where Goal Difference is 16
team_with_goal_diff_16 = df[df['Goal Difference'] == 16]['Club']
# Print the result
print(f"Final Answer: {', '.join(team_with_goal_diff_16)}")
```
