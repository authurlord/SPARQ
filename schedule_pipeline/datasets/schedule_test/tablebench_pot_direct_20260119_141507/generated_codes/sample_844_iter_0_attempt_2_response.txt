Step 1: The user wants to compare the total medal counts of Australia and Russia.  
Step 2: Load the dataframe.  
Step 3: Find the 'total' column values for Australia and Russia.  
Step 4: Compare the two values and determine which nation has a higher total.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
australia_total = df[df['nation'] == 'australia']['total'].values[0]
russia_total = df[df['nation'] == 'russia']['total'].values[0]

if australia_total > russia_total:
    result = "Australia"
else:
    result = "Russia"

print(f"Final Answer: {result}")
```
