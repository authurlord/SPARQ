Step 1: The user wants to count how many parties have more than 10% of the total votes.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the '%' column is greater than 10%.  
Step 4: Count the number of such rows (excluding the "Total" row, which has 100% and is not a party).  

Note: The "Total" row should be excluded since it does not represent a party.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter out the "Total" row and select only parties with >10% votes
filtered_df = df[df['%'] > '10.0'].dropna()
# Exclude the "Total" row by checking if the party name is not "Total"
party_filter = df['Party'] != 'Total'
filtered_df = df[party_filter & (df['%'] > '10.0')]
count = filtered_df.shape[0]
print(f"Final Answer: {count}")
```
