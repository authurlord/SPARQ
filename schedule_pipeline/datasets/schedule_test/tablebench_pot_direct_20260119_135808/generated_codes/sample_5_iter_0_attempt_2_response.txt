Step 1: The user wants the average value of the "2001 general" column across all regions.
Step 2: Load the dataframe.
Step 3: Extract the "2001 general" column, which contains values as strings (some with parentheses).
Step 4: Clean the values by removing any text in parentheses and converting to float.
Step 5: Calculate the mean of the cleaned values.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Clean the '2001 general' column: remove text in parentheses and convert to float
df['2001 general'] = df['2001 general'].str.replace(r'\(.*\)', '', regex=True).astype(float)
# Calculate the average
average_2001_general = df['2001 general'].mean()
print(f"Final Answer: {average_2001_general:.1f}")
```
