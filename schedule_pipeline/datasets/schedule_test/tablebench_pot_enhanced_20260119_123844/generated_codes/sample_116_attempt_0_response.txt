Step 1: The user wants a line chart showing the trend in maximum building height over time.
Step 2: Load the dataframe.
Step 3: Extract the 'Years as tallest' column and parse the start year (first year in the range).
Step 4: Convert the 'Height ft (m)' column to numeric values (extracting the feet value).
Step 5: Create a line chart with the start year on the x-axis and height on the y-axis.
Step 6: Use matplotlib to plot the line chart.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')

# Extract the start year from 'Years as tallest' column
df['start_year'] = df['Years as tallest'].str.split('–').str[0].astype(int)

# Extract the height in feet (numeric value before parentheses)
df['height_ft'] = df['Height ft (m)'].str.extract('(\d+)').astype(int)

# Sort by start year to ensure correct order
df = df.sort_values('start_year')

# Plot the line chart
plt.figure(figsize=(10, 6))
plt.plot(df['start_year'], df['height_ft'], marker='o', linestyle='-', color='b')
plt.title('Trend in Maximum Building Height Over Time')
plt.xlabel('Year')
plt.ylabel('Height (ft)')
plt.grid(True)
plt.tight_layout()
plt.show()

# Final Answer: The chart has been displayed.
print("Final Answer: Line chart displayed")
```
