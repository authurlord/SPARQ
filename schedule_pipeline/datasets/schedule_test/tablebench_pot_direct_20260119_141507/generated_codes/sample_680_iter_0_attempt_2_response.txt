Step 1: The user wants the correlation coefficient between 'median household income' and 'population' for New Mexico counties.
Step 2: Filter the data to include only rows where the 'county' is in New Mexico. Note that "new mexico" appears as a row in the table, and other counties are listed (e.g., "los alamos", "santa fe", etc.). We need to identify which entries are part of New Mexico counties.
Step 3: From the table, we see that "new mexico" is a row with population and income values. However, the rest of the rows are individual counties. Since "new mexico" is a state-level entry, and the question asks about "New Mexico counties", we should exclude the state-level row and only consider the county-level rows where the county name is part of New Mexico.
Step 4: Check which counties are in New Mexico — all the county names listed (e.g., "los alamos", "santa fe", "bernalillo", etc.) are valid New Mexico counties.
Step 5: So, we will exclude the "united states" row and the "new mexico" row (as it's a state-level aggregate), and keep only the county-level entries.
Step 6: Extract the 'median household income' and 'population' columns from these filtered rows.
Step 7: Compute the correlation coefficient between these two variables using pandas.
Step 8: Print the correlation coefficient.

Note: The "new mexico" row has a large population and income, but it's not a county-level entry. So we exclude it. All other rows are county-level entries.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where county is not "united states" and not "new mexico"
filtered_df = df[(df['county'] != 'united states') & (df['county'] != 'new mexico')]

# Extract the 'median household income' and 'population' columns
income = filtered_df['median household income'].astype(float)
population = filtered_df['population'].astype(float)

# Calculate correlation coefficient
correlation = income.corr(population)
print(f"Final Answer: {correlation:.3f}")
```
