Step 1: The user wants the highest score achieved by Lionel Palairet.
Step 2: Load the dataframe.
Step 3: Filter the row where 'player' is 'lionel palairet'.
Step 4: Extract the value in the 'highest score' column.
Step 5: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for Lionel Palairet
lionel_palairet_row = df[df['player'] == 'lionel palairet']
# Extract the highest score
highest_score = lionel_palairet_row['highest score'].values[0]
print(f"Final Answer: {highest_score}")
```
