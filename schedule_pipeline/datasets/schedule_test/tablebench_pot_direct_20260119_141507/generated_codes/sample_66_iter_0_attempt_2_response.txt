Step 1: The user wants to know the number of 3-pointers made by Alpha Ambrose Kargbo.  
Step 2: Load the dataframe.  
Step 3: Filter the row where the player name is "Alpha Ambrose Kargbo".  
Step 4: Extract the value in the "3 - points" column for that row.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where player name is "Alpha Ambrose Kargbo"
alpha_ambrose_kargbo = df[df['player name'] == 'alpha ambrose kargbo']
# Extract the 3-pointers value
three_pointers = alpha_ambrose_kargbo['3 - points'].values[0]
print(f"Final Answer: {three_pointers}")
```
