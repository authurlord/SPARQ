Step 1: The user wants the correlation coefficient between the 'draw' and 'points' columns.  
Step 2: Load the dataframe.  
Step 3: Extract the 'draw' and 'points' columns.  
Step 4: Compute the Pearson correlation coefficient between them using pandas.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Calculate the correlation coefficient between 'draw' and 'points'
correlation = df['draw'].corr(df['points'])
print(f"Final Answer: {correlation:.2f}")
```
