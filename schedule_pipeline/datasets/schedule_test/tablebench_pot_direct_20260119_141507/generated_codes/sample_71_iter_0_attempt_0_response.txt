Step 1: The user wants to find the capital of Australia from the table.  
Step 2: Load the dataframe.  
Step 3: Filter the row where 'country / territory' is 'australia'.  
Step 4: Extract the value in the 'capital' column for that row.  
Step 5: Print the result.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the capital of Australia
australia_capital = df[df['country / territory'] == 'australia']['capital'].values[0]
print(f"Final Answer: {australia_capital}")
```
