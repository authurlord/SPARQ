Step 1: The user wants the total number of years served by all mayors.  
Step 2: Load the dataframe.  
Step 3: Convert 'Taking Office' and 'Leaving' columns to integers.  
Step 4: Calculate the difference between 'Leaving' and 'Taking Office' for each mayor.  
Step 5: Sum all the years served.  
Step 6: Print the total.  

Note: For the current mayor (Michel Angers), 'Leaving' is 'Current', so we treat it as not yet ended and exclude it from the calculation.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Taking Office' and 'Leaving' to integers, handling 'Current' as NaN
df['Taking Office'] = pd.to_numeric(df['Taking Office'], errors='coerce')
df['Leaving'] = pd.to_numeric(df['Leaving'], errors='coerce')

# Filter out rows where 'Leaving' is 'Current' (i.e., not a number)
df = df.dropna(subset=['Leaving'])

# Calculate years served for each mayor
df['Years Served'] = df['Leaving'] - df['Taking Office']

# Sum total years served
total_years = df['Years Served'].sum()
print(f"Final Answer: {int(total_years)}")
```
