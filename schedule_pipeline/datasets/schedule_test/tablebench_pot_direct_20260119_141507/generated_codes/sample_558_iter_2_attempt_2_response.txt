The error occurred because the year column contains string values like '—' (which represents missing data), and comparing strings with integers (e.g., '1935' >= '—') causes a TypeError. We need to filter only the years from 1935 to 1943, excluding any rows where the "Year" is not a valid integer or outside that range.

Step-by-step approach:
1. Load the DataFrame.
2. Convert the "Year" column to numeric, replacing non-numeric entries (like '—') with NaN.
3. Filter rows where the year is between 1935 and 1943 (inclusive).
4. Extract the "Quantity withdrawn" column for those rows.
5. Compute the average of the filtered values.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')
# Convert Year to numeric, treating '—' as NaN
df['Year'] = pd.to_numeric(df['Year'], errors='coerce')
# Filter rows where Year is between 1935 and 1943 inclusive
filtered_df = df[(df['Year'] >= 1935) & (df['Year'] <= 1943)]
# Calculate the average of "Quantity withdrawn" for the filtered rows
average_withdrawn = filtered_df['Quantity withdrawn'].mean()
print(f"Final Answer: {average_withdrawn:.1f}")
```
