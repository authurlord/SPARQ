Step 1: The user is asking for the correlation coefficient between the '1990 - 95' and '2006 - 10' columns. These are both percentage values representing some metric over time.
Step 2: Load the dataframe.
Step 3: Extract the two columns as numeric data (convert strings to floats).
Step 4: Compute the Pearson correlation coefficient between them.
Step 5: Print the result.

Note: The column names are given as '1990 - 95' and '2006 - 10', so we will use those exactly.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert string values to float for numerical computation
df_numeric = df[['1990 - 95', '2006 - 10']].apply(pd.to_numeric, errors='coerce')
# Calculate the correlation coefficient
correlation = df_numeric['1990 - 95'].corr(df_numeric['2006 - 10'])
print(f"Final Answer: {correlation:.3f}")
```
