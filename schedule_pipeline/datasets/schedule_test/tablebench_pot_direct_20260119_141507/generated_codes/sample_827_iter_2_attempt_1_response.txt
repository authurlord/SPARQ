The error occurred because the 'total' column contains string values ('51', '21', etc.) that need to be converted to numeric before computing median. We must convert the 'total' column to integers, then compute the median for the top 5 nations and for all nations.

Step-by-step approach:
1. Load the dataframe.
2. Convert the 'total' column to numeric (to avoid string-to-numeric conversion errors).
3. Extract the total medals for the top 5 nations (rank 1 to 5).
4. Compute the median of the top 5 nations' totals.
5. Compute the median of all nations' totals.
6. Print both medians.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'total' column to numeric (handles string values like '51', '21')
df['total'] = pd.to_numeric(df['total'], errors='coerce')

# Get total medals for top 5 nations (rank 1 to 5)
top_5_totals = df[df['rank'].le(5)]['total']
median_top_5 = top_5_totals.median()

# Get total medals for all nations
all_totals = df['total']
median_all = all_totals.median()

print(f"Final Answer: {median_top_5}, {median_all}")
```
