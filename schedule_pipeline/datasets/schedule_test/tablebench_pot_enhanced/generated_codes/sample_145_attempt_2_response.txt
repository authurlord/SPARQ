Step 1: The user wants a bar chart comparing the average 'mpg (US gallons)' for diesel and petrol fuel types.
Step 2: Load the dataframe.
Step 3: Filter data by 'Fuel Type' (diesel and petrol).
Step 4: Calculate the mean of 'mpg (US gallons)' for each fuel type.
Step 5: Create a bar chart using matplotlib to visualize the comparison.
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')
# Convert 'mpg (US gallons)' to float for calculation
df['mpg (US gallons)'] = pd.to_numeric(df['mpg (US gallons)'], errors='coerce')

# Group by 'Fuel Type' and calculate mean mpg
avg_mpg = df.groupby('Fuel Type')['mpg (US gallons)'].mean()

# Plot bar chart
plt.figure(figsize=(8, 5))
avg_mpg.plot(kind='bar', color=['blue', 'red'])
plt.title('Average MPG (US gallons) by Fuel Type')
plt.xlabel('Fuel Type')
plt.ylabel('Average MPG (US gallons)')
plt.xticks(rotation=0)
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.show()
```
