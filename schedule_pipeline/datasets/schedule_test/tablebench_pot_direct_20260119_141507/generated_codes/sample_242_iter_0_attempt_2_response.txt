Step 1: Identify the top-scoring forward (fw) and top-scoring midfielder (mf) by total goals.
Step 2: Filter the data for players with position 'fw' and 'mf'.
Step 3: Find the player with the highest total goals in each group.
Step 4: Calculate the difference between their total goals.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for forwards and midfielders
forwards = df[df['position'] == 'fw']
midfielders = df[df['position'] == 'mf']

# Find top scorer in each group by total goals
top_forward_goals = forwards['total goals'].max()
top_midfielder_goals = midfielders['total goals'].max()

# Calculate the difference
difference = top_forward_goals - top_midfielder_goals
print(f"Final Answer: {difference}")
```
