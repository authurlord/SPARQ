Step 1: The user wants the average number of Indians admitted per year from 2000 to 2010 (inclusive).
Step 2: Load the dataframe.
Step 3: Filter rows where 'year' is between '2000' and '2010'.
Step 4: Convert 'indians admitted' column to integer type.
Step 5: Calculate the mean of the 'indians admitted' column for the filtered rows.
Step 6: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data from 2000 to 2010
df_filtered = df[df['year'].between('2000', '2010')]
# Convert 'indians admitted' to integer
df_filtered['indians admitted'] = pd.to_numeric(df_filtered['indians admitted'])
# Calculate average
avg_indians = df_filtered['indians admitted'].mean()
print(f"Final Answer: {avg_indians:.1f}")
```
