Step 1: The user is asking for a forecast of points for Suzuki in the 50cc and 125cc classes for upcoming years based on historical data from 1961 to 1967. Since no specific forecasting model is mentioned, we will assume a simple linear trend based on the average points per year for each class.

Step 2: Filter the data for Suzuki in the 50cc and 125cc classes separately.

Step 3: Calculate the average points per year for each class.

Step 4: Use the average as a forecast for the upcoming year (assuming the trend continues).

Step 5: Output the forecasted points for both classes.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter data for Suzuki in 50cc and 125cc classes
suzuki_50cc = df[(df['team'] == 'suzuki') & (df['class'] == '50cc')]
suzuki_125cc = df[(df['team'] == 'suzuki') & (df['class'] == '125cc')]

# Calculate average points per year for each class
avg_50cc_points = suzuki_50cc['points'].mean()
avg_125cc_points = suzuki_125cc['points'].mean()

print(f"Final Answer: {avg_50cc_points:.1f}, {avg_125cc_points:.1f}")
```
