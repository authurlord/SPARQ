Step 1: The user wants the total number of films from 2012 to 2014 inclusive.
Step 2: Load the dataframe.
Step 3: Filter rows where the '2011' column (which represents the year) is between 2012 and 2014.
Step 4: Sum the 'Films' column for these rows.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for years 2012 to 2014
filtered_df = df[(df['-'] == '2012') | (df['-'] == '2013') | (df['-'] == '2014')]
# Sum the 'Films' column
total_films = filtered_df['Films'].sum()
print(f"Final Answer: {total_films}")
```
