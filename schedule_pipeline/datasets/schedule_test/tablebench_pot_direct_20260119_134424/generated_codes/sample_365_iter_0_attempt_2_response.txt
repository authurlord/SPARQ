Step 1: The user wants to count how many jurisdictions had more than 70% of votes in favor of prohibition.
Step 2: Load the dataframe.
Step 3: Select the 'percent for' column and convert it to float.
Step 4: Filter jurisdictions where 'percent for' > 70.
Step 5: Count the number of such jurisdictions and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'percent for' to float and filter jurisdictions with more than 70% in favor
count = df[df['percent for'].astype(float) > 70].shape[0]
print(f"Final Answer: {count}")
```
