Step 1: The user wants the median number of executions in persona across all tribunals (excluding the "total" row, as it represents an aggregate).  
Step 2: Load the dataframe.  
Step 3: Filter out the "total" row since it does not represent individual tribunals.  
Step 4: Extract the 'executions in persona' column for the remaining rows.  
Step 5: Compute the median of this column and print it.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Remove the 'total' row as it is not a tribunal
df_filtered = df[df['tribunal'] != 'total']
# Extract the 'executions in persona' column and compute median
median_executions = df_filtered['executions in persona'].median()
print(f"Final Answer: {median_executions}")
```
