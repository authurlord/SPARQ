Step 1: The user wants to find the year when the athlete achieved their personal best time in the 400m event.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'Event' is '400 m'.  
Step 4: Find the minimum time (personal best) from the 'Notes' column.  
Step 5: Identify the corresponding 'Year' for that record.  
Step 6: Print the result.

Note: The 'Notes' column contains the time in seconds, so we need to convert it to float for comparison.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for 400m events
four_hundred_m = df[df['Event'] == '400 m']
# Convert Notes to float for numerical comparison
four_hundred_m['Notes'] = pd.to_numeric(four_hundred_m['Notes'], errors='coerce')
# Find the row with the minimum time
best_time_row = four_hundred_m.loc[four_hundred_m['Notes'].idxmin()]
# Extract the year
best_year = best_time_row['Year']
print(f"Final Answer: {best_year}")
```
