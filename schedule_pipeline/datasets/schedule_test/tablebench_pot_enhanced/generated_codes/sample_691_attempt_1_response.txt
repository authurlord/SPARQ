Step 1: Identify the age group with the highest percentage. The percentages are in the '%', '%_1', and '%_2' columns, but since the question refers to the overall population distribution, we focus on the 'Both Gender' column's '%' values.
Step 2: Find the maximum percentage from the 'Both Gender' column (excluding 'All Ages' and 'TOTAL' rows).
Step 3: Find the minimum percentage from the same column.
Step 4: Calculate the difference between the highest and lowest percentages.
Step 5: Return the age group with the highest percentage and the difference.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Exclude 'All Ages' and 'TOTAL' rows for analysis
data = df[~df['Age Group'].isin(['All Ages', 'TOTAL'])]

# Find the row with the highest percentage in 'Both Gender'
max_row = data.loc[data['%'].idxmax()]
highest_age_group = max_row['Age Group']
highest_percentage = float(max_row['%'])

# Find the row with the lowest percentage in 'Both Gender'
min_row = data.loc[data['%'].idxmin()]
lowest_percentage = float(min_row['%'])

# Calculate the difference
difference = highest_percentage - lowest_percentage

print(f"Final Answer: {highest_age_group}, {difference:.2f}")
```
