The error occurred because the GDP per capita values are stored as strings, and we cannot perform arithmetic operations on strings. We need to convert the 'gdp per capita (us)' column to numeric before performing subtraction.

Step 1: Load the dataframe.
Step 2: Convert the 'gdp per capita (us)' column to numeric (to handle string-to-number conversion).
Step 3: Identify the country with the highest GDP per capita.
Step 4: Calculate the difference between that value and the GDP per capita of EC6 (1958).

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'gdp per capita (us)' to numeric, coercing errors to NaN if any
df['gdp per capita (us)'] = pd.to_numeric(df['gdp per capita (us)'], errors='coerce')

# Find the country with the highest GDP per capita
max_gdp_per_capita = df.loc[df['gdp per capita (us)'].idxmax(), 'member countries']
max_value = df['gdp per capita (us)'].max()

# GDP per capita of EC6 (1958)
ec6_gdp_per_capita = df.loc[df['member countries'] == 'ec6 (1958)', 'gdp per capita (us)'].values[0]

# Calculate the difference
difference = max_value - ec6_gdp_per_capita

print(f"Final Answer: {max_gdp_per_capita}, {difference:.0f}")
```
