Step 1: The user wants to find the player with an average of 11.4 yards per reception.
Step 2: Load the dataframe.
Step 3: Filter the row where the 'Avg.' column equals '11.4'.
Step 4: Extract and print the 'Player' name.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the player with average yards per reception equal to 11.4
player = df[df['Avg.'] == '11.4']['Player'].iloc[0]
print(f"Final Answer: {player}")
```
