Step 1: Identify the total number of trailers in 1923 and 1927.
Step 2: Extract the rows where the year is '1923' and '1927'.
Step 3: Sum the 'trailers' column for each year.
Step 4: Calculate the percentage increase using the formula: ((new - old) / old) * 100.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for 1923 and 1927
trailers_1923 = df[df['year'] == '1923']['trailers'].astype(int).sum()
trailers_1927 = df[df['year'] == '1927']['trailers'].astype(int).sum()

# Calculate percentage increase
percentage_increase = ((trailers_1927 - trailers_1923) / trailers_1923) * 100
print(f"Final Answer: {percentage_increase:.1f}")
```
