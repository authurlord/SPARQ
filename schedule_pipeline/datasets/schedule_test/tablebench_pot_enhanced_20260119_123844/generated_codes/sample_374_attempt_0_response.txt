Step 1: The user wants to count the number of mountains located in Austria.
Step 2: Load the dataframe.
Step 3: Filter rows where the 'location' column contains 'austria'.
Step 4: Count the number of such rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where location contains 'austria' (case-insensitive)
austria_mountains = df[df['location'].str.contains('austria', case=False, na=False)]
count_austria = len(austria_mountains)
print(f"Final Answer: {count_austria}")
```
