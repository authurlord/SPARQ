Step 4: Sum the values in the '12 - inch' column (excluding the total row, as it represents the aggregate).  
Step 5: Print the result.

Note: The last row is labeled "total", which is not a ship, so we exclude it when summing.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Exclude the last row (total) and sum the '12 - inch' column for all ships
```
