Step 1: The user wants to find the year when the athlete achieved their best (i.e., highest) position in the 400m event at the European Championships.  
Step 2: Filter the data for rows where 'Competition' is 'European Championships' and 'Event' is '400 m'.  
Step 3: Among these filtered rows, identify the row with the best (lowest numerical value of 'Position') position.  
Step 4: Extract the corresponding 'Year' and print it.

Note: The 'Position' column contains values like '3rd', '17th', etc. We need to convert them into numerical order for comparison. Since '3rd' is better than '17th', we need to parse the ordinal positions numerically.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter for European Championships and 400 m event
filtered_df = df[(df['Competition'] == 'European Championships') & (df['Event'] == '400 m')]

# Convert Position to numeric by extracting the number from strings like '3rd', '17th', etc.
filtered_df['Position_Num'] = filtered_df['Position'].str.extract('(\d+)').astype(int)

# Find the row with the best (minimum) position
best_row = filtered_df.loc[filtered_df['Position_Num'].idxmin()]

# Extract the year
best_year = best_row['Year']
print(f"Final Answer: {best_year}")
```
