Step 1: The user wants the difference between the average final scores of Ghent in 2010 and 2011.
Step 2: Load the dataframe.
Step 3: Filter rows where location is 'ghent' and year is either 2010 or 2011.
Step 4: Calculate the average final score for each year.
Step 5: Compute the difference between the two averages.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for Ghent in 2010 and 2011
ghent_data = df[df['location'] == 'ghent']
ghent_2010 = ghent_data[ghent_data['year'] == '2010']
ghent_2011 = ghent_data[ghent_data['year'] == '2011']

# Calculate average final scores
avg_2010 = ghent_2010['score - final'].astype(float).mean()
avg_2011 = ghent_2011['score - final'].astype(float).mean()

# Compute difference
difference = avg_2011 - avg_2010
print(f"Final Answer: {difference:.3f}")
```
