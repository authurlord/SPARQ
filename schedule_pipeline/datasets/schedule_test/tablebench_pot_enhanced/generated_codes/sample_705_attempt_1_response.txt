Step 1: The user wants to identify the staple food with the highest amount of Copper (mg) per 100g portion.
Step 2: Load the dataframe.
Step 3: Extract the 'Copper (mg)' row and find the maximum value.
Step 4: Identify the corresponding staple food (column name) with the highest value.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the row for 'Copper (mg)'
copper_row = df[df['STAPLE:'] == 'Copper (mg)']
# Get the values for each staple food
copper_values = copper_row.iloc[0, 1:]  # Exclude the first column (STAPLE:)
# Find the column with the maximum value
max_copper_staple = copper_values.idxmax()
print(f"Final Answer: {max_copper_staple}")
```
