Step 1: The user wants the difference in months between the earliest and latest 'Date Built' for locomotives with consecutive SR No.  
Step 2: Load the dataframe.  
Step 3: Convert 'Date Built' to datetime format for proper comparison.  
Step 4: Extract the earliest and latest dates from 'Date Built'.  
Step 5: Calculate the difference in months between these two dates.  
Step 6: Print the result as an integer (number of months).  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Date Built' to datetime
df['Date Built'] = pd.to_datetime(df['Date Built'], format='%B %Y')

# Find the earliest and latest 'Date Built'
earliest_date = df['Date Built'].min()
latest_date = df['Date Built'].max()

# Calculate the difference in months
months_diff = (latest_date.year - earliest_date.year) * 12 + (latest_date.month - earliest_date.month)

print(f"Final Answer: {months_diff}")
```
