Step 1: The user wants to find the year with the maximum decrease in typhus cases compared to the previous year.
Step 2: Load the dataframe.
Step 3: Convert the 'typhus' column to numeric (as it contains strings like '120', '1300', etc.).
Step 4: Calculate the year-over-year difference in typhus cases.
Step 5: Identify the year with the largest negative difference (i.e., the biggest decrease).
Step 6: Return that year.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'typhus' column to numeric
df['typhus'] = pd.to_numeric(df['typhus'], errors='coerce')

# Calculate the difference in typhus cases from the previous year
df['typhus_diff'] = df['typhus'].diff()

# Find the row with the most negative difference (largest decrease)
min_decrease_year = df.loc[df['typhus_diff'].idxmin()]['year']

print(f"Final Answer: {min_decrease_year}")
```
