Step 1: The user wants the average number of points for entries where the language is not English.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'language' column is not 'english'.  
Step 4: Calculate the mean of the 'points' column for the filtered rows.  
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where language is not 'english'
non_english_points = df[df['language'] != 'english']['points']
# Calculate the average points
average_points = non_english_points.mean()
print(f"Final Answer: {average_points:.1f}")
```
