Step 1: The user wants the median points scored by artists who sang in languages other than French.
Step 2: Load the dataframe.
Step 3: Filter out rows where the 'language' is 'french'.
Step 4: Calculate the median of the 'points' column for the filtered data.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter out rows where language is 'french'
non_french_df = df[df['language'] != 'french']
# Calculate median of points for non-French songs
median_points = non_french_df['points'].median()
print(f"Final Answer: {median_points}")
```
