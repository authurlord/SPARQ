Step 1: The user wants to forecast the issue price for 2013 based on the historical trend from 2002 to 2012.
Step 2: Load the dataframe.
Step 3: Extract the 'year' and 'issue price' columns.
Step 4: Convert 'issue price' to float for numerical analysis.
Step 5: Perform a simple linear regression to model the trend over time.
Step 6: Predict the issue price for 2013.
Step 7: Print the predicted value.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')
# Convert 'issue price' to float
df['issue price'] = df['issue price'].astype(float)
# Extract year and issue price
years = df['year'].values.reshape(-1, 1)
prices = df['issue price'].values

# Perform linear regression
model = np.polyfit(years.flatten(), prices, 1)
predicted_price = np.polyval(model, 2013)

print(f"Final Answer: {predicted_price:.2f}")
```
