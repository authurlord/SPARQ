Step 1: The user wants to find the year with the maximum increase in the number of tropical storms compared to the previous year.
Step 2: Load the dataframe.
Step 3: Convert 'number of tropical storms' to integer type for numerical comparison.
Step 4: Calculate the difference between consecutive years using the shift() method.
Step 5: Find the year with the maximum increase.
Step 6: Output the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'number of tropical storms' to integer
df['number of tropical storms'] = pd.to_numeric(df['number of tropical storms'])
# Calculate the difference in tropical storms from the previous year
df['increase'] = df['number of tropical storms'].diff()
# Find the year with the maximum increase
max_increase_year = df.loc[df['increase'].idxmax(), 'year']
print(f"Final Answer: {max_increase_year}")
```
