Step 1: Identify the 'dp / da' value for the 2003 floor-crossing event and the 1999 election event.
Step 2: Calculate the difference between the 1999 election's 'dp / da' value and the 2003 floor-crossing event's 'dp / da' value.
Step 3: Since the question asks for the minimum number of additional 'dp / da' values needed for the 2003 event to surpass the 1999 election, we compute how many more are required to exceed the 1999 value.
Step 4: Use the given data to extract the relevant values and perform the calculation.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Extract 'dp / da' values for the 2003 floor-crossing and 1999 election events
dp_da_2003 = df[df['event'] == '2003 floor - crossing']['dp / da'].values[0]
dp_da_1999 = df[df['event'] == '1999 election']['dp / da'].values[0]

# Convert to integers
dp_da_2003 = int(dp_da_2003)
dp_da_1999 = int(dp_da_1999)

# Calculate minimum additional 'dp / da' values needed to surpass 1999 election
additional_needed = dp_da_1999 - dp_da_2003 + 1

print(f"Final Answer: {additional_needed}")
```
