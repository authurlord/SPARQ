Step 1: The user wants to identify the nation that won exactly 30 silver medals.
Step 2: Load the dataframe.
Step 3: Filter the rows where 'Silver' column equals 30.
Step 4: Extract the 'Nation' from the filtered row and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row where Silver is 30
nation_with_30_silver = df[df['Silver'] == '30']['Nation'].values[0]
print(f"Final Answer: {nation_with_30_silver}")
```
