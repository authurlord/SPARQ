The error occurred because the "area (km 2 )" column contains string values (e.g., '682.1'), not numeric. We need to convert this column to float before performing comparisons.

Step-by-step approach:
1. Load the dataframe.
2. Convert the "area (km 2 )" and "human development index (2000)" columns to numeric (float) to enable mathematical operations.
3. Filter rows where area > 700 and human development index > 0.7.
4. Compute the average population density of the filtered rows.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Convert relevant columns to numeric, handling any parsing issues
df['area (km 2 )'] = pd.to_numeric(df['area (km 2 )'], errors='coerce')
df['population density ( / km 2 )'] = pd.to_numeric(df['population density ( / km 2 )'], errors='coerce')
df['human development index (2000)'] = pd.to_numeric(df['human development index (2000)'], errors='coerce')

# Filter municipalities with area > 700 and HDI > 0.7
filtered_df = df[(df['area (km 2 )'] > 700) & (df['human development index (2000)'] > 0.7)]

# Calculate average population density of filtered rows
average_density = filtered_df['population density ( / km 2 )'].mean()

print(f"Final Answer: {average_density:.2f}")
```
