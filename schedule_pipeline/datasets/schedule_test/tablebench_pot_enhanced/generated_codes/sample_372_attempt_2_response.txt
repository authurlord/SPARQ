Step 1: The user wants to count how many cost categories have a percentage increase greater than 5% from 2017 to 2018.
Step 2: Load the dataframe.
Step 3: Convert the 'Percent Increase (Decrease)' column to numeric, handling negative values and 'nm' (not meaningful) entries.
Step 4: Filter rows where the percentage increase is greater than 5.
Step 5: Count the number of such rows and print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Percent Increase (Decrease)' to numeric, replacing 'nm' with NaN
df['Percent Increase (Decrease)'] = pd.to_numeric(df['Percent Increase (Decrease)'], errors='coerce')
# Drop rows where the percentage change is 'nm' or NaN
df_clean = df.dropna(subset=['Percent Increase (Decrease)'])
# Filter for percentage increase > 5
count_high_increase = df_clean[df_clean['Percent Increase (Decrease)'] > 5].shape[0]
print(f"Final Answer: {count_high_increase}")
```
