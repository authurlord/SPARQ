Step 1: The user wants to calculate the number of R class locomotives in service at the end of 1931.
Step 2: The R class in service at the start of 1931 is given as 11.
Step 3: One locomotive was withdrawn during the year.
Step 4: Subtract the number withdrawn from the initial count to get the final count.
Step 5: Print the result.

```python
# Given data
R_class_start_1931 = 11
withdrawn_1931 = 1

# Calculate R class in service at the end of 1931
R_class_end_1931 = R_class_start_1931 - withdrawn_1931
print(f"Final Answer: {R_class_end_1931}")
```
