Step 1: The user wants to find the player with an average of 11.4 yards per reception.
Step 2: Load the dataframe.
Step 3: Filter the row where the 'Avg.' column is '11.4'.
Step 4: Extract and print the player's name.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the player with Avg. = 11.4
player = df[df['Avg.'] == '11.4']['Player'].iloc[0]
print(f"Final Answer: {player}")
```
