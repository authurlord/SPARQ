The error occurred because the 'year' column contains string values (e.g., '1968'), and we cannot directly compare strings with integers using `>=`. We need to convert the 'year' column to integers before filtering.

Step-by-step approach:
1. Load the dataframe.
2. Convert the 'year' column to integer type.
3. Filter rows where the year is between 1960 and 1980 (inclusive).
4. Calculate the average number of floors for the filtered buildings.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'year' to integer type
df['year'] = df['year'].astype(int)
# Filter buildings constructed between 1960 and 1980 (inclusive)
filtered_buildings = df[(df['year'] >= 1960) & (df['year'] <= 1980)]
# Calculate average number of floors
avg_floors = filtered_buildings['floors'].mean()
print(f"Final Answer: {avg_floors:.1f}")
```
