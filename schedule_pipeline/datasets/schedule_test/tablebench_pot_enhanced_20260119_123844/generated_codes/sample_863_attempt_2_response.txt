Step 1: The user wants to find the year with the highest average issue price and the difference between that year's average and the lowest year's average.
Step 2: Load the dataframe.
Step 3: Convert 'issue price' column to float for numerical operations.
Step 4: Group by 'year' and calculate the average issue price per year.
Step 5: Find the year with the highest average issue price and the year with the lowest.
Step 6: Compute the difference between the two averages.
Step 7: Print the result in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'issue price' to float
df['issue price'] = pd.to_numeric(df['issue price'])
# Group by 'year' and calculate average issue price
avg_price_by_year = df.groupby('year')['issue price'].mean()
# Find the year with highest and lowest average issue price
highest_year = avg_price_by_year.idxmax()
lowest_year = avg_price_by_year.idxmin()
# Calculate the difference
difference = avg_price_by_year.max() - avg_price_by_year.min()
print(f"Final Answer: {highest_year}, {difference:.2f}")
```
