Step 1: Identify the locomotive built in the earliest year and the one built in the latest year.
Step 2: Extract the 'built' column and convert it to integer for comparison.
Step 3: Find the minimum and maximum values in the 'built' column.
Step 4: Retrieve the corresponding locomotive names for the earliest and latest build years.
Step 5: Calculate the difference between the latest and earliest build years.
Step 6: Print the result in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'built' column to integer
df['built'] = pd.to_numeric(df['built'], errors='coerce')

# Find the locomotive built in the earliest year
earliest_year = df['built'].min()
earliest_locomotive = df[df['built'] == earliest_year]['locomotive'].values[0]

# Find the locomotive built in the latest year
latest_year = df['built'].max()
latest_locomotive = df[df['built'] == latest_year]['locomotive'].values[0]

# Calculate the difference
difference = latest_year - earliest_year

print(f"Final Answer: {earliest_locomotive}, {difference}")
```
