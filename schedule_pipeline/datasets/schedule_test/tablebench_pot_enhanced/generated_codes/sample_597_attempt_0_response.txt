Step 1: The user wants the average number of viewers for the first 5 episodes.
Step 2: Load the dataframe.
Step 3: Select the 'viewers (millions)' column and extract the first 5 values.
Step 4: Calculate the mean of these values and print.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the first 5 episodes' viewers
first_five_viewers = df['viewers (millions)'].head(5)
# Calculate the average
average_viewers = first_five_viewers.mean()
print(f"Final Answer: {average_viewers:.2f}")
```
