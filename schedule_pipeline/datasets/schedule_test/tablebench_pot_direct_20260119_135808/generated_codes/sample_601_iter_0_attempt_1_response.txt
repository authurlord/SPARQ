Step 1: The user wants to calculate the number of R class locomotives in service at the end of 1931.
Step 2: Load the dataframe.
Step 3: Extract the 'R class in service at start of year' and 'Quantity withdrawn' for the year 1931.
Step 4: Subtract the quantity withdrawn from the starting number to get the ending count.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for the year 1931
row_1931 = df[df['Year'] == '1931']
# Calculate R class in service at the end of 1931
r_class_end = int(row_1931['R class in service at start of year'].iloc[0]) - int(row_1931['Quantity withdrawn'].iloc[0])
print(f"Final Answer: {r_class_end}")
```
