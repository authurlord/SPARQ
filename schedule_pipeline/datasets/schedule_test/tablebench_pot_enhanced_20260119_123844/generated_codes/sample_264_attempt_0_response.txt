Step 1: The user wants the total population of places where Afrikaans is the most spoken language.
Step 2: Load the dataframe.
Step 3: Filter rows where 'most spoken language' is 'afrikaans'.
Step 4: Sum the 'population' column for these rows and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where 'most spoken language' is 'afrikaans'
afrikaans_places = df[df['most spoken language'] == 'afrikaans']
# Calculate total population
total_population = afrikaans_places['population'].sum()
print(f"Final Answer: {total_population}")
```
