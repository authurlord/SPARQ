Step 1: The user wants the difference in enrollment between the institution with the highest enrollment and the lowest enrollment.
Step 2: Load the dataframe.
Step 3: Convert the 'enrollment' column to numeric (it is currently stored as string).
Step 4: Find the maximum and minimum enrollment values.
Step 5: Calculate the difference and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'enrollment' column to numeric
df['enrollment'] = pd.to_numeric(df['enrollment'])
# Calculate the difference between max and min enrollment
enrollment_diff = df['enrollment'].max() - df['enrollment'].min()
print(f"Final Answer: {enrollment_diff}")
```
