The error occurred because the 'points' column was being treated as a string or mixed-type, likely due to the first row being a header row with the same column names. We need to ensure that the data is properly parsed and that the 'points' column is numeric.

Step-by-step approach:
1. Load the DataFrame.
2. Identify that the first row contains column headers (not data), so we skip it.
3. Ensure all relevant columns (played, drawn, lost, points for, points against, tries for, tries against, try bonus, losing bonus) are numeric.
4. Calculate the contribution of each factor to the 'points' total using correlation or regression-like analysis — however, since the question asks which factors "significantly contribute", we interpret this as identifying which factors have the highest correlation with 'points'.
5. Compute the Pearson correlation between each factor and the 'points' column.
6. Select the top 3 factors with the highest absolute correlation.

Note: Since the 'points' column is already present and numeric in the data (after proper parsing), we can safely compute correlations.

```python
import pandas as pd

# Load the data
df = pd.read_csv('table.csv')

# Drop the first row which contains column headers (it's duplicated)
# The first row is actually the header, so we don't need to drop it — the column names are already set correctly
# But the first data row is a club name, so we skip the first row if it's just headers
# In this case, the first row is actually a header row with club names, so we start from index 1
df = df.iloc[1:]  # Skip the first row (which is the header)

# Convert relevant columns to numeric, handling any potential issues
numeric_columns = ['played', 'drawn', 'lost', 'points for', 'points against', 'tries for', 'tries against', 'try bonus', 'losing bonus']
df[numeric_columns] = df[numeric_columns].apply(pd.to_numeric, errors='coerce')

# Drop rows with NaN values after conversion
df = df.dropna()

# Compute correlation with 'points'
correlations = df[numeric_columns].corrwith(df['points'])

# Get top 3 factors with highest absolute correlation
top_3_factors = correlations.abs().sort_values(ascending=False).head(3).index.tolist()

print(f"Final Answer: {', '.join(top_3_factors)}")
```
