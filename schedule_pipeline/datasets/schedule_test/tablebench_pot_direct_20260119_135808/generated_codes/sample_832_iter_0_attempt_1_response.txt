Step 1: The user wants the standard deviation of the 'horse-power' for warships built before 1870.
Step 2: Load the dataframe.
Step 3: Filter rows where 'built year' is less than 1870.
Step 4: Convert 'horse-power' to numeric and calculate the standard deviation.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter warships built before 1870
df_before_1870 = df[df['built year'] < 1870]
# Convert 'horse-power' to numeric and calculate standard deviation
std_hp = df_before_1870['horse - power'].astype(float).std()
print(f"Final Answer: {std_hp:.2f}")
```
