Step 1: The user wants the average change in qualifying score for the 'all around' event between 'olympic trials' and 'us championships' in 2008.
Step 2: Load the dataframe.
Step 3: Filter rows where the event is 'all around', competition is either 'olympic trials' or 'us championships', and year is 2008.
Step 4: Extract the qualifying scores for both competitions.
Step 5: Calculate the difference (change) between the two scores.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter data for 'all around' event in 2008
all_around_data = df[(df['event'] == 'all around') & (df['year'] == '2008')]

# Extract qualifying scores for 'olympic trials' and 'us championships'
olympic_trials_score = all_around_data[all_around_data['competition'] == 'olympic trials']['qualifying score'].values[0]
us_championships_score = all_around_data[all_around_data['competition'] == 'us championships']['qualifying score'].values[0]

# Calculate the change
change = float(olympic_trials_score) - float(us_championships_score)

print(f"Final Answer: {change:.1f}")
```
