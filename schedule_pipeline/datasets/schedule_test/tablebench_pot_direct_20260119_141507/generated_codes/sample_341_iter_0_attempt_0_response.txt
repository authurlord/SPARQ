Step 1: The user is asking for the year when the athlete won a gold medal in the 400m event at the CARIFTA Games (U-20) with a personal best (PB) time.  
Step 2: Look for rows where:
   - "Event" is "400 m"
   - "Competition" is "CARIFTA Games (U-20)"
   - "Position" is "1st" (gold medal)
   - "Notes" contains "PB" (personal best)
Step 3: Extract the "Year" from such a row.

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter rows based on conditions
filtered_df = df[
    (df['Event'] == '400 m') &
    (df['Competition'] == 'CARIFTA Games (U-20)') &
    (df['Position'] == '1st') &
    (df['Notes'].str.contains('PB', case=False))
]

# Get the year of the first match (only one such row expected)
year = filtered_df.iloc[0]['Year'] if not filtered_df.empty else None
print(f"Final Answer: {year}")
```
