Step 1: The user wants the total number of votes cast (i.e., the "total" column) in counties where Obama received more than 60% of the votes.  
Step 2: Load the dataframe.  
Step 3: Filter rows where 'obama%' > 60%.  
Step 4: Sum the 'total' column for those filtered rows.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter counties where Obama received more than 60%
filtered_df = df[df['obama%'].str.replace('%', '').astype(float) > 60]
# Sum the total votes in those counties
total_votes = filtered_df['total'].sum()
print(f"Final Answer: {total_votes}")
```
