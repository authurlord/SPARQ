Step 1: The user wants the crude birth rate (per 1000) for the year 1995.  
Step 2: Locate the row where the year is 1995 in the table.  
Step 3: Extract the value in the "Crude birth rate (per 1000)" column for that row.  
Step 4: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the row where the year is 1995 and get the crude birth rate
crude_birth_rate_1995 = df[df['Unnamed: 0'] == '1995']['Crude birth rate (per 1000)'].values[0]
print(f"Final Answer: {crude_birth_rate_1995}")
```
