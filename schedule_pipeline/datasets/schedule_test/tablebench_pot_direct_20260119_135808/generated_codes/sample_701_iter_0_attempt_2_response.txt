Step 1: The user wants to find the year with the highest number of injuries.
Step 2: Load the dataframe.
Step 3: Parse the 'Injuries (US $000)' column, handling non-numeric values like 'no data' and '202 (estimate)'.
Step 4: Convert the injuries to numeric, replacing invalid entries with NaN.
Step 5: Find the year corresponding to the maximum injury value.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Clean the 'Injuries (US $000)' column by converting to numeric, coercing errors to NaN
df['Injuries (US $000)'] = pd.to_numeric(df['Injuries (US $000)'], errors='coerce')
# Find the row with the maximum injuries
max_injuries_row = df.loc[df['Injuries (US $000)'].idxmax()]
year_with_max_injuries = max_injuries_row['Year']
print(f"Final Answer: {year_with_max_injuries}")
```
