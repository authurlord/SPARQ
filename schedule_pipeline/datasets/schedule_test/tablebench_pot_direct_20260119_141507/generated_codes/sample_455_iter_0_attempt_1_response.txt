- Incorrect or inconsistent date formats (e.g., "abc" instead of a year).
- Missing or non-numeric values in critical fields like "whenbuilt" or "withdrawn".
- Inconsistent locations (e.g., "eastleigh" vs "brighton").
- Invalid years (e.g., "1234" for when built, which is likely an error).

Step 2: Check for invalid or suspicious entries in the "whenbuilt" and "withdrawn" columns.
- "whenbuilt" should ideally be a year (e.g., 1948, 1949, etc.). Any value like "abc", "march 1950", "april 1950", or "1234" may be anomalies.
- "withdrawn" should also be a year. Values like "1967", "1964", "1966" are fine, but if a withdrawn year is earlier than whenbuilt, it's invalid.

Step 3: Identify rows where:
- "whenbuilt" is not a valid year (e.g., contains text or out-of-range values).
- "whenbuilt" is "abc" or "march 1950" (non-standard format).
- "withdrawn" is earlier than "whenbuilt".

Step 4: Print the list of such anomalies with their names and details.

import pandas as pd

df = pd.read_csv('table.csv')

# Identify anomalies
anomalies = []

# Check for invalid 'whenbuilt' values
invalid_whenbuilt = df[df['whenbuilt'].apply(lambda x: not str(x).isdigit() and str(x).lower() not in ['abc', 'march 1950', 'april 1950', 'may 1950', 'january 1951'])]
for idx, row in invalid_whenbuilt.iterrows():
    anomalies.append({
        'name': row['name'],
        'whenbuilt': row['whenbuilt'],
        'withdrawn': row['withdrawn']
    })

# Check for withdrawn earlier than whenbuilt
for idx, row in df.iterrows():
    whenbuilt_str = str(row['whenbuilt'])
    withdrawn_str = str(row['withdrawn'])
    
    # Skip if whenbuilt is not a number or date
    if not whenbuilt_str.isdigit() and whenbuilt_str.lower() not in ['abc', 'march 1950', 'april 1950', 'may 1950', 'january 1951']:
        continue
        
    # If whenbuilt is a string like "march 1950", convert to year
    if 'march' in whenbuilt_str or 'april' in whenbuilt_str or 'may' in whenbuilt_str or 'january' in whenbuilt_str:
        year_part = whenbuilt_str.split()[-1]
        try:
            whenbuilt_year = int(year_part)
        except:
            continue
    else:
        try:
            whenbuilt_year = int(whenbuilt_str)
        except:
            continue
            
    # Convert withdrawn to integer
    try:
        withdrawn_year = int(withdrawn_str)
    except:
        continue
        
    # If withdrawn is before whenbuilt, it's an anomaly
    if withdrawn_year < whenbuilt_year:
        anomalies.append({
            'name': row['name'],
            'whenbuilt': row['whenbuilt'],
            'withdrawn': row['withdrawn']
        })

# Print anomalies
if anomalies:
    print("Anomalies found:")
    for anomaly in anomalies:
        print(f"Name: {anomaly['name']}, When Built: {anomaly['whenbuilt']}, Withdrawn: {anomaly['withdrawn']}")
else:
    print("No anomalies found.")
