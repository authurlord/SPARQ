Step 1: The user wants the standard deviation of the horse-power for warships built before 1870.
Step 2: Load the dataframe.
Step 3: Convert the 'horse - power' column to numeric, as it's currently stored as strings.
Step 4: Filter rows where 'built year' is less than 1870.
Step 5: Calculate the standard deviation of the 'horse - power' column for the filtered data.
Step 6: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'horse - power' column to numeric
df['horse - power'] = pd.to_numeric(df['horse - power'], errors='coerce')
# Filter warships built before 1870
df_before_1870 = df[df['built year'] < 1870]
# Calculate standard deviation of horse-power for those warships
std_hp = df_before_1870['horse - power'].std()
print(f"Final Answer: {std_hp:.2f}")
```
