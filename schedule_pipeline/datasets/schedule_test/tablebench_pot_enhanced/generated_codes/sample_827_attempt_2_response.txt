Step 1: The user is asking for two things:
- The median total number of medals won by nations in the top 5 rankings (i.e., rows with rank 1 to 5).
- The median total number of medals won by all countries (across all rows).

Step 2: Load the dataframe.
Step 3: Extract the 'total' column, which contains the total medals.
Step 4: Filter the data for the top 5 ranks and compute the median for that subset.
Step 5: Compute the median for all nations.
Step 6: Print both results.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'total' column to integer for numerical operations
df['total'] = pd.to_numeric(df['total'])

# Median for top 5 ranked nations
top_5_medals = df[df['rank'].astype(int) <= 5]['total']
median_top_5 = top_5_medals.median()

# Median for all nations
median_all = df['total'].median()

print(f"Final Answer: {median_top_5}, {median_all}")
```
