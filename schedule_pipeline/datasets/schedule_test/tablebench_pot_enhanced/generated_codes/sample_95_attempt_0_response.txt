Step 1: The user wants to know the points scored by 'llanhilleth rfc' in the league season.
Step 2: Load the dataframe.
Step 3: Filter the row where 'club' is 'llanhilleth rfc'.
Step 4: Extract the value from the 'points' column and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter the row for 'llanhilleth rfc'
llanhilleth_points = df[df['club'] == 'llanhilleth rfc']['points'].iloc[0]
print(f"Final Answer: {llanhilleth_points}")
```
