Step 1: The user wants to calculate the number of R class locomotives in service at the end of 1931.
Step 2: The R class in service at the start of 1931 is given as 11.
Step 3: One locomotive was withdrawn during the year, so subtract 1 from the starting number.
Step 4: The result is the number of R class locomotives in service at the end of 1931.
```python
# Given data
R_class_start_1931 = 11
quantity_withdrawn_1931 = 1

# Calculate R class in service at the end of 1931
R_class_end_1931 = R_class_start_1931 - quantity_withdrawn_1931
print(f"Final Answer: {R_class_end_1931}")
```
