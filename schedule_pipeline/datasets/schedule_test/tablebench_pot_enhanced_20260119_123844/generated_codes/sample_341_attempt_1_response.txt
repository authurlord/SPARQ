Step 1: The user wants to find the year when the athlete won a gold medal (1st position) in the 400m event at the CARIFTA Games (U-20) with a personal best (PB) time.

Step 2: Load the dataframe.

Step 3: Filter rows where:
- Competition is "CARIFTA Games (U-20)"
- Event is "400 m"
- Position is "1st"
- Notes contain "PB" (indicating personal best)

Step 4: Extract the 'Year' from the filtered rows and return it.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for CARIFTA Games (U-20), 400 m, 1st position, and PB in notes
filtered_df = df[(df['Competition'] == 'CARIFTA Games (U-20)') & 
                 (df['Event'] == '400 m') & 
                 (df['Position'] == '1st') & 
                 (df['Notes'].str.contains('PB', na=False))]

# Get the year from the filtered result
year = filtered_df['Year'].iloc[0]
print(f"Final Answer: {year}")
```
