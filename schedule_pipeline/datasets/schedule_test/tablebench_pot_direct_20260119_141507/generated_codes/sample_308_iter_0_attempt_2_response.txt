Step 1: Identify the relevant data — we need to find songs written by Glen Campbell.  
Step 2: Filter the rows where the 'Artist' is "Glen Campbell".  
Step 3: Check the 'Year' column to see if the year falls within the 1980s (1980–1989).  
Step 4: Count how many such entries exist.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter songs by Glen Campbell and check if year is in the 1980s
glen_campbell_1980s = df[(df['Artist'] == 'Glen Campbell') & (df['Year'].between(1980, 1989))]
count = len(glen_campbell_1980s)
print(f"Final Answer: {count}")
```
