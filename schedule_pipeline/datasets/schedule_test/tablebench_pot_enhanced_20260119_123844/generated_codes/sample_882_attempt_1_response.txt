Step 1: The user wants to find the season in which Liverpool scored the highest total number of goals in the Premier League.
Step 2: Load the dataframe.
Step 3: Filter rows where Club is 'Liverpool' and Season is not 'Liverpool Total'.
Step 4: Focus on the 'League' column to identify Premier League seasons (where 'League' is 'Premier League').
Step 5: Extract the 'Total' column (total goals) for those seasons and find the season with the maximum value.
Step 6: Return the corresponding season.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for Liverpool and Premier League seasons
liverpool_premier = df[(df['Club'] == 'Liverpool') & (df['League'] == 'Premier League')]
# Find the season with the highest total goals
max_goals_season = liverpool_premier.loc[liverpool_premier['Total'].idxmax(), 'Season']
print(f"Final Answer: {max_goals_season}")
```
