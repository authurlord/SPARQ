Step 1: The user is asking for the year when the athlete won a gold medal in a 20 km event.  
Step 2: A "gold medal" corresponds to a "1st" position in the competition.  
Step 3: We need to filter rows where the "Position" is "1st" and the "Event" is "20 km".  
Step 4: Extract the corresponding "Year" from those rows.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where Position is '1st' and Event is '20 km'
gold_medal_years = df[(df['Position'] == '1st') & (df['Event'] == '20 km')]['Year']
# Since the question asks for "in which year", we return the year(s) as a list
print(f"Final Answer: {list(gold_medal_years)}")
```
