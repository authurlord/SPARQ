Step 1: The user wants the top 3 mountains in New Zealand ranked by elevation from highest to lowest.
Step 2: Load the dataframe.
Step 3: Filter data for mountains in New Zealand (all entries are in New Zealand, so no filtering needed).
Step 4: Sort the 'elevation (m)' column in descending order.
Step 5: Select the top 3 rows and extract the peak names.
Step 6: Print the result in the required format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Sort by elevation (m) in descending order and get top 3
top_3_mountains = df.sort_values(by='elevation (m)', ascending=False).head(3)['peak'].tolist()
print(f"Final Answer: {', '.join(top_3_mountains)}")
```
