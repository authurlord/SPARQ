Step 1: The user wants the total average viewership of the top 5 TV shows.
Step 2: Load the dataframe.
Step 3: Select the 'average' column and extract the first 5 values (top 5 shows).
Step 4: Sum these values and print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Extract the 'average' column for top 5 shows and sum them
total_average_viewership = df['average'].head(5).sum()
print(f"Final Answer: {total_average_viewership}")
```
