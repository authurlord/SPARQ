Step 1: The user wants to calculate the number of R class locomotives in service at the end of 1931.
Step 2: The number at the start of 1931 is 11, and 1 locomotive was withdrawn during the year.
Step 3: Subtract the number withdrawn from the starting number to get the ending count.
Step 4: Print the result.

```python
# Given data for 1931
R_class_start = 11
quantity_withdrawn = 1

# Calculate R class in service at the end of 1931
R_class_end = R_class_start - quantity_withdrawn
print(f"Final Answer: {R_class_end}")
```
