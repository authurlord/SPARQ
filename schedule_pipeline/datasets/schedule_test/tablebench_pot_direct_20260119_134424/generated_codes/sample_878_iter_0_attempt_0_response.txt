Step 1: The user wants to find the difference in points between the singer with the highest score and the singer with the 5th highest score.
Step 2: Load the dataframe.
Step 3: Sort the 'points' column in descending order.
Step 4: Extract the top 1 (highest) and 5th highest scores.
Step 5: Calculate the difference and print it.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Sort by points in descending order
df_sorted = df.sort_values(by='points', ascending=False)
# Get the highest score (1st) and 5th highest score
highest_points = df_sorted.iloc[0]['points']
fifth_highest_points = df_sorted.iloc[4]['points']
# Calculate the difference
difference = int(highest_points) - int(fifth_highest_points)
print(f"Final Answer: {difference}")
```
