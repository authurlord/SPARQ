Step 1: Identify the total number of trailers in 1923 and 1927 from the data.
Step 2: Calculate the percentage increase using the formula: ((new - old) / old) * 100.
Step 3: Load the dataframe.
Step 4: Filter rows where 'year' is '1923' and '1927', extract the 'trailers' values.
Step 5: Compute the percentage increase and print.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for 1923 and 1927
trailers_1923 = df[df['year'] == '1923']['trailers'].sum()
trailers_1927 = df[df['year'] == '1927']['trailers'].sum()

# Calculate percentage increase
percentage_increase = ((trailers_1927 - trailers_1923) / trailers_1923) * 100
print(f"Final Answer: {percentage_increase:.1f}")
```
