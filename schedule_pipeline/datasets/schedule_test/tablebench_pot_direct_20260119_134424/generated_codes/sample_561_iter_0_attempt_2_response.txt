Step 1: Filter the data for songs released between 1942 and 1946 (inclusive).
Step 2: Extract the 'US Chart position' column.
Step 3: Convert the values to numeric, handling any non-numeric entries (like '10 (R&B)') by removing the text part or skipping them.
Step 4: Calculate the average of valid US Chart positions.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for years 1942 to 1946
df_filtered = df[df['Year'].astype(int).between(1942, 1946)]
# Extract US Chart position and clean non-numeric values
df_filtered['US Chart position'] = df_filtered['US Chart position'].str.replace(r'\(.*\)', '', regex=True).astype(float)
# Calculate average
avg_position = df_filtered['US Chart position'].mean()
print(f"Final Answer: {avg_position:.1f}")
```
