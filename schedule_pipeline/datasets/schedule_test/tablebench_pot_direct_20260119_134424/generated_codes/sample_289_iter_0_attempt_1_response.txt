Step 1: Filter the data to include only municipalities in the "la haute - côte - nord" regional county municipality.
Step 2: Extract the population values for these municipalities.
Step 3: Calculate the average population of municipalities in this region.
Step 4: Find the smallest population in the region.
Step 5: Compute the difference between the average population and the smallest population.
Step 6: Print the result as the minimum number of people to be added.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for 'la haute - côte - nord' region
la_haute_cote_nord = df[df['regional county municipality'] == 'la haute - côte - nord']
# Convert population to integer
la_haute_cote_nord['population'] = la_haute_cote_nord['population'].astype(int)
# Calculate average population in the region
avg_population = la_haute_cote_nord['population'].mean()
# Find minimum population
min_population = la_haute_cote_nord['population'].min()
# Calculate number of people to add
people_to_add = avg_population - min_population
print(f"Final Answer: {int(people_to_add)}")
```
