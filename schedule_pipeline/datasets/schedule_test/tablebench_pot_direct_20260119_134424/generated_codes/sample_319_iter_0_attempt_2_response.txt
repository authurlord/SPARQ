Step 1: The user wants to find the year when the athlete won the Stockholm Marathon with a time less than 2:35:00.
Step 2: Load the dataframe.
Step 3: Filter rows where 'Event' is 'Marathon' and 'Venue' is 'Stockholm, Sweden'.
Step 4: Among these, filter rows where the 'Notes' (time) is less than 2:35:00.
Step 5: Extract the 'Year' from the filtered row and print it.

Note: The time in 'Notes' is in format 'HH:MM:SS'. We can compare it as a string since the format is consistent and lexicographical comparison works for times in this format.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for Stockholm Marathon and time less than 2:35:00
stockholm_marathon = df[(df['Event'] == 'Marathon') & (df['Venue'] == 'Stockholm, Sweden')]
# Filter by time < 2:35:00
fast_times = stockholm_marathon[stockholm_marathon['Notes'] < '2:35:00']
# Extract the year
year = fast_times['Year'].iloc[0]
print(f"Final Answer: {year}")
```
