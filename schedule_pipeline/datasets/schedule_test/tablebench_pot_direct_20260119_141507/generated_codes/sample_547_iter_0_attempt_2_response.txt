Step 1: The user wants the difference in average final scores between Ghent in 2010 and 2011.  
Step 2: Filter the data for events in Ghent.  
Step 3: Separate the data by year (2010 and 2011).  
Step 4: Calculate the average final score for each year.  
Step 5: Compute the difference between the two averages.  

```python
import pandas as pd

df = pd.read_csv('table.csv')

# Filter rows where location is 'ghent'
ghent_data = df[df['location'] == 'ghent']

# Extract final scores for 2010 and 2011
scores_2010 = ghent_data[ghent_data['year'] == '2010']['score - final'].astype(float)
scores_2011 = ghent_data[ghent_data['year'] == '2011']['score - final'].astype(float)

# Calculate average final scores
avg_2010 = scores_2010.mean()
avg_2011 = scores_2011.mean()

# Compute the difference
difference = avg_2011 - avg_2010
print(f"Final Answer: {difference:.3f}")
```
