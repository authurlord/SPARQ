The error occurred because the year "total" is included in the data and is a string, so we cannot directly filter rows from 2005 to 2009 when using boolean indexing with `year >= '2005'` and `year <= '2009'`. We need to exclude the row where `team == 'castleford tigers'` and `year == 'total'`.

Step-by-step approach:
1. Load the dataframe.
2. Filter rows where the team is "castleford tigers" and the year is between 2005 and 2009 (inclusive), excluding the "total" row.
3. Compute the average of the "apps" column for these filtered rows.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter rows where team is 'castleford tigers' and year is between 2005 and 2009 (excluding 'total')
filtered_df = df[(df['team'] == 'castleford tigers') & (df['year'].astype(str).str.startswith('200')) & (df['year'] >= 2005) & (df['year'] <= 2009)]
# Exclude the total row (which has year 'total')
filtered_df = filtered_df[filtered_df['year'] != 'total']
# Calculate the average number of appearances (apps)
avg_apps = filtered_df['apps'].mean()
print(f"Final Answer: {avg_apps:.1f}")
```
