The error occurred because the "total" column contains string values (e.g., '10', '11') rather than numeric values. We need to convert them to integers before computing the standard deviation.

Step-by-step approach:
1. Load the DataFrame.
2. Convert the "total" column from strings to integers.
3. Compute the standard deviation of the "total" column.
4. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'total' column to integer type to avoid type errors
df['total'] = df['total'].astype(int)
# Calculate the standard deviation of the 'total' column
std_total = df['total'].std()
print(f"Final Answer: {std_total:.1f}")
```
