The error occurred because the "Political Rights" column contains string values (like '6', '7') that are not properly converted to numeric type when performing arithmetic operations. We need to ensure the data is converted to numeric before computing the standard deviation.

Step-by-step approach:
1. Load the dataframe.
2. Filter rows from 1975 to 1990 (inclusive) based on the 'Year' column.
3. Convert the 'Political Rights' column to numeric (to handle string values like '6').
4. Compute the standard deviation of the filtered numeric values.
5. Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Political Rights' to numeric, coercing errors to NaN
df['Political Rights'] = pd.to_numeric(df['Political Rights'], errors='coerce')

# Filter data from 1975 to 1990 inclusive
filtered_df = df[(df['Year'] >= '1975') & (df['Year'] <= '1990')]

# Compute standard deviation of 'Political Rights' in the filtered data
std_political_rights = filtered_df['Political Rights'].std()

print(f"Final Answer: {std_political_rights:.2f}")
```
