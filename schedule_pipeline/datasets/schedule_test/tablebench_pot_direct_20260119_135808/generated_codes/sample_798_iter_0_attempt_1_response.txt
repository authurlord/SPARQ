Step 1: The user wants the average annual change in the number of Conservative councillors from 1947 to 1972.  
Step 2: Load the dataframe.  
Step 3: Extract the 'Conservative councillors' values for the years 1947 and 1972.  
Step 4: Calculate the total change (final - initial) and divide by the number of years (1972 - 1947 = 25 years).  
Step 5: Print the result as a float.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter data for the years 1947 and 1972
start_value = df[df['Year'] == '1947']['Conservative councillors'].values[0]
end_value = df[df['Year'] == '1972']['Conservative councillors'].values[0]

# Calculate average annual change
annual_change = (int(end_value) - int(start_value)) / (1972 - 1947)
print(f"Final Answer: {annual_change:.2f}")
```
