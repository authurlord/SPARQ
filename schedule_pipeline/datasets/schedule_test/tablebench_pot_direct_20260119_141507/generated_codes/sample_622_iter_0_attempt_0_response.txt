Step 1: The user wants the total research funding (in thousands) for universities located in London.  
Step 2: Load the dataframe.  
Step 3: Filter rows where the 'location' is 'london' (or contains 'london' — note that some entries like 'egham' are in London but not the city itself; however, based on the data, only institutions explicitly listed as 'london' or within London boroughs should be considered). From the table, we see 'london' appears in several entries: Birkbeck, Goldsmiths, Institute of Education, Royal Holloway, SOAS.  
Step 4: Extract the 'research funding (000)' column for these London-based institutions.  
Step 5: Sum the values and print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter universities located in London
london_universities = df[df['location'].str.contains('london', case=False)]
# Sum the research funding in thousands
total_funding = london_universities['research funding (000)'].sum()
print(f"Final Answer: {total_funding}")
```
