Step 1: The user wants the average annual change in the number of Conservative councillors from 1947 to 1972.
Step 2: Load the dataframe.
Step 3: Extract the 'Conservative councillors' column and convert it to integers.
Step 4: Calculate the difference between the first and last values (1947 and 1972), then divide by the number of years (1972 - 1947 = 25) to get the average annual change.
Step 5: Print the result.

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'Conservative councillors' to integer
df['Conservative councillors'] = pd.to_numeric(df['Conservative councillors'])
# Extract values for 1947 and 1972
first_value = df[df['Year'] == '1947']['Conservative councillors'].values[0]
last_value = df[df['Year'] == '1972']['Conservative councillors'].values[0]
# Calculate average annual change
annual_change = (last_value - first_value) / (1972 - 1947)
print(f"Final Answer: {annual_change:.2f}")
```
