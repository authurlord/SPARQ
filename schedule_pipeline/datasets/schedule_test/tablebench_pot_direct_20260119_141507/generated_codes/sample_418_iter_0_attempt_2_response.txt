Step 1: The user wants to analyze the trend in "points per game" across tournaments and identify significant changes in performance over time.  
Step 2: First, convert the "points per game" column to numeric for proper analysis.  
Step 3: Sort the data by tournament (which appears to be chronological based on the years).  
Step 4: Observe the trend in points per game over time.  
Step 5: Identify any significant jumps or drops in performance.  

Note: The tournament names are not strictly chronological, but we can infer order from the years (e.g., 2003, 2005, etc.). We will sort by the tournament name as it is listed, which roughly follows chronological order.

We will calculate the points per game values and check for notable changes (e.g., large increases or decreases).

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'points per game' to numeric (in case of string)
df['points per game'] = pd.to_numeric(df['points per game'], errors='coerce')

# Sort by tournament to analyze chronological trend
df_sorted = df.sort_values(by='tournament')

# Extract points per game values and look at trends
points_per_game = df_sorted['points per game'].values

# Identify significant changes (e.g., jumps or drops)
changes = []
for i in range(1, len(points_per_game)):
    diff = points_per_game[i] - points_per_game[i-1]
    if abs(diff) > 1.0:  # Significant change threshold
        changes.append((df_sorted.iloc[i-1]['tournament'], df_sorted.iloc[i]['tournament'], diff))

print(f"Final Answer: {changes}")
```
