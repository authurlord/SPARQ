Step 1: The user wants to find the nation that has a total of 8 medals, including 3 gold medals.  
From the table, we can see that:
- The "Total" column shows the total number of medals.
- The "Gold" column shows the number of gold medals.

We need to filter rows where:
- Total = 8
- Gold = 3

Looking at the data:
- France has 3 gold, 3 silver, 2 bronze → Total = 8 → matches.

So the nation is France.

Now, write correct and safe Python code:

```python
import pandas as pd

# Load the data
df = pd.read_csv('table.csv')

# Filter rows where Total is 8 and Gold is 3
result = df[(df['Total'] == 8) & (df['Gold'] == 3)]

# Extract the Nation name
nation = result['Nation'].values[0] if not result.empty else None

print(f"Final Answer: {nation}")
```
