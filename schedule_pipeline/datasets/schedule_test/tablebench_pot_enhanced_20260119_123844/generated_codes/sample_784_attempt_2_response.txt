Step 1: The user wants to forecast the issue price for 2013 based on historical data from 2002 to 2012.  
Step 2: Load the dataframe.  
Step 3: Extract the 'year' and 'issue price' columns.  
Step 4: Convert 'issue price' to numeric (float) for analysis.  
Step 5: Perform a simple linear regression to model the trend in issue prices over time.  
Step 6: Predict the issue price for 2013 using the regression model.  
Step 7: Print the forecasted price.

```python
import pandas as pd
import numpy as np

df = pd.read_csv('table.csv')
# Convert 'issue price' to float
df['issue price'] = pd.to_numeric(df['issue price'], errors='coerce')

# Prepare data for linear regression
X = df['year'].values.reshape(-1, 1)  # Year as independent variable
y = df['issue price'].values           # Issue price as dependent variable

# Fit a linear regression model
model = np.polyfit(X.flatten(), y, 1)
predicted_price_2013 = np.polyval(model, 2013)

print(f"Final Answer: {predicted_price_2013:.2f}")
```
