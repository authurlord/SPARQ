Step 1: The user wants the total number of years that all ambassadors served.  
Step 2: Load the dataframe.  
Step 3: Convert 'Start' and 'End' columns to integers.  
Step 4: Calculate the duration of each ambassador's service (End - Start + 1, since both start and end years are inclusive).  
Step 5: Sum all durations and print the total.  
Step 6: Note: "Chargé d'Affaires" roles are not counted as ambassadors, so we filter only rows where Title is 'Ambassador'.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter only ambassadors
ambassadors = df[df['Title'] == 'Ambassador']
# Convert Start and End to integers
ambassadors['Start'] = ambassadors['Start'].astype(int)
ambassadors['End'] = ambassadors['End'].astype(int)
# Calculate years served for each ambassador
ambassadors['Years'] = ambassadors['End'] - ambassadors['Start'] + 1
# Sum total years served
total_years = ambassadors['Years'].sum()
print(f"Final Answer: {total_years}")
```
