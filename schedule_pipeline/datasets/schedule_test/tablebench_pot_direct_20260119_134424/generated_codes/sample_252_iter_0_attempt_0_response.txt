Step 1: The user wants the difference between the highest points and the average points of the top 3 artists.
Step 2: Load the dataframe.
Step 3: Extract the 'points' column and convert it to integers.
Step 4: Find the maximum points.
Step 5: Identify the top 3 artists by points and calculate their average.
Step 6: Compute the difference between the highest points and the average of the top 3.
Step 7: Print the result.
```python
import pandas as pd

df = pd.read_csv('table.csv')
# Convert 'points' column to integer
df['points'] = pd.to_numeric(df['points'])
# Find the highest points
max_points = df['points'].max()
# Get the top 3 artists by points
top_3_avg = df.nlargest(3, 'points')['points'].mean()
# Calculate the difference
difference = max_points - top_3_avg
print(f"Final Answer: {difference:.1f}")
```
