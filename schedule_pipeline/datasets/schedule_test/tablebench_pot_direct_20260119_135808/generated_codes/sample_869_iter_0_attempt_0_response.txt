Step 1: The user wants the difference between the highest and lowest metabolic rates among female animals.  
Step 2: Load the dataframe.  
Step 3: Filter rows where 'Sex' is 'Female'.  
Step 4: Extract the 'Metabolic rate' column, convert to float, and find the max and min values.  
Step 5: Calculate the difference and print it.  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Filter for female animals
female_animals = df[df['Sex'] == 'Female']
# Convert 'Metabolic rate' to float and calculate difference between max and min
max_rate = female_animals['Metabolic rate'].astype(float).max()
min_rate = female_animals['Metabolic rate'].astype(float).min()
difference = max_rate - min_rate
print(f"Final Answer: {difference:.1f}")
```
