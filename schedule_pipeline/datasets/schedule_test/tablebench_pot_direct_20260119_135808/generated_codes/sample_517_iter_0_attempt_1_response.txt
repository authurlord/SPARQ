Step 1: The user wants to identify the year with the highest proportion of AIDS-related orphans among all orphans.  
Step 2: Load the dataframe.  
Step 3: Extract the column 'aids orphans as % of orphans' which represents the percentage of orphans due to AIDS.  
Step 4: Find the row with the maximum value in this column.  
Step 5: Return the corresponding year (from the 'country' column, which includes the year in parentheses).  

```python
import pandas as pd

df = pd.read_csv('table.csv')
# Find the row with the maximum percentage of AIDS orphans
max_row = df.loc[df['aids orphans as % of orphans'].idxmax()]
# Extract the year from the country column (e.g., 'botswana (1990)')
year = max_row['country'].split('(')[1].split(')')[0]
print(f"Final Answer: {year}")
```
