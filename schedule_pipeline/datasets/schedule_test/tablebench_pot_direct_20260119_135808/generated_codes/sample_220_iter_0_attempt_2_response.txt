Step 1: The user wants to analyze how the urban percentage changes with increasing population size between 1959 and 1989.
Step 2: Load the dataframe.
Step 3: Filter data for years between 1959 and 1989 (inclusive).
Step 4: Convert 'population (000)' to numeric for proper analysis.
Step 5: Plot urban percentage against population size using matplotlib.
Step 6: Display the plot to visualize the trend.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('table.csv')
# Filter data for years between 1959 and 1989
filtered_df = df[(df['year (january)'] >= '1959') & (df['year (january)'] <= '1989')]
# Convert population to numeric
filtered_df['population (000)'] = pd.to_numeric(filtered_df['population (000)'])
# Plot urban percentage vs population
plt.figure(figsize=(10, 6))
plt.plot(filtered_df['population (000)'], filtered_df['urban , %'], marker='o', linestyle='-', color='b')
plt.title('Urban Percentage vs Population Size (1959-1989)')
plt.xlabel('Population (in thousands)')
plt.ylabel('Urban Percentage (%)')
plt.grid(True)
plt.show()
```
